# 셰이더/그래픽 개발 규칙

## 커밋 정책

- 셰이더/그래픽 변경: 브라우저 시각 확인 후에만 커밋 (개발 중 커밋 금지)

## 이터레이션 루프

- 파라미터 숫자 조정은 역할극/페르소나 논의 불필요 — 구현해서 확인
- 시각적/경험적 판단이 필요한 작업은 논의보다 구현 우선
- **자율 반복**: 변경 → 스크린샷 → 자체 평가 → 만족할 때까지 반복
- 매 이터레이션마다 `screenshots/`에 스크린샷 저장 + 결과보고서 작성 (사용자가 나중에 확인용)
- 만족스러운 지점에 도달했을 때만 사용자에게 최종 보고

## 축적된 교훈

- THRESHOLD/ALPHA만 바꾸면 신호+노이즈 동시 증폭 → 노이즈 먼저 제거 후 증폭
- 확산 맵은 점 노이즈 제거에 완벽하나 ridge 대비도 함께 감소
- 시간 블러 > 공간 블러 — ridge 폭 보존하면서 노이즈 제거
