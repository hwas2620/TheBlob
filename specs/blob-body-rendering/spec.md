## 현재 상태

### 관련 파일
- `src/gpu/shaders/glsl/blob_body.frag.glsl` — 본체 셰이더 (핵심)
- `src/gpu/shaders/blob_body.ts` — 플레이스홀더 치환
- `src/gpu/SceneRenderer.ts` — 렌더링 순서, 블렌딩
- `src/config.ts` — BLOB_BODY 파라미터

### 현재 알파 매핑 (blob_body.frag.glsl)

```
avgVal (trailMap 9셀 평균) → 3단계 알파:
├─ < 0.3 (NOISE_FLOOR): α=0 (투명)
├─ 0.3~2 (FADE_START):  α = smoothstep * 0.15 (점막, 최대 15%)  ← 구름 원인
└─ ≥ 2:                 α = smoothstep(0.1, 0.5, densityT) * 0.85
                         densityT = (avgVal-2)/(150-2)
                         avgVal≥76에서 α=0.85 포화 ← 평탄 원인
```

## 문제 정의

레퍼런스 이미지 vs 현재 렌더링 비교:

| 속성 | 레퍼런스 (실물) | 현재 구현 | 문제 |
|------|----------------|----------|------|
| 중심부 | 불투명, 올리브그린 질감 | α=0.85 균일 → 평탄한 노란색 | 덩어리감/질량감 없음 |
| 가장자리 | **날카로운 경계**, 부채꼴 형태 | α 0→15% 넓은 그라데이션 | 구름/안개처럼 확산 |
| 위족(pseudopod) | 뻗어나가는 촉수 형태, 뚜렷한 윤곽 | 점막 영역이 원형 헤일로 | 촉수 형태 인식 불가 |
| 밀도 변화 | 중심=불투명, 주변=반투명, 정맥 사이=투명 | avgVal≥76이면 전부 0.85 | 내부 밀도 차이 보이지 않음 |
| 표면 질감 | 젖은 광택, 3D 입체감 | 단색 플랫 | 입체감 제로 |

### 근본 원인 3가지

1. **점막 영역(0.3~2)이 넓고 투명**: 15% 알파로 넓은 범위를 희미하게 채움 → 구름
2. **본체 알파 S커브 조기 포화**: densityT 0.5에서 이미 max → 내부 밀도 차이 소멸
3. **엣지 처리 없음**: 경계에서 안쪽/바깥쪽 구분이 그라데이션뿐 → 날카로운 유기적 경계 없음

## 요구사항

- [ ] **R1. 엣지 선명화** — 점막 영역 축소 또는 알파 커브 변경으로 경계를 더 뚜렷하게
- [ ] **R2. 밀도 기반 불투명도** — 중심부(고밀도)와 주변부(저밀도)의 알파 차이 확대
- [ ] **R3. 내부 질감** — 균일한 평면이 아닌, 밀도 변화가 보이는 표면

## 접근 방식

### 가용 데이터

blob_body 셰이더가 접근 가능한 텍스처:
- `u_trailMap` (R32F): 확산된 트레일 (현재 사용 중)
- `u_occupancyMap`: 에이전트 밀도 맵 (바인딩 있으나 density 모드에서만 사용)

**occupancyMap 활용 가능성**: 에이전트 실제 위치 = 확산 전 데이터. 점 단위 밀도로 엣지가 더 날카로움.

### 전략: blob_body.frag.glsl 알파 커브 수정 + occupancyMap 혼합

변경 범위를 **셰이더 1개 + config 파라미터**로 한정. 파이프라인 구조 변경 없음.

구체적 접근은 `/plan`에서 설계.

## 비검증 가정 (구현 시 확인 필요)

- occupancyMap의 해상도/갱신 빈도가 본체 엣지 표현에 충분한가?
- 알파 커브만 바꿔서 "덩어리감"이 나오는가, 아니면 셰이딩(법선/깊이) 필요한가?
- smoothstep 파라미터 변경만으로 충분한가, 아니면 커브 함수 자체를 바꿔야 하는가?
