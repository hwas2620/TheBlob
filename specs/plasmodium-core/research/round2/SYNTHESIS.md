# 2차 실험 종합과 누락 점검

작성: 2026-11-13. 상태: 완료(1~6절 모두 작성).
대상: 2차 실험 7개(E1, E2, E6, E7, E8, E9, E10)와 그 독립 검증 6건. E2 는 검증이 없다.
원칙: 담당자 자기 평가보다 검증자 판정을 우선했다. 검증자가 반박한 주장은 채택하지 않았다. 이 문서의 "[내 판단]", "[내 계산]"은 실험이나 검증에 없는 내 추론이다.

## 0. 결론 먼저

1. 분기·위계 정맥은 나온다. 조건은 "간선 전도도 + 전역 압력 풀이 + 비포화 초선형 강화(γ 1.2~1.5) + 정적 간선 잡음 + 국소(점) 소스"다(E1, 새 시드 재실행으로 확인). 이 나무는 GPU 로 옮길 수 있는 멀티그리드 근사 풀이에서도 512² 까지 유지된다(E9, 새 시드 재실행으로 확인). 1차 실패의 핵심 항목은 이 범위 안에서 풀렸다.
2. 그러나 그 나무는 "고정된 한 점에서 자라 나오는 군체"에 한정된다. 부피 보존에 맞는 소스(물러나는 뒤쪽 경계, 몸 전체)에서는 평행 수로나 줄기 없는 조각이 된다(E1 검증).
3. 부피를 보존하며 스스로 움직이는 몸은 E7/E10 모델에서 나온다. 넓은 시트 전진면, 그 뒤의 분기 정맥, 마른 점액 흔적, 두께 맥동과 왕복 유량, 계단식 전진이 한 실행에 있다(E10, 새 시드 재실행으로 확인). 한계가 크다: 한 방향 이주는 먹이 구배가 있을 때만 되고(맥동 시 무구배 0/8), 정맥이 서로 끊긴 조각난 나무이며(최대 성분 40~51%), 전진면과 정맥이 격자 방향에 잠기고, 근사 풀이로 돌린 적이 없다.
4. 위 1과 3은 아직 합쳐진 적이 없다. E9 의 풀이는 순수 푸아송 + 미리 정한 원반에서만, E7/E10 의 몸은 희소 직접 풀이에서만 돌았다. 권장 모델의 가장 큰 미검증 이음매가 이것이다.
5. 재현 목표 다섯 가운데 (5) "먹이 사이를 굵은 관으로 이음"은 부피 보존 모델에서 시험된 적이 없다. 고정 마스크(E6)와 처방 파동(E8)에서만 부분적으로 보였다.
6. 브라우저 구현의 실제 프레임 시간은 아무도 재지 않았다. 패스 수는 전부 numpy 코드 구성에서 센 값이다.

실험별 근거.

**E9 (7.0).** 대표 구성(512², rate·dt=0.05)을 검증자가 시드 3으로 다시 돌려 발산 없음, 유량 오차 평균 0.059(최대 0.20), 반지름별 고리를 지나는 정맥 수 6→118, 그 중앙 C 4704→45 를 얻었다. 줄기 방향의 격자 편향은 검출되지 않았다(n=723, 11.33° 대 균등 기대 11.25°). 감점 사유: 256² 최소 예산은 유량 오차 버스트 1.3~3.2 와 일시적 Cmax 5.7만을 겪는다. Ccap=3000 은 0.15~0.4R 줄기를 전부 상한에 붙여 안쪽 위계를 지운다. 750²·1500² 는 돌리지 않았고 그 격자는 조대화 레벨이 2~3개뿐이다. 몸은 미리 정한 원반이고 순수 푸아송만 풀었다. 드로콜은 현실적으로 80~90 이다.

**E1 (6.5).** 저장 파일 재채점과 따로 짠 그래프 지표가 보고와 일치했고, 새 시드 7(N=384)에서 같은 나무가 나왔다(분기 273, Strahler 6). 위계는 유량 p90/p10 12~40, r=C^(1/4) 비 2.1~4.0 으로 렌더가 부풀린 것이 아니다. 감점 사유: 나무는 소스가 점일 때만 생긴다. 고리가 없다(그래프 기준 0~4, 렌더의 15~25 는 인공물). 등방성은 정적 간선 잡음이 만든다. 굵기 기준은 경계선(새 시드 rel 0.5 에서 1.94). 성장이 멈추면 완전히 얼어붙는다.

**E10 (6.5).** 새 시드 7 재실행이 구배 하 이주(69.0셀), 뒤가 굵은 전도도 구배(Spearman −0.48), 정맥 총/순 유량 6.2, 젖음 위상 잠금 R 0.87, 질량 오차 3.4e-16 을 재현했다. 감점 사유: 무구배 맥동 8회는 전부 사방 팽창이다. 굵기 구배 교정의 원인은 저역 통과가 아니다(가설 (iii)은 문구대로는 불성립). 정맥은 성분 54~70개의 조각난 나무다. 구배를 27° 돌리면 정맥이 45°·0° 빗살이 된다. Jacobi 40회는 굵은 정맥 유량을 1.8배 과대평가한다.

**E7 (5.5).** 질량 오차 매 스텝 최대 3.4e-16, 음수 두께 없음. 대칭이 스스로 깨져 시트 전진면과 정맥망이 함께 나온다. 감점 사유: 무구배 단일 부채는 5개 시드 중 1개이고 그것도 앞/뒤 폭비 1.02 의 띠다. 굵기는 전진면 10~30셀 뒤에서 최대이고 꼬리는 반지름 환산 0.4~0.8배다. 이주는 가설에 없던 나이 수축 규칙이 만든다(꺼 보면 이동 5.7셀 대 26.4셀). 초기 퍼짐이 대각선으로 12% 더 멀다.

**E6 (4.5).** 간선 그래프 순환 수로 다시 세면 직류 나무 0, 고정 방사파 0~2, 회전 교류 14, 직류+교류 9~12 다. 감점 사유: 혼합 구성의 고리는 줄기 전도도의 0.1~1% 인 관이 닫는다(1% 이상만 세면 7/3/1). 가설 문장 그대로의 고정 연동파는 실패했다. 몸은 고정 마스크다. 전도도 대비 3.6e5 로 GPU 경로가 없다.

**E8 (4.0).** 대표 실행은 재현됐고 전도도 그래프로도 연결된 분기망이다(최대 성분 0.89~0.91, 순환 17~20). 감점 사유: δ 문턱 주장은 모델의 정확한 눈금 불변성 때문에 성립하지 않는다. "Jacobi 로도 망이 비슷하다"는 2단계에서 틀렸다(최대 성분 0.16). 정맥 셀의 56~60% 에서 p=κ(h−h_eq)가 깨져 있다. 맥동파는 실험실 좌표에 처방한 것이다. 먹이장이 토러스 주기가 아니라 몸이 이음매에 눌려 멈췄다.

**E2 (4.0, 잠정, 검증 없음).** 담당자 보고만 있다. 내가 연 그림 두 장(F_montage, D_montage)은 보고와 어긋나지 않는다: cap=1 은 굵기가 균일한 비누막 다각형 그물, cap=0 은 덩어리, 게임 trail 규칙은 cap=1 이어도 수축. 그림 확인은 독립 검증이 아니다. 아래에서 E2 유래 내용은 전부 "미검증"으로 표시한다.

### 2.2 식과 규칙 (E10 대표 설정, 시간 단위는 모델 단위)

격자 G×G, 8이웃 간선(E, N, NE, SE 4채널, 길이 1 또는 √2).
셀 상태: wet, h, age, θ, slime. 간선 상태: C. 정적 텍스처: 간선 잡음 G_e = exp(0.5·N(0,1)), 항복 잡음 η.

1. 위상: dθ/dt = ω·(1 + 0.1·(1 − e^(−age/τ_a))) + D_θ·Σ_{젖은 8이웃} w_j·sin(θ_j − θ_i). 새로 젖은 셀은 부피를 준 이웃의 θ 를 물려받는다.
2. 쉬는 두께: h* = [h0·e^(−age/τ_a)·(1 − (1 − h_fill/h0)·e^(−age/τ_f)) + min(β·√Cn, cap)]·(1 + ε·cos θ). Cn = 인접 간선 C 의 최댓값.
3. 압력: p_i/(κ·dt) + Σ_e W_e·(p_i − p_j) = (h_i − h*_i)/dt, W_e = G_e·(C_e + r)/L_e.
4. 유량과 두께: Q_e = W_e·(p_i − p_j), h_i ← h_i − dt·Σ_e Q_e.
5. 강화: dC_e/dt = rate·((|Q_e|/Q0)^γ − C_e), Q0 는 위 표의 자동 정규화.
6. 마름: h < h_min 이고 age > grace 면 마른다. 남은 부피는 젖은 8이웃에 나눠 주고 slime=1.
7. 젖음: 마른 셀 j 는 젖은 8이웃의 최대 h 가 hy0·(1 + σ_y·η_j) + λ·(3 − n_wet8) + y_s·slime_j − y_c·food_j 를 넘으면 젖고, 그 이웃에서 min(h_fill, 0.5·h/후보 수)를 받는다. age=0, 새 간선 C = D0·(1 ± 0.3).

값: κ=20, h0=1, τ_a=50, τ_f=2, β=0.05, cap=0.5, hy0=1.05, σ_y=0.02, λ=0.06, y_s=0.5, h_fill=0.2, h_min=0.15, grace=2, γ=1.5, rate=0.05, D0=2, r=0.05, dt=0.1, 주기 4, ε=0.1, D_θ=8.8, y_c=0.2.
시간 비[내 계산]: 주기 = 40스텝, 적응 시간 1/rate = 5주기, 나이 수축 τ_a = 12.5주기, rate·dt = 0.005/스텝(E9 의 상한 0.05 보다 10배 작다), v/(rate·R) ≈ 0.16/(0.05·32) ≈ 0.1(E1 담당자가 보고한 "줄기 + 균질 전진 시트" 구간 0.07~0.2 안. 이 구간 자체는 검증자가 확인하지 못했다).

화면의 관 굵기는 C^(1/4) 에 비례해 그린다. 모델 안의 정맥은 전부 1셀 폭이므로 굵기 위계는 렌더 규칙으로만 보인다(모든 검증자가 지적).

### 2.3 검증된 조합과 검증되지 않은 이음매

검증된 조합
- 규칙 2~7 + 직접 풀이: E7(검증자 새 시드 2회).
- 규칙 1~7 + 직접 풀이: E10(검증자 새 시드 1회 + 구배 회전 1회).

   유리한 점[내 판단]: E10 의 전도도 대비는 약 10³(W 최대 2541)으로 E1 나무의 5e7~4e8 보다 훨씬 낮고, 차폐 항이 있어 성분별 합 0 조건(E9 의 섬 폭주 원인)이 필요 없다. 시험된 것은 아니다.

5. 먹이 점원과 먹이 사이 관.
6. 입자층 전체.

두 운전 구간에 대한 가설[내 판단, 미시험]. 게임에서 먹이를 먹는 동안에는 먹이 자리가 실제 부피 소스다. 이것은 E1 이 나무를 얻은 조건(점 소스 → 전진면 싱크)과 같고 Almeida–Dilão 의 설정과도 같다. 굶으며 이주할 때는 소스가 뒤쪽 전체로 퍼져 E7/E10 의 거동이 된다. 따라서 "먹이 셀은 늙지 않는 저장소"(코드에 규칙은 있으나 미시험) 한 줄이 두 구간을 잇는 후보다.

## 3. 누락 점검

### 3.1 돌리지 않은 시험

1. 근사 풀이를 넣은 통합 모델. E7 33회(스모크 2회 포함)와 E10 본 실행 20회는 E7 의 Jacobi 1회를 빼면 전부 희소 직접 풀이다. 멀티그리드로 돌린 실행은 0건이다.
2. 큰 격자. 750² 이상은 어느 실험도 돌리지 않았다. 최대는 E9 512²(처방 원반), E1 384, E6 256, E7/E10 192, E8 128. E2 의 1024² 는 1회이고 미검증이다.
3. 토러스와 장시간. E7/E10 의 구배 실행은 t=325~398 에 상자 경계에 닿아 끝났다. 정상 이주 상태, 자기 흔적을 다시 만났을 때, 막혔을 때의 거동은 본 적이 없다. E8 의 토러스 실행은 먹이장이 주기적이 아니었다.
4. 등방 전진 규칙. 반지름 2 곡률 추정(lam_R=2)은 E7 에서 1회뿐이다. 육각·지터 격자는 E1 의 미리 정한 몸에서만 시험됐다.
5. 점 먹이와 먹이 사이 관. E7/E10 의 먹이는 선형 구배 하나뿐이다. 먹이 저장소 규칙은 코드에만 있다. 목표 (5)는 통합 모델에서 미충족이다.
6. 점액 기피. y_s=0 과 0.5 의 1쌍 비교에서 차이가 없었다. 기피를 재는 시험(갈림길 선택, MSD)은 없다.
7. 굵기 교정의 원인 분리. 관 부피항에 맥동을 곱하지 않는 대조(pulse_tube=0, 코드에 옵션 있음), 균일 위상 + 구배 대조가 없다.
8. 절단 시험. 길이의 뒤 절반(부피 19%)만 지웠고 25주기 안에 멈추지 않았다. 문헌 관찰(5~10주기 뒤 정지)과 맞지 않는다. 시트 가장자리만 남기는 조건과 맥동 없는 대조가 없다.
9. 정맥 폭 정칙화. 측방 확산으로 정맥을 2~4셀 폭으로 만든 E1 실행은 나무를 유지했다고 보고됐으나 검증자가 확인하지 못했다. 이 상태에서의 MG 수렴과 네이티브 격자 채점은 아무도 하지 않았다.
10. 먹이로 부피가 늘어나는 경우. 모든 E7/E10 실행은 총 부피가 일정하다. 무구배 5개 실행의 젖은 면적이 2955~3007셀로 거의 같았다는 점에서 전진면 총 길이는 부피 예산이 정한다. 부피가 늘 때의 거동은 모른다.
11. Ccap 대안. 총전류 기준 상한, 유량 제한 등은 제안만 있다. E7 식 자동 Q0 정규화가 근사 풀이의 폭주를 막는지도 미시험이다.
12. float32. 상한 없는 512²(Cmax 1.4만~2.4만), E7/E10 전체, 4,180스텝을 넘는 표류는 float64 로만 봤거나 보지 않았다.
13. 4프레임마다 풀이 + 적응. 256² 에서만 확인됐다.
14. E2 전체의 독립 검증, 그리고 입자와 창발한 몸의 결합. "이동 실패 시에도 침착", GPU 의 감지→이동 한 패스 순서, occupancy 2스텝 갱신도 미시험이다.
15. WebGL2 실측. 프레임 시간, 드로콜 비용, FBO 전환 비용을 잰 사람이 없다.
16. 2차 실험 번호 E3, E4, E5 는 결과 목록과 폴더에 없다. 무엇을 하려던 것인지 이 자료로는 알 수 없다.
17. 1차 문헌 노트가 제안하고 아무도 돌리지 않은 것: 준흥분성 Oregonator 파편을 "전진 허가" 변수로 쓰는 안(등방 환경에서 스스로 초승달 전진면이 되는 식이 명시된 유일한 모델), 탈젖음 압력, 막다른 끝 우선 후퇴 규칙, 점액 기피 MSD 검증.

### 3.3 서로 모순되는 결과

A. 줄기는 어디서 오는가. E1: 부피 보존에 맞는 분포 소스에서는 줄기가 없다. E6: 교류만으로는 줄기–가지 위계가 없고, 교류가 직류의 3배 이상이면 직류 줄기도 사라진다. E10: 정맥 총/순 유량이 3.6~7.1 인데(교류 우세) 뒤쪽 정맥이 가장 굵다. 세 결과가 한 설명으로 묶이지 않는다.
   후보 설명[내 판단, 미시험]: E10 은 관 부피항 min(β√C, cap)에도 맥동을 곱한다(e10.py 214행, pulse_tube=1). 굵은 관일수록 맥동 부피가 커서 스스로 펌프가 되고, 그 유량이 다시 관을 굵게 한다. 나이 구간별 C 중앙값이 6→9→30→74 로 단조 증가한다는 검증자 수치는 "상류라서 굵다"보다 "오래돼서 굵다"와 더 잘 맞는다. 그렇다면 E10 의 굵기 구배는 유량이 모이는 줄기 체계가 아닐 수 있고, 정맥이 조각나 있다는 사실과도 맞는다. pulse_tube=0 대조로 가릴 수 있다.
B. 멀티그리드 비용. E9: 1사이클/스텝이면 충분. E8: 2단계 망에서 200사이클 초과. 내가 코드를 확인한 결과 E8 의 mg_test.py 는 조각 상수 보간에 순수 Galerkin(PᵀAP, 과보정 없음)이다. E9 도 이 구성은 10사이클에 오차 0.55 로 느리다고 보고했다. 따라서 직접 모순은 아니다. 다만 E9 의 구성을 E8·E7 식의 차폐 연산자에 넣어 본 사람은 없다.
C. 고리와 맥동. E6 가설: 왕복 유량이 고리를 남긴다. E10 검증: 맥동을 켜면 네이티브 그래프의 고리가 271개(기준선)에서 19~54개로 줄고 망이 조각난다. 방향이 반대다. 설정이 다르다(고정 마스크와 부과한 부하 대 창발한 몸).
D. 등방성. 같은 간선 잡음 σ=0.5 로 E1·E9 는 격자 편향이 없고 E7·E10 은 뚜렷하다. 차이는 전진면이 처방인지 창발인지다. 젖음 규칙(8이웃 최댓값, 8이웃 개수 곡률)이 이방성의 원인이라는 것이 내 판단이다. 시험되지 않았다.
E. 맥동과 방향성. 문헌 관찰은 부채가 연동파 방향과 정렬한다고 한다. E7 g4 와 E10 에서는 어떤 위상 방식이든 맥동이 자발적 편극을 없앴다. Schick 2024 의 세 상태(원반/초승달/번개)를 자발적으로 낸 실험은 없다.
F. 절단 반응. 문헌: 공급이 끊기면 약 5주기 지속, 약 10주기에 정지. E10: 25주기 안에 멈추지 않음(시험 조건이 약함).
G. 얇은 셀이 비워지는 시간. 문헌 값이 2주기(Schenz), 20~75분(Kuroda 환산), 200~500주기(Akita)로 두 자릿수 넘게 다르다. 모델은 τ_a=12.5주기를 쓴다. 근거 있는 선택이 아니다.
H. 점유 제한. 1차 numpy 하이브리드: 점유 제한을 켜면 입자가 흩어져 관이 사라짐. 게임 config 주석: 칸당 1개가 격자 패턴의 원인이라 500 으로 올림. E2: 칸당 1개가 그물의 필요조건이고 흩어지는 것은 가둠이 없어서. E2 의 설명이 앞의 둘을 정리해 주지만 검증이 없고, E2 도 가둠 없는 실행에서 가닥이 가로·세로 축에 정렬되는 것을 보고했다(원인 미확인).
I. 적응 속도. 문헌: 적응 5~50주기. E10: 5주기와 10주기만 시험. E6: 적응이 주기보다 훨씬 느린 극한만. E9: 스텝당 rate·dt ≤ 0.05. 게임 시간으로 어디에 둘지 정해지지 않았다.

### 3.5 결합했을 때 깨질 수 있는 가정

1. "예산이 모자라면 전도도가 폭주한다"는 E9 의 경보는 Q0 가 고정일 때의 것이다. 자동 Q0 정규화는 평균 목표 전도도를 묶으므로 폭주 대신 조용히 틀린 형태가 나올 수 있다[내 판단]. 유량 오차를 따로 재지 않으면 알 수 없다.
2. 유량형 갱신은 Σh 를 지키지만 h ≥ 0 은 지키지 못한다. 유출 제한을 넣으면 음수는 없어지지만 정맥 셀의 56~60% 에서 압력–두께 관계가 깨지고, 강화가 제한 전 유량(실제로 흐르지 않은 양)을 쓴다(E8 검증).
3. 근사 유량의 Kirchhoff 잔차는 0.07~0.5 다(E9). 두께장을 이 유량으로 옮길 때의 영향은 측정되지 않았다.
4. 모든 셀의 쉬는 두께가 나이와 함께 0 으로 간다. 몸은 계속 새 땅으로 나가야 한다. 먹이 위에 머무르는 게임 상황에서 몸이 말라 흩어질 수 있다.
5. 자동 Q0 는 전역량이다. 몸이 둘로 갈라지면(E7 에서 실제로 일어남) 한쪽의 유량 규모가 다른 쪽의 정맥 문턱을 정한다[내 판단].
6. 간선 잡음은 기질에 고정된 정적 텍스처다. 토러스에서 같은 자리를 다시 지나면 같은 정맥 무늬가 나온다[내 판단].
7. 선형 먹이 구배는 토러스에서 주기적이지 않다. E8 의 이음매 인공물이 그 예다. 방향 편향은 점 먹이가 만드는 주기적인 장에서 나와야 하는데, 그 조건의 실행이 없다.
8. 입자 그물은 넓이가 있어야 생긴다(센서 거리 5~9px). 통합 모델의 뒤쪽 몸은 1셀 폭 정맥과 흩어진 방울뿐이고 젖은 셀은 색칠 영역의 39~42% 다. 입자층이 살 수 있는 곳은 앞쪽 시트뿐일 수 있다[내 판단].
9. 입자 10만 개를 밀도 10% 로 쓰려면 몸 면적이 67만~200만 px 여야 한다(E2, 미검증). 통합 모델의 몸 면적이 게임 스케일에서 얼마가 될지 모른다.
10. 게임 속도. 전진이 적응보다 빠르면 정맥이 생기지 않는다(E1 담당자 보고: v/(rate·R) ≥ 0.67 에서 정맥 없음. 검증자는 이 조건을 확인하지 못했다). 적응이 풀이보다 빠르면 폭주한다(E9). 두 조건 사이의 창은 750² 에서 rate·dt 0.01~0.05/프레임으로 추정됐을 뿐이다(E9 외삽, 미측정).
11. 관 굵기 표시. 관 부피항은 C=100 에서 포화하므로 두께 h 로는 굵기 차이가 드러나지 않는다. C^(1/4) 로 굵기를 그리는 렌더 패스의 비용은 누구도 세지 않았다.

## 4. 0단계(브라우저 프로토타입) 통과 기준 제안

spec 의 현재 기준 (a)~(e)를 두 관문으로 나누고 수치를 붙였다. 문턱값은 2차 실험이 실제로 낸 범위에서 잡았다. B2, B3, B5 는 지금의 numpy 모델이 통과하지 못하거나 시험된 적이 없는 항목이다.

관문 A — 풀이 (미리 정한 원반 + 점 소스, E1/E9 복제, 512² 와 768²)
- A1. 안정성: 1만 스텝, 시드 2개에서 NaN 없음, Cmax 가 numpy 기준 실행의 3배 이내.
- A2. 정확도: 200스텝마다 리드백해 CPU 직접 풀이와 비교한 유량 L2 오차의 중앙값 ≤ 0.15, 최댓값 ≤ 0.4.
- A3. 형태: 반지름 0.25/0.5/0.75/0.9R 고리를 지나는 정맥 수가 E9 실행에서 관측된 범위 5~6 / 7~13 / 15~21 / 39~50 의 ±20% 안.
- A4. 시간: 내장 GPU 에서 스텝당 시뮬레이션 시간과 드로콜 수를 실측해 기록한다. 목표는 프레임 평균 4ms. 못 맞추면 512² 또는 k프레임마다 풀이로 낮추고 A1~A3 을 다시 통과해야 한다.

관문 B — 몸 (권장 모델 전체, 관문 A 를 통과한 풀이 구성)
- B1. 질량: 1만 스텝에서 총 부피 상대 오차 ≤ 0.1%(float32), 음수 두께 셀 0, 최대 연결 성분 밖 부피 ≤ 10%.
- B2. 전진면: 점 먹이 쪽으로 한 방향 이주(최근 성장의 80% 이상이 120° 구간 안)가 시드 5개 중 4개 이상. 먹이 방향 0°/27°/45° 모두에서 정맥 현 길이의 격자 방향 ±7.5° 비율 ≤ 0.45(등방 0.333).
- B3. 정맥(간선 그래프로 판정, 렌더 채점 금지): 최대 연결 성분 ≥ 0.8, 유량 문턱 그래프의 Strahler 최대 ≥ 4, r=C^(1/4) 의 p90/p10 ≥ 2, 전진면에서 멀수록 굵음(위치–log C Spearman ≤ −0.4).
- B4. 맥동: 정맥 총/순 유량 ≥ 3, 젖음 위상 잠금 R ≥ 0.7, 뒤→앞 위상 지연 0.5~2바퀴가 몸 길이를 2배로 바꿔도 유지, 내부 시트 두께 진폭 ≥ 3%(E10 은 노화 추세를 포함해 3.6~4.1%, 맥동 순기여는 약 2%).
- B5. 먹이: 점 먹이 3개 이상에 전용 규칙 없이 도달. 도달한 먹이 사이가 연결된 정맥 경로로 50주기 이상 이어지고 그 경로의 C 중앙값이 전체 정맥 중앙값의 10배 이상(반지름 약 1.8배).
- B6. 점액: 흔적이 남는다. 빈 땅과 자기 흔적 중 고를 수 있을 때 빈 땅 쪽 전진이 80% 이상, 사방이 흔적이면 멈추지 않는다.
- B7. 지속성: 토러스에서 500주기 동안 몸이 사라지거나 얼어붙지 않고 B1, B3 을 유지.
- B8. 입자층(선택): 켜도 B1~B7 과 A4 가 유지되고 몸 밖 입자 1% 미만, 1만 스텝에서 뭉침 없음. 실패하면 입자는 흐름 표시로만 쓴다.

관문 A 가 실패하면 관문 B 로 가지 않는다. 관문 B 에서 B3 또는 B5 가 실패하면 spec 의 방식 D(정맥만 그래프로 풀기)나 "먹이 = 점 소스" 구간만 쓰는 축소안을 검토한다.

## 5. 0단계 전에 필요한 다음 실험

N1. 통합 모델 + 멀티그리드 (최우선)
- 목표: 권장 모델의 가장 큰 미검증 이음매를 닫는다. E10 대표 설정이 E9 의 MG 로도 같은 형태를 내는지, 예산이 얼마인지.
- 설계: e10.py 의 직접 풀이를 E9 의 MG(PᵀAP/1.5, V(2,2), ω=0.8, 웜스타트)로 바꾼다. N=256 과 512, 구배 실행 시드 3개, 같은 시드의 직접 풀이를 기준선으로 둔다. 변수: 스텝당 사이클 1/2, 주기당 스텝 40/120, 유출 제한 유무, float32, 정맥 측방 확산(2~3셀 폭). 측정: 10스텝마다 직접 풀이 대비 유량 오차(전체와 C>100 간선), 최소 두께, 이동 거리, 위치–log C Spearman, 네이티브 최대 성분, 고립 성분의 영향.
- 통과: 유량 오차 중앙값 ≤ 0.15, 음수 두께 0, 형태 지표가 직접 풀이의 시드 간 편차 안.

N2. 등방 전진 규칙과 몸 크기
- 목표: 격자 잠김을 없애고, 몸이 커져도 맥동과 전진면이 유지되는 눈금 규칙을 찾는다.
- 설계: 젖음 규칙을 반지름 2~3 등방 곡률 추정, 공간 상관이 있는 항복 잡음, 격자 지터 가운데서 바꿔 구배 0°/27°/45° 로 돌린다. 몸 길이 65/130/260셀(N=192/384/768 은 직접 풀이 한계 안에서)에서 D_θ ∝ L², τ_a ∝ L 같은 눈금 후보를 시험한다. 측정: 정맥 방향 분포, 전진 가장자리 직선성, 단일 전진면 빈도(시드 5), 위상 바퀴 수.
- 통과: 세 방향 모두 격자 방향 비율 ≤ 0.45, 위상 지연 0.5~2바퀴 유지.

N3. 줄기·연결·먹이
- 목표: 모순 A 를 가리고, 조각난 정맥을 잇고, 목표 (5)를 통합 모델에서 처음 시험한다.
- 설계: (a) pulse_tube 0/1 과 균일 위상 + 구배 대조로 굵기 구배의 원인 분리. (b) 먹이 점원 1~3개를 늙지 않는 저장소로 두고(선택적으로 부피 주입) 저장소–전진면 사이 정맥이 이어지는지, 먹이 둘 사이 경로가 굵어지는지. (c) 꼬리 정맥이 마른 흔적에서 끊기는 것에 대한 대책 1~2개(막다른 끝 우선 후퇴, 저장소 연결). 측정은 전부 네이티브 간선 그래프: 최대 성분, Strahler, 먹이 사이 경로의 C.

N4. E2 독립 검증과 창발한 몸 결합 (입자층을 유지할 경우에만)
- 목표: 입자층을 부품으로 쓸 수 있는지 정한다.
- 설계: E2 의 세 주장(칸당 1개 제한이 필요조건, 가둠이 필요, 게임 trail 규칙에서는 수축)을 새 시드로 각 1~2회 재실행. 그다음 E10 실행의 젖은 마스크 시계열을 몸으로 써서 입자 그물이 앞쪽 시트에 생기고 따라오는지 본다.
- 통과: 세 주장이 재현되고, 창발 마스크에서 1만 스텝 동안 그물이 유지된다. 아니면 입자는 흐름 표시로만 쓴다.

우선순위는 N1 > N3 > N2 > N4 다. N1 이 실패하면 권장 모델은 구현 경로가 없으므로 나머지보다 먼저 한다.
