# E6-shuttle-flow-loops — 왕복 유량(교류)과 고리

상태: 완료. 판정 partial. 결론은 6절, 표는 5절.

## 1. 가설
H1. 맥동이 만드는 왕복 유량(몸 크기 파장의 연동파, 순 소스 0)을 주기 평균 |Q| 로 강화에 쓰면 고리와 우회로가 남는다.
H2. 전진면 싱크의 직류 유량과 합치면 순수한 나무가 아니라 고리가 있는 위계망이 된다.
H3. 먹이 노드 사이에서 소스/싱크를 교대하면 먹이를 잇는 굵은 관이 생기고 나머지는 가지치기된다.
부가 질문(문헌에 답 없음): 교류만으로 줄기-가지 위계가 생기는가.

## 2. 모델 (e6.py, E1 의 e1.py 를 고정 몸 + 다중 부하용으로 줄여 다시 씀. e1_copy.py 는 원본 사본)
- 격자: sq8 (대각 포함 8이웃), 간선 길이 L_e (1 또는 √2), 간선마다 정적 로그정규 잡음 g_e = exp(σ·N(0,1)), σ=0.5 (E1 과 같음).
- 몸: 고정 마스크. disc(반지름 0.42N, 경계에 σ=2셀로 평활한 가우스 잡음 1셀 진폭의 요철) 또는 fan(꼭짓점이 뒤, 중심각 110°).
- 압력: 젖은 노드에서 Σ_e w_e (p_i − p_j) = S_i, w_e = g_e (C_e + r)/L_e, r = 1e-3. 희소 직접 풀이(splu), 부하 여러 개는 같은 분해로 푼다.
- 유량: Q_e = w_e (p_i − p_j).
- 부하(소스/싱크) S(t) = (1−f)·S_dc + f·S_ac(t)
  - S_dc: 점 소스(뒤쪽 x = cx − 0.8R, 반지름 2셀) + 전진면 싱크(테두리 셀 중 앞쪽 반, 가중치 cos). 합 0. 총량 I0 = Σ 가중치.
  - S_ac(t) = A·[cos(ωt − φ(x)) − 평균], A 는 "반주기 동안 옮기는 총량의 진폭" ½Σ|S_ac| 의 주기 평균이 I0 가 되게 정함. 합 0.
  - φ(x): plane = 2π (x·n̂)/λ (n̂ 고정 또는 회전), radial = 2π |x − x_rear|/λ. λ = 몸 지름(2R).
- 강화: dC_e/dt = rate·( (⟨|Q_e|⟩/Q0)^γ − C_e ), Q0 = 1, 비포화 거듭제곱 법칙(E1 의 pow).
  - ⟨|Q|⟩ 계산 방법 2가지:
    (quad) C 를 고정하고 위상 K=8 점에서 |Q_dc + cosθ·Q_a + sinθ·Q_b| 를 평균. S 가 t 에 대해 cos/sin 의 선형 결합이므로 한 스텝에 풀이 3개(dc, a, b)면 주기 평균이 정확히 나온다. "적응이 주기보다 훨씬 느리다"는 극한.
    (ema) 시간을 실제로 진행(주기당 16스텝), |Q| 를 시정수 1주기의 EMA 로 저역 통과, 적응 시정수는 주기의 20배. quad 의 검증용.
- 초기 조건: 모든 간선 C = D0·(1 + 0.3·U(−1,1)), D0 = 1 (공간 구조 없는 백색 잡음). 구조를 그려 넣지 않는다.
- 요동 싱크(고리의 다른 경로): 스텝마다 전진면 싱크의 일부(비율 p_on)만 켠 표본 K개를 뽑아 ⟨|Q|⟩ 평균. 부분집합은 상관 길이 ℓ 의 가우스 무작위장 상위 p_on 분위.
- 먹이: 먹이 n개(시드로 정한 무작위 위치). 모든 쌍 (i,j) 에 대해 i=소스, j=싱크인 부하의 |Q| 를 평균(= 쌍을 빠르게 교대하는 극한).

## 3. 계획 (배치)
- A: 교류만 (plane 고정 / plane 회전 느림·빠름 / radial), γ=4/3. quad 대 ema 검증 1회. 시드 2개.
- B: 직류+교류 비율 f = 0, 0.5, 0.75, 0.9, 0.97, 1. 고리 수와 위계를 함께 측정.
- C: γ = 1.0, 1.1, 1.2 (직류), 요동 싱크 p_on × ℓ. 고리 수 대 위계 맞바꿈 곡선.
- D: 먹이 4~5개 쌍 교대. 균일 초기 조건 / 직류 나무에서 시작(가지치기 확인) / 교류 배경 추가.
- 마지막: 가장 나은 구성 N=256 1회.

3. 해상도: N=256 에서도 큰 고리 수가 같다(교류만 10, f=0.5 14; N=128 은 10, 13). 그물코 크기는 격자가 아니라 몸 크기(=파장)에 비례한다. 다만 N=256 f=0.5 의 고리는 가는 관이 만든 것이라 문턱 0.35 에서는 0개다.
4. 부채꼴 몸 + 직류 0.5 + 방향 ±45° 흔들리는 평면파 0.5 (e_fan_f050_pwob45_s1/s2): 꼭짓점 줄기 → 전진면 쪽 가지 + 가지 사이 연결 고리 8~10개 + 잔가지. taper −0.32, 공통 채점 all_three 통과(시드 2개). 이번 실험에서 실제 점균 사진에 가장 가까운 그림이다. 단, 실물과 달리 그물코 크기가 앞뒤로 균일하고, 잔가지가 막다른 가지다.
   주의: fan 마스크는 격자 상자에 위아래가 잘려 호의 일부가 직선 벽이다(싱크는 실제 호 부분에만 있음).
5. 정적 다방향 부하(F): 평면파 2방향(0°, 90°) 또는 3방향(0°, 60°, 120°)의 cos/sin 부하를 동시에 풀어 ⟨|Q|⟩ 를 평균해도 회전파와 같은 고리 그물이 된다(큰 고리 10~13, 시드 2개). 회전이 꼭 필요한 것이 아니라 "서로 다른 방향의 부하가 둘 이상" 이면 된다. 2방향이면 부하 4개라 RGBA 한 장에 들어간다.
6. 배경 전도도 r (판의 기본 전도도): r = 0.001(기본) 큰 고리 10 → r = 0.01 은 7 → r = 0.03 은 6 → r = 0.1 은 0(가운데에 수지상 나무 하나만 남음) → r = 0.3, 1.0 은 정맥 없음. 균일 상태의 간선 전도도가 약 0.15 이므로 r 이 그 값에 가까워지면 판이 유량을 나르고 관이 필요 없어진다. 고리가 남은 경우의 전도도 대비 Cmax/r 은 6천 이상이다(r=0.03: 6024, r=0.1: 1766 에서는 고리 없음).

## 6. 결론
- H1 (왕복 유량 → 고리): 조건부로 맞다. 파 방향이 하나로 고정되면(평면파, 한 점 방사파, 정상파) 고리 없이 평행 수로만 생기고 서로 끊긴다. 방향이 둘 이상이거나 시간에 따라 바뀌면(±20° 흔들림부터) 하나로 이어진 고리 그물이 되고 적응 시간 360배까지 유지된다. 시드 2개, N=128·256 에서 재현.
- 부가 질문 (교류만으로 줄기-가지 위계): 생기지 않는다. 굵은 다각형 그물 + 잔가지의 2단 위계뿐이고, 페이스메이커 쪽이 굵어지는 위계는 없다(taper_rho −0.03 ~ −0.10). 합이 0 인 부하에서는 몸 끝(페이스메이커)을 지나는 교류 유량이 0 이기 때문이다. 교류 줄기는 서로 반대 위상인 두 부피 사이의 좁은 목에서만 생긴다(먹이 쌍 실험이 그 예).
- H2 (직류 + 교류 → 고리가 있는 위계망): 일부만 맞다. 직류:교류 = 1:1~3:1 (f = 0.25~0.5)에서 줄기와 고리가 함께 보이고 공통 채점 기준을 통과한다(시드 2개, 원반·부채꼴). 그러나 줄기→가지 굵기 구배(taper)는 직류 나무의 절반 이하로 약해지고(0.68~0.83 → 0.12~0.33), 교류가 직류의 3배 이상이면(f ≥ 0.75) 직류 줄기는 사라진다. 실물은 왕복류가 순 유량보다 훨씬 크다고 알려져 있으므로(문헌 노트), "약한 직류 + 강한 교류"로는 실물의 줄기를 설명하지 못한다.
- 고리 대 위계: 네 경로 모두 맞바꿈이다. 지수 1.05~1.1 이 같은 고리 수에서 위계를 가장 많이 남긴다. 요동 싱크는 테두리 정맥을 만든다.
- H3 (먹이 쌍 교대 → 먹이를 잇는 굵은 관 + 가지치기): 맞다. 먹이 4개 시드 2개에서 슈타이너 나무 꼴의 굵은 관만 남았다. 먹이 5개 1회에서는 고리 1개. 기존 망에서 시작하면 경로가 이력에 의존한다.
- 종합 판정: partial.

## 7. 실패하거나 기대와 달랐던 시도
- 고정 방향 교류(문헌이 말하는 "뒤쪽 페이스메이커에서 앞으로 가는 파" 그대로): 고리 0~5(문턱 0.35 에서 0~2), 망이 끊김. 가설 H1 의 원래 문장은 이 구성에서 틀렸다.
- 요동 싱크: p_on 0.012~0.5, 상관 길이 0~12 여덟 조합 모두 큰 고리 6개 이하.
- 배경 전도도 r ≥ 0.1: 고리 소멸, r ≥ 0.3: 정맥 소멸.
- 직류 + 강한 교류(f ≥ 0.75): 줄기 소멸.

## 8. GPU 실현성 (이 실험에서는 근사 풀이를 돌리지 않았다. 아래는 E9 결과와 이번 결과를 합친 추정이다)
- 전역 압력 풀이가 필요하다(직접 풀이로만 시험함).
- 부하가 여러 개여도 행렬이 같으므로 압력 텍스처의 채널에 나눠 담으면 패스 수는 늘지 않는다. 평면파 2방향 × (cos, sin) = 4채널(RGBA 한 장)로 고리가 나왔다(F). 직류를 더하려면 채널이 하나 더 필요하다(텍스처 2장 또는 방향 1.5개).
- 주기 평균은 닫힌 식이라 시간 진행과 EMA 버퍼가 필요 없다. 간선 유량이 Q(θ) = d + A·cos(θ − ψ), A = √(Qa² + Qb²) 이면 ⟨|Q|⟩ = |d| (|d| ≥ A), 아니면 (2/π)[√(A² − d²) + |d|·asin(|d|/A)]. 부하가 정적이므로 웜스타트가 그대로 듣는다. 화면의 왕복 흐름은 같은 Qa, Qb 에서 cos/sin 으로 합성하면 된다.
- 간선 전도도 4방향 = RGBA 한 장, 간선 잡음은 정적 텍스처.
- 패스 추정: 멀티그리드 V(2,2) 1사이클 ≈ 미세 패스 9.4회 분량(E9) + 조대 전도도 제한 약 1.3 + 유량·적응 1 → 프레임당 풀스크린 12회 분량 안팎. 직접 확인하지 않았다.
- 위험: 고리가 남는 영역의 전도도 대비 Cmax/r 은 6천 이상이고 정맥은 간선 1줄 폭이다. E9 는 "폭 1셀·대비 ≥ 500 이면 멀티그리드 발산"이라고 보고했다. r 을 올려 대비를 1800 으로 낮추면 고리가 사라졌다(G). 따라서 지금 파라미터로는 GPU 풀이가 수렴한다는 근거가 없다. 정맥 폭을 여러 셀로 퍼뜨리는 항(E1 의 Dm)이나 전도도 상한을 넣고 고리가 남는지 따로 확인해야 한다.

## 11. 한계
- 몸이 고정 마스크다. 전진, 부피 보존, 두께, 점액은 없다. 맥동은 미리 정한 위상 패턴의 부하로만 넣었고 두께와 결합하지 않았다.

- 간선 잡음 σ=0.5 의 sq8 격자 하나만 썼다. 격자 종류와 잡음 세기 의존성은 보지 않았다(F 의 2방향 그물에는 0°/90° 방향 격자 무늬가 보인다).
- 근사 풀이(멀티그리드, Jacobi)는 시험하지 않았다.
- 시드는 대부분 2개다. f=0.5 회전파는 시드에 따라 큰 고리 13 대 6, taper −0.26 대 −0.12 로 차이가 컸다. 먹이 5개, 회전 정지, r 스윕, N=256 은 시드 1개다.
- 고리 수는 관 래스터의 구멍 수라 문턱(0.2 / 0.35)에 따라 달라진다. 두 값을 함께 적었다. taper_rho 는 이 실험에서 정의한 지표다.
