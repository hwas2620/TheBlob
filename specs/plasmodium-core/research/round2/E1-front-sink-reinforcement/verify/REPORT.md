# E1 독립 반박 검증 (verify/) — 진행 기록

대상: E1-front-sink-reinforcement, 담당자 verdict=partial, 대표 실행 runs/f_N384_s1
가설: 전진면 싱크 + 중심/뒤쪽 소스 + 전역 압력 풀이 + 초선형 강화 -> 분기·위계 정맥 나무가 창발, 시드·격자·스케일·이동에 견고.

모델 식(코드 e1.py 확인):
- sum_e w_e (p_i - p_j) = S_i, w_e = g_e (C_e + r)/L_e, 희소 직접 풀이
- Q_e = w_e (p_i - p_j), dC_e/dt = rate (|Q_e/Q0|^gamma - C_e)
- 싱크: 전진면 셀마다 -j0, 소스: 중심 반지름 2셀 원판

계획:
1. 대표 이미지 3~5장 열람
