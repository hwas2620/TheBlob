# E1 — 전진면 싱크 + 전역 압력 포아송 + 유량 초선형 강화 (REPORT)

(작성 중인 살아 있는 문서. 배치가 끝날 때마다 아래에 덧붙인다. 마지막 절이 가장 최신 상태다.)

## 0. 가설
전진면이 부피를 소비하는 싱크이고 몸 뒤쪽/중심이 소스인 전역 유량(압력 포아송)을 풀고, 간선 전도도를 유량으로 초선형 강화하면
전진면 뒤에 분기·위계 정맥 나무가 창발한다. 이 결과는 시드·격자·스케일·몸의 이동에 견고하다.

## 1. 구현한 식 (e1.py — 전임자 코드를 검토 후 이어서 사용)
- 노드 = 격자 셀, 간선 = 격자 링크(sq4: 2방향, sq8: 4방향, hex: 3방향; jitter 는 노드 좌표를 U(-j/2, j/2) 로 흔듦). 간선마다 전도도 C_e ≥ 0.
- 몸 마스크 wet(t) 는 **운동학적으로 미리 정해 준다**(창발 아님):
  - grow: 도착시각 T(x) = (|x−c| − R_init + front_rough·η(x)) / v, η = σ=2셀 가우스 평활 백색잡음(표준편차 1). wet = T ≤ t.
  - translate: 반지름 Rb 원반이 +x 로 속도 v 로 평행이동. teardrop: 앞은 반원, 뒤는 길이 taper·Rb 의 쐐기 꼬리.
- 전진면 = 마른 이웃이 있는 젖은 셀. 싱크 S_i = −j0 (grow) 또는 −j0·cos(법선, 진행방향) (이동, 앞쪽 절반만).
- 소스: point(중심 반지름 2셀 원판에 균등), body(전진면 제외 몸 전체 균등), ring(대조), rear(이동 모드: 뒤쪽 경계 셀에 −cos 가중), tail(꼬리 한 점).
  총량은 ΣS = 0 이 되도록 맞춘다.
- 압력: 젖은 노드에서 Σ_e w_e (p_i − p_j) = S_i,  w_e = g_e (C_e + r)/L_e,  r = 1e-3(누설),  g_e = exp(edge_sigma·N(0,1)) (정적, 공간 상관 없는 간선 잡음).
  scipy 희소 직접 풀이(spsolve), 매 스텝.
- 유량 Q_e = w_e (p_i − p_j).
- 적응: dC_e/dt = rate·( f(|Q_e|/Q0) − C_e ),  pow: f = x^γ,  sig: f = x^γ/(1+x^γ).  명시적 오일러, dt=0.1.
- 새로 젖은 간선: C_e = D0·(1 + D0_noise·U(−1,1)) (정적 백색 잡음). 마른 간선: C_e = 0.
- 초기 조건: 반지름 R_init=6 원반, 모든 간선 C = D0(1±잡음). **정맥 경로를 심은 것 없음.**

## 2. 코드 검토 결과 (1단계)
- 구조를 손으로 넣은 곳: 없음. 공간 구조를 가진 입력은 (a) 미리 정한 몸 윤곽(원반/물방울), (b) 전진면 도착시각의 평활 잡음 η(σ=2셀), (c) 중심 점 소스 위치뿐이다.
  간선 잡음 g_e 와 초기 C 잡음은 간선별 독립(백색)이라 경로 정보를 담지 않는다.
- Kirchhoff 잔차: 로그의 kirchhoff_rel_resid = max_i |Σ_e Q_e − S_i| / max|S| 는 직접 풀이에서 1e-11~1e-9. 식(노드별 유출 합 − S) 확인함. 독립 재계산은 analyze.py 에서 다시 함(아래).
- **채점 관련 주의(중요)**: 정맥이 격자 간선 1줄(폭 1셀)이라, 노드장(native)으로 eval_morph 를 돌리면 대각선 1셀 정맥이 4-연결 작은 객체 제거에 지워지고
  p99 임계값이 굵은 줄기만 남겨 분기점이 0~5로 나온다. 전임자는 이를 피하려고 "공식" body.npy/vein.npy 를 **렌더**로 바꿨다:
  간선을 지름 0.7·C^(1/4) 셀(Poiseuille C∝r^4)의 선분으로 4배 해상도에 그림(C>0.008 인 간선만). 즉 eval.json 의 지표는 이 렌더 규칙에 의존한다.
  → 렌더와 무관한 간선 그래프 지표(analyze.py: 유량 임계값별 분기 노드 수, 고리 수, Strahler 차수, 접합점 Murray 지수)를 추가해 교차 확인한다.
- **b_ 계열이 분기점 5개 이하로 채점된 이유**: 간선 잡음 때문이 아니다. b_ 계열의 eval.json 은 렌더 도입 전 판(native 노드장 채점)이다.
  같은 실행의 로그(log_b_pow_sq8.txt)에 `EVAL render: branch_points 47, all_three True` 가 찍혀 있고, 파라미터가 동일한 b_pow_sq8n 과 c_pow15_s1 은
  native 분기점 0, ring 정맥 수 5/11/18/34 로 완전히 같다. (아래 3절 표의 b_ 행은 native 채점, c_ 행은 렌더 채점이라 직접 비교 불가.)

## 5. 이번 세션 추가 도구

- table.py(표), moving_stats.py(이동 모드: 스냅샷 간 정맥 집합 Jaccard, 실험실 좌표 vs 몸 좌표), batch_run.py(동시 실행 수 지정).

## 11. 실패/부정적 결과 (그대로 기록)
- 포화(sig) 강화 법칙: 위계 없음(균일 굵기 방사선/그물).
- γ ≤ 1.0: 그물 또는 전체가 참. 고리는 γ>1.1 에서 사실상 0 — **고리가 있는 실제 정맥망은 재현되지 않는다**(코드의 sink_fluct 옵션, 즉 요동 싱크는 시간 부족으로 돌리지 않음).
- 몸 전체 균등 소스, 고리 소스: 줄기 없음. 뒤쪽 경계 분포 소스 + 원반 몸: 평행 수로(나무 아님).
- D0=100: 전진면 띠를 통해 닫히는 큰 고리(나무 아님).
- 느린 적응(v/(rate·Rb) ≥ 0.67): 정맥이 거의/전혀 없음.
- 잡음 없는 격자: 나무는 생기지만 격자 방향에 잠긴 눈꽃/직각 가지(sq8: A8≈0.5~0.7, sq4: A4≈0.6, hex: A6≈0.6).
- 공통 채점의 위계 기준은 경계선: 기본 조건(N=128, v=0.5) 4개 시드 중 all_three 통과 1개(wr 1.8/1.9/2.24/1.8, sr 1.9~2.3). f_ 계열(v=1, N=128~384) 9개는 전부 통과하나 wr 2.0~2.4 로 여유가 없다.
  렌더 폭이 정수 픽셀로 양자화돼 wr 이 1.8/2.0/2.24 처럼 튄다. 스케일을 키워도 wr 은 늘지 않는다(줄기와 끝가지가 같이 굵어짐).
- eval_morph 를 native 노드장에 직접 적용하면 분기점 0~4 (1셀 폭 정맥이 지워짐) — 공식 지표는 전임자의 렌더 규칙(지름 0.7·C^(1/4)셀, 4배 확대, C>0.008)에 의존한다.
  hex/jitter 격자는 렌더 뼈대에 잔가지가 생겨 bp 가 2~3배 부풀려진다(그래프 분기 노드는 같음).
- 전임자의 c_sig15_Dm05, c_sig15_j30_Dm05 는 중단된 채로 남아 있다(다시 돌리지 않음).

## 12. GPU 실현성 (추정 — 이 실험에서는 직접 풀이만 사용, 근사 풀이는 검증하지 않음)
- **전역 풀이 필요: 예.** 강화가 작동하려면 소스→싱크 전역 유량이 필요하다(몸 지름 규모의 타원형 문제). 국소 규칙만으로는 불가.
- 스텝당 패스(추정): 멀티그리드 V(2,2) 1사이클 ≈ 미세 격자 9.4패스 분량(문헌 노트의 자체 점검값; 레벨당 평활 4 + 잔차/제한/보간 3 → 8레벨이면 드로콜 약 56회, 대부분 작은 텍스처)
  + 전진면/소스·싱크 1 + 유량·적응 1(sq8 간선 4방향 = RGBA 한 장) + ΣS=0 맞춤용 합산(밉맵 축소 또는 화면차폐형 누설 항으로 대체) ≈ **풀스크린 환산 12패스 안팎, 드로콜 60회 안팎**. 예산 경계선.
- 위험 요소: (a) 정맥이 1셀 폭이고 전도도 대비가 10³~10⁶ → 문헌 노트 기준(폭 1셀·대비≥500 에서 MG 발산)에 정면으로 걸린다. 완화 후보는 10절(r≥0.3, Dm>0)이나 미검증.
  (b) 등방성을 위해 간선별 정적 잡음(σ≥0.25) 텍스처 1장 필요. (c) 몸 윤곽·전진면을 여기서는 미리 줬다. 게임에서는 다른 규칙이 줘야 한다.
  (d) 시간 척도: 적응 시간 동안 전진면이 몸 길이의 1/5 이하만 움직여야 하므로, 압력을 프레임당 1사이클 웜스타트로 추적하는 방식과는 잘 맞는다(소스가 느리게 변함).

## 13. 결론
- 판정: **partial** (핵심 주장은 강하게 지지, 견고성 주장 중 "몸의 이동/소스 배치"는 조건부).
  - 지지: 전진면 싱크 + 국소 소스 + 전역 압력 + 비포화 초선형 강화(γ≥1.2)면 분기·위계 나무가 손으로 심지 않아도 생긴다.
    시드 4개, 격자 4종, N=128~384, 성장 정지 후 유지, 이동하는 물방울 몸(시드 2개)에서 재현. 그물↔나무 전이는 γ=1.0~1.1. 접합 차수 3 이 95~99%. Horton 분기비 2.6~3.6.
  - 조건/한계: (1) 소스가 국소(중심 점, 꼬리)여야 한다. 뒤쪽 경계 전체나 몸 전체가 소스면 줄기-가지 나무가 아니다. (2) 등방성에는 간선 잡음 σ≥0.25 가 필요(분기 자체에는 불필요).
    (3) v/(rate·몸 반지름) ≲ 0.07 이어야 전진면 뒤까지 나무; 0.2 근처는 "줄기 + 균질 전진 시트". (4) 고리가 없다. (5) 공통 채점의 굵기 위계 기준은 경계선 통과.
    (6) 몸 윤곽과 전진면은 운동학적으로 준 것이라 부채꼴 전진면의 창발은 시험하지 않았다. (7) 직접 풀이만 사용.
