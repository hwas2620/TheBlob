상태: **완료** (전임자 실행 45개 정리 + 새 실행 6개. 판정 partial. 요약은 6~8절.)

## 0. 가설
Jones 2010 입자망은 올바른 영역(셀당 1입자 점유 제한, 몸 면적의 3~15% 밀도, RA>=SA)과 고정점이 있으면
실제 스케일에서 분기 그물로 유지되고, 이동·확장하는 몸을 따라온다.
현재 게임이 한 줄로 뭉치는 것은 점유 제한이 사실상 꺼져 있기 때문이다(AGENT.OCCUPANCY_MULT=500).

## 2. 구현된 식 (jones.py 기준, 코드 확인함)
- 입자 상태: 위치 (x,y) 실수, 방향 단위벡터 (hx,hy). 몸 마스크 body, 점유 수 occ, trail.
- motor: (x,y) + 1px·h 로 이동 시도. 새 칸이 몸 밖이거나, 다른 칸인데 occ>=cap 이면 실패 → 이동·침착 없이 방향을 균등 무작위로 다시 뽑음.
  성공하면 새 칸 trail += depT(=5). 갱신 순서는 매 스텝 Fisher-Yates 로 섞는 순차(비동기) 갱신.
- sensor: F, FL, FR = trail[pos + SO·dir(θ, θ∓SA)].
  F>FL&&F>FR 직진 / F<FL&&F<FR 무작위 ±RA / FL<FR → +RA / FR<FL → −RA / 그 외 직진.
- 고정점: 지정 칸(먹이 노드 3×3, 전진면 띠)에 매 스텝 trail += w. node_supp<1 이면 입자가 있는 칸은 w·supp.
- 확산: trail ← 3×3 평균 × (1−damp), damp=0.1, 토러스.
- SO 구배: SO(x) = SO + (SO_rear − SO)·age01(x)^so_pow.
- 초기 조건: 입자는 몸 칸에 균등 무작위(cap=1 이면 서로 다른 칸), 방향 균등 무작위, trail=0. 구조를 심지 않음.
- 잡음: 초기 위치/방향, 갱신 순서 셔플, 충돌 시 방향 재추첨, F<FL&&F<FR 일 때 좌우 무작위. 그 밖의 잡음 없음.
- vein.npy = 마지막 40스텝 trail 시간평균. body.npy = 몸 마스크 × (1 + 9×9 국소 입자 점유율).

(jones2.py / jones2_new.py 의 추가 규칙은 3절에서 코드 확인 후 적는다.)

## 3. 추가 규칙 (jones2.py / jones2_new.py / jones3.py, 코드 확인함)
- growdisk: 반지름 R(t)=min(R0+floor(v·t), R) 로 커지는 원반. movedisk: 반지름 R 원반이 +x 로 v px/스텝 병진(토러스). 둘 다 **몸 마스크를 미리 정한 속도로 움직인다**(창발 아님).
- front_inject=p: 새로 젖은 칸마다 확률 p 로 입자 1개 생성. exit_mode=relocate: 몸 밖에 남은 입자를 새로 젖은 빈 칸으로 옮김(입자 수 보존). delete: 삭제.
- grow/shrink(Jones 성장·수축): Gf=3 스텝마다, 이동에 성공한 입자의 9×9 창 점유 칸 수 c 가 1<=c<=10 이면 3×3 이웃 빈 칸에 새 입자. Sf=3 스텝마다 5×5 창 c>24 이면 삭제.
- SO 구배: SO(x)=SO+(SO_rear−SO)·age01. so_mix: 입자마다 SO 4 또는 14 를 반반 배정.
- sync=1 (GPU 식 2패스 claim): 패스1 = 모든 입자가 이전 상태 기준 목표 칸에 무작위 우선순위로 claim(칸마다 최대값 1개만 남음). 패스2 = claim 이 이긴 입자만 이동·침착, 나머지는 제자리 + 방향 무작위. 이번 스텝에 비워지는 칸으로는 못 들어감.
- "게임 trail"(F03/F04/F06): 3×3 평균 4패스(diff_passes=4), 감쇠는 마지막 패스에만 ×0.97(damp=0.03), SO=9. 게임의 상한 500, 입자별 SO/SA 변이, 스카우트·추종·압력 규칙, "이동 실패해도 침착"은 **넣지 않았다**.
- (이번에 추가, jones3.py) geom='free': 몸 마스크 없음(토러스 전체가 이동 가능). 입자는 반지름 init_R 원반 안에서 균등 무작위로 시작. 평가용 몸 = 입자 윤곽(점유 맵을 σ=6 가우시안으로 흐린 값 > 0.02, 구멍 채움).
- (이번에 추가, jones3.py) sync=2 "지연 점유 검사": 스텝 시작 시점의 점유 맵만 보고 목표 칸이 비었으면 이동. 같은 스텝에 여러 입자가 같은 칸에 들어가는 것을 막지 않음(중재 없음). 게임의 기존 occupancy 패스를 문턱 1 로 쓰는 것과 같은 방식.

## 6. 질문별 답 (근거 실행, 시드 수 명시)

### (1) 점유 제한·밀도·SA/RA·SO
- **점유 제한이 결정적이다.** cap=1 이면 밀도 3~40% 의 모든 실행(A01,02,05,08~16; 12개)이 연결된 다각형 그물(T=8000 에서 BP 20~101, 최대 성분 0.99~1.0).
  cap=0 이면 밀도 10/40/100%, SA/RA 22.5/45·45/45·34.4/34.4 의 7개 실행(A03,04,06,07,17,18,20) 모두 T=2000 이전에 BP 0~1(고리 하나 또는 직선 하나). 시드 2개(A03/A04) 포함.
- 밀도(cap=1, SA22.5/RA45/SO7, T=8000): 3% BP 35(가는 선, 최대 성분 0.988) / 5% 50 / 10% 52·59 / 20% 54(폭 12px) / 40% 46(폭 27px, 정맥 면적 50% — 구멍 뚫린 판) / 90%(SA=RA=34.4) 전체 균일 참, 구조 없음.
  → 선 모양 그물은 5~15%, 20~40% 는 "구멍 난 시트", 90% 는 시트. 3% 는 되지만 성기다.
- SA/RA: RA>SA 여야 한다. SA22.5/RA45 는 유지되며 천천히 조대화, SA15/RA45 는 가장 촘촘하고 안정(BP 101@8k, 94@32k). SA30/RA45(SO5)도 그물(BP 54).
  **SA=RA(45/45, 60/60)는 벽에서 떨어져 수축**: 45/45 는 BP 20@8k → 0@32k(고리 하나). 가설의 "RA>=SA" 중 등호는 틀렸다.
- SO: 그물눈 크기를 정한다. SO5 → BP 95(그물눈 넓이 중앙값 1670px²), SO7 → 52·59(1850~2900px²), SO12 → 큰 방 6개 안팎 + 접합부가 막처럼 넓어짐(BP 62 는 막 속 작은 구멍 때문에 부풀려진 값). 관 폭은 SO 와 거의 무관하게 6~8px.
- 모양: 굵기가 균일한 비누 거품형 다각형 그물이다. 접합 차수는 대부분 3(눈으로 본 것, 측정 안 함). 실제 점균의 뒤쪽 그물과는 닮았지만 굵기 위계가 없다.
- 주의: 이동 성공률은 0.1~0.5 다(정맥 안이 정체 상태). Jones 규칙은 이동에 성공했을 때만 침착한다. 게임은 실패해도 침착한다 — 이 차이는 시험하지 않았다.

### (2) 장시간 유지
- T=32000(B01/B02, 시드 2개): 그물은 끝까지 하나로 연결된 채 벽에 붙어 유지된다. 그러나 정상 상태는 아니다. BP 176·187(@500) → 55·57(@8k) → 43·42(@32k), 후반 기울기 d lnBP/d ln t = −0.37·−0.60. 그물눈이 계속 커진다.
- SA15/RA45(B03, 시드 1개): 110(@8k) → 94(@32k), 기울기 −0.14. 거의 정지.
- SA=RA=45(B04, 시드 1개): 수축해 고리 하나(BP 0).
- 32000 스텝은 60스텝/초로 약 9분. 그보다 긴 시간은 보지 않았다. 조대화가 멈춘다는 증거는 SA15 한 조건·시드 1개뿐이다.
- 조대화를 되돌리는 것은 "새로 젖은 곳에 새 입자"다(D 계열). 몸이 움직이는 한 앞쪽에는 항상 촘촘한 새 그물이 있다.

### (3) 고정점
- 기본 영역(SA22.5/RA45)에서 먹이 노드 12개(w=5; C01/C02, 시드 2개): BP 57·61@32k (노드 없음 43·42), 후반 기울기 −0.03·+0.29 → 조대화가 멈추고 그물이 약 33~45% 더 촘촘하게 남는다. 효과는 있지만 크지 않다.
- 수축 영역(SA=RA=45)에서 노드 12개(C05, 시드 1개): BP 10@32k (노드 없음 0). 수축이 노드에 걸려 노드를 잇는 굵은 망으로 남는다(Jones 의 Steiner 형 결과와 같은 그림).
- 전진면 띠 투사(C04, 시드 1개): 테두리를 따라 고리가 생기고 안쪽 그물이 거기에 걸림(BP 54@32k).
- **가장 강한 고정점은 몸 마스크의 벽이었다.** 가둠을 없애면(G01/G02, 시드 2개) 그물은 수축하지 않고 반대로 맵 전체로 흩어진다. 노드 12개를 줘도 같다(G03). 따라서 "고정점이 있으면 유지"는 정확하지 않고, **"입자를 가두는 몸 마스크가 있으면 유지"** 가 맞다.

### (4) 성장·이동하는 몸
- 전제: 몸 마스크는 미리 정한 속도 v=0.05px/스텝(입자 속도의 5%)으로 움직였다. 창발한 몸이 아니다. 다른 속도는 시험하지 않았다.
- 새로 젖은 칸에 입자를 공급하면 따라온다. 커지는 원반 + 10% 주입(D01): BP 163, 밀도 0.10 유지. Jones 성장/수축 규칙(D03): BP 127, 밀도 0.11~0.14 로 자기 조절. 움직이는 원반 + 재배치(D04/D05, 시드 2개): BP 33·35, 후반 기울기 +0.11·0.0(정상 상태). 삭제 + 성장/수축 규칙(D06): BP 32, 밀도 0.12.
- 공급이 없으면 따라오지 않는다(D02): 입자 덩어리가 가운데 남고 가닥 몇 개만 벽에 닿음(BP 15).
- "따라온다"의 실체: 기존 그물이 운반되는 것이 아니라 새 자리에 수백 스텝 안에 새 그물이 생기는 것이다. 그래서 앞은 젊고 촘촘하고 뒤는 늙고 성기다. D01 의 앞/뒤 뼈대 길이 밀도 43/20 (2.15배), 분기점 밀도 13.1/3.0 (4.4배), 가지 길이 중앙값 11.5px/32.5px. D04/D05 의 앞/뒤 뼈대 밀도 비 2.2·1.41.
  이것은 목표 특징 (2)의 "전진면 바로 뒤는 촘촘, 뒤로 갈수록 성김"과 방향이 같다. 단 관 굵기는 앞뒤가 같다(가지 폭 6.0/6.0px).

### (5) 센서 거리 구배와 굵기 위계
- SO 를 앞 4 → 뒤 16 으로 주면 그물눈 크기 차이는 커진다(가지 길이 뒤/앞 2.3~3.0배: E01, E03, E04).
- 관 굵기는 거의 안 변한다. 구역별 폭 중앙값 뒤/앞: 원반 E01 1.12, 움직이는 원반 E03/E04(시드 2개) 1.33·1.67(가지 단위로는 1.58·1.85, 단 뒤쪽 가지 표본 4~5개), 부채 E05 1.24. SO 혼합(E02) 1.08. 기준 2 에 못 미친다.
- 공통 eval 의 width_ratio_p90_p10 은 2.4~3.0 으로 기준을 넘지만, 구배가 없는 기본 실행도 2.4~2.8 이다. 접합부의 뭉친 곳을 굵은 관으로 세기 때문이고(전임자 hier.py 로 접합부를 빼면 1.3~2.0), 세기 비 strength_ratio 는 전부 1.4~2.4 로 기준 3 미만이다.
- 결론: **Jones 입자로는 굵기 위계가 생기지 않는다.** 그물눈 크기의 구배만 만들 수 있다(나이에 따른 조대화 또는 SO 구배).
- E05(미리 그린 부채꼴 + SO 구배, 시드 1개)는 눈으로 가장 점균 같다: 호 쪽은 촘촘한 그물, 꼭짓점 쪽으로 가닥이 모여 줄기 하나. 그러나 부채 모양과 줄기 수렴은 마스크 기하가 강제한 것이다.

### (6) 동기 갱신과 게임 trail 규칙
- 동기 2패스 claim(F01/F02, 시드 2개): BP 49·52@8k, 비동기 A01/A02 의 52·59 와 같다. 1024²·입자 99707개(F05): BP 243, 고리 121, 최대 성분 1.0, 후반 기울기 −0.17. 실제 스케일에서 성립.
- 지연 점유 검사·중재 없음(F08, 시드 1개): BP 58, 고리 25. 한 칸에 여러 입자가 28% 있어도 그물은 같다. "정확히 1개"일 필요는 없고 "대략 1개"면 된다.
- 게임 trail 규칙(확산 4패스, 감쇠 0.97, SO=9):
  - cap=0(F04, 시드 1개): 점 2개로 뭉침(BP 0). 게임에서 보이는 "뭉침"과 같은 그림.
  - cap=1(F03 시드 1, F06 시드 2): 폭 16~31px 의 흐린 그물이 생겼다가 벽에서 떨어져 수축. BP 10@8k, 8@8.4k → 3@32k. **유지되지 않는다.**
  - cap=1 + 가둠 없음(G04, 시드 1개): 수축해 굵은 고리 하나(BP 2@12k).
  - 해석(검증 안 함): trail 의 퍼짐 길이 σ≈sqrt(패스 수·(2/3)·수명). Jones 규칙은 sqrt(0.67·10)≈2.6px(SO 의 0.37배), 게임은 sqrt(2.67·33)≈9.4px(SO 의 1.04배). 센서 간격만큼 흐려지면 가는 관을 구분하지 못한다. 확산 패스 수와 감쇠를 따로 바꿔 보지는 않았다.
- 따라서 "게임이 뭉치는 것은 점유 제한이 꺼져 있어서"는 **절반만 맞다.** 점유 제한이 꺼져 있으면 반드시 뭉친다(필요조건 확인). 그러나 켜기만 해서는 그물이 유지되지 않는다. trail 을 짧게(1패스·감쇠 0.9) 하고 입자를 몸 마스크에 가둬야 한다.

| 밀도 | 몸 면적의 5~15% | 10만 입자를 반지름 100 에 스폰(약 3.2개/칸) |
| trail | 3×3 평균 1패스, ×0.9 | 3×3 평균 4패스, 마지막에 ×0.97, 상한 500 |
| 침착 | 이동 성공 시에만 | 매 스텝 모든 입자, 스카우트 15배 |
| 가둠 | 몸 마스크 밖으로 못 나감 | 없음(토러스 전체) |
| 그 밖 | 순수 Jones 3센서 규칙 | 입자별 SO/SA 변이, 스카우트·추종·압력·복귀 규칙 (이번 실험에 없음) |

### 권장 영역
- 점유: 칸당 1개. 지연 검사로 충분(F08).
- 밀도: 몸 면적의 약 10%(5~15%). 10만 입자면 몸 면적 67만~200만 px(1500² 맵의 30~89%)에 해당한다. 몸이 작으면 활성 입자 수를 줄여야 한다(예: 반지름 300px 몸 → 1.4만~4.2만 개). 활성 입자 수를 몸 면적에 맞추는 규칙이 필요하다(전진면 주입 확률 0.1 + 몸 밖 삭제, 또는 Jones 성장/수축 규칙).
- SA 15~22.5°, RA 45°(RA>SA). SA=RA 는 쓰지 않는다.
- SO 5~9px(그물눈 크기 조절). 앞쪽 작게·뒤쪽 크게 주면 그물눈 구배가 커진다.
- trail: 3×3 평균 1패스 + ×0.9. 이동에 성공한 입자만 침착(Jones 원형. "실패해도 침착"은 시험 안 함).
- 가둠: 입자가 몸 마스크(예: E7 의 두께장 h > 문턱) 밖으로 나가지 못하게 한다. 없으면 그물이 맵 전체로 흩어진다.

### WebGL2 점유 제한 구현 비용
- 방법 A, 지연 검사(F08 방식): 게임에 이미 있는 occupancy 패스(입자 10만 개를 점으로 R32F 맵에 가산 렌더)를 그대로 쓴다. 바꿀 것은 (1) 문턱을 22.2 → 1 로(목표 칸 점유 < 0.5 일 때만 이동), (2) 목표 칸이 자기 칸과 같으면 항상 허용(floor(newPos)==floor(pos)), (3) occupancy 를 2스텝마다가 아니라 매 스텝 갱신, (4) 점유 맵은 texelFetch 로 정확한 칸을 읽기, (5) 이동 성공 플래그를 상태 w 에 넣어 침착 패스에서 실패한 입자를 버리기.
  추가 풀스크린 패스 0, 추가 점 렌더 0(이미 있는 것을 매 스텝으로: 스텝당 +0.5회). (3)을 2스텝마다로 둔 경우는 시험하지 않았다.
- 방법 B, 엄격한 2패스 claim(F01/F02/F05 방식): claim 텍스처(R32F, 맵 크기)에 입자를 목표 칸 위치의 점으로 그리고 gl.MAX 블렌딩으로 우선순위 최댓값만 남긴다. 우선순위는 입자마다 겹치지 않는 정수(예: (idx·소수 + frame·소수) mod 131071)로 주고, 갱신 패스에서 claim 값이 자기 값과 같을 때만 이동한다. Jones 순서(이동 먼저, 감지 나중)라 목표 칸은 현재 방향만으로 정해지므로 claim 정점 셰이더는 상태 텍스처만 읽는다.
  추가 풀스크린 패스 0, 추가 점 렌더 1(10만 정점). float 텍스처 블렌딩(EXT_float_blend)이 필요한데 게임이 이미 occupancy 가산에 쓰고 있다.
- 입자 층 전체: 풀스크린 패스는 trail 확산·감쇠 1 + 침착 합성 1 = 약 2(현재는 trail 4 + 합성). 전역 풀이는 필요 없다. 프레임당 60패스 예산의 대부분을 유량 풀이(E9 의 멀티그리드)에 남길 수 있다.
- numba 참고치: 1024²·10만 입자·동기 claim 8000스텝에 2스레드 111초(약 72스텝/초).

### 유량 정맥 모델(E1/E7)과 함께 쓴다면 입자의 역할 (의견, 결합은 시험하지 않음)
- 입자가 못 하는 것: 굵기 위계, 간선으로의 합류, 부채꼴 전진면, 몸의 경계 유지. 이것은 유량 모델(전도도 C, 두께 h)의 몫이다.
- 입자가 할 수 있는 것:
  1. **전진면 바로 뒤의 촘촘한 그물 질감.** 새로 젖은 곳에 입자를 뿌리면 수백 스텝 안에 그물눈 20~40px 의 고운 그물이 생기고 뒤로 갈수록 저절로 성겨진다(D01, D04/D05). E1/E7 의 나무는 고리가 없고 E7 은 굵기 구배가 거꾸로였으므로, 전진면 뒤 "가늘고 촘촘 + 고리 있음" 구간을 입자가 채울 수 있다.
  2. **고리와 가로 연결.** 유량 나무의 가지 사이를 잇는 가는 그물(차수 3 접합, 고리 다수).
  3. **시트 → 그물 전이.** 밀도 90% 는 균일한 시트, 40% 는 구멍 난 시트, 10% 는 그물이다(A19, A16, A01). 전진면에서 높은 밀도로 주입하고 뒤에서 솎아 내면 "앞은 시트, 뒤는 그물"이 입자만으로 나올 가능성이 있다. D06 의 초반(밀도 0.28 → 0.12)이 이 전이를 한 번 보여 준다. 공간 구배로는 시험하지 않았다.
  4. 정맥 안의 흐름 질감(입자가 정맥을 따라 움직이는 것 자체)과 맥동 표시.
- 결합 방식 제안(모두 미검증): 몸 마스크 = h > 문턱. 입자 감지값 = 자기 trail + α·(유량 전도도 C) 로 해서 입자 그물이 굵은 유량 정맥에 달라붙게 한다. 굵은 관의 굵기는 C 로 그리고 입자 trail 은 그 위의 가는 그물로 합성한다. 입자 공급은 새로 젖은 칸 확률 0.1, 제거는 h < 문턱.
- 입자만으로 가려는 경우의 한계: 몸 경계를 스스로 만들지 못하고(G 계열), 굵기 위계가 없다(E 계열). 목표 특징 (1)(2)(3)(4) 중 입자 단독으로 되는 것은 (2)의 "그물과 고리" 부분뿐이다.

## 8. 가설 판정: partial
- 맞은 부분: 칸당 1입자 제한 + 밀도 3~40% + RA>SA 이면 512²와 1024²(입자 10만)에서 연결된 분기 그물이 생기고 32000 스텝까지 유지된다(시드 2개). 동기 갱신에서도 같다. 입자를 공급하면 커지거나 움직이는 몸에도 그물이 생긴다. 점유 제한을 끄면 항상 뭉친다.
- 틀리거나 부족한 부분:
  1. 유지에 필요한 것은 고정점이 아니라 가둠(몸 마스크)이다. 가둠이 없으면 흩어진다(시드 2개).
  2. RA=SA 는 수축한다. RA>SA 여야 한다.
  3. 게임의 뭉침은 점유 제한만의 문제가 아니다. 게임 trail 규칙에서는 cap=1 이어도 그물이 10⁴ 스텝 안에 수축한다(시드 2개).
  4. 굵기 위계가 없다. 연구 목표의 (2) 중 "굵기 위계"와 (1) 부채꼴 전진면, (3) 맥동, (4) 부피 보존에 따른 이동은 이 모델에 없다.
  5. 기본 영역의 그물은 32000 스텝에서도 아직 조대화 중이다.
  6. 몸의 이동·성장은 손으로 정한 마스크였다.

## 11. 한계와 확인하지 못한 것
- 몸 마스크는 전부 손으로 정했다(원반, 부채, 정해진 속도의 병진·성장). 창발한 몸과의 결합은 안 했다. 이동 속도는 v=0.05px/스텝 하나뿐.
- 격자는 512²(입자 약 1.5만)가 대부분이고 1024²·10만은 1회(F05, 시드 1개, T=8000). 1500² 는 돌리지 않았다(코드가 2의 거듭제곱만 지원).
- 시드 1개뿐인 결론: B03, B04, C03~C05, D01~D03, D06, E01, E02, E05, F04, F05, F08, G03, G04.
- 게임 셰이더의 부가 규칙(입자별 SO/SA 변이, 스카우트, 추종, 압력, 복귀, 먹이 화학주성, 침착 맥동, trail 상한, 실패 시에도 침착)은 재현하지 않았다. "게임 trail"은 확산·감쇠·SO 만 맞춘 것이다.
- GPU 의 실제 순서(확산 뒤의 trail 을 읽어 감지 → 회전 → 이동을 한 패스에)와 Jones 순서(이동·침착 → 감지)의 차이는 시험하지 않았다. occupancy 를 2스텝마다 갱신하는 경우도 안 봤다.
- 맥동, 먹이 사이 관 형성(목표 5)의 정량 평가, 점액 기피는 다루지 않았다. 먹이 노드는 고정점으로만 썼다.
- 32000 스텝보다 긴 시간의 거동은 모른다.
- 공통 eval 의 "hierarchical" 판정은 접합부 뭉침 때문에 거의 모든 그물 실행에서 참이 된다. 굵기 위계의 근거로 쓰지 않았다.
- 입자 수 보존: 고정 N 실행(A, B, C, E, F, G, D02, D04, D05)은 입자 수가 정수로 정확히 보존된다(오차 0). D01, D03, D06 은 규칙상 입자 수가 변한다. 두께장이 없으므로 부피 보존에 해당하는 양은 입자 수뿐이다.
