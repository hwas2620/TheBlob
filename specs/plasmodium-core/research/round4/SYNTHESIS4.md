# 4차 실험 종합

작성: 2026-11-15, 주 세션. 워크플로 없이 주 세션이 직접 돌렸다. **독립 검증이 없다.**
3차 종합(`../round3/SYNTHESIS3.md`)이 남긴 문제 가운데 먹이 사이 관, 몸이 먹이에 머무르지 않음, 정맥 조각남, 큰 격자를 다뤘다.
실험 둘: F1(먹이와 수축 박자, 실행 88회, 192²·256²), G1(큰 격자, 실행 11회, 384²~768²).

## 0. 결론 먼저

1. **먹이 사이 관이 안 남던 원인을 찾았다.** 두 먹이 덩어리가 같은 박자로 맥동하면 서로 주고받는 흐름이 없어 관이 유지되지 않는다.
   박자가 어긋나면 관이 남는다. 180° 어긋나게 강제하면 시드 3개 모두 관이 남고, 같은 박자면 남지 않는다.
2. **수축 무늬가 움직이게 하면 세 문제가 함께 풀린다 (192² 격자, 시드 3개).** 몸 크기만 한 파장의 수축파를 넣고 방향을 천천히 돌리면
   먹이 셋의 9쌍이 모두 굵은 관으로 이어지고, 몸이 갈라지지 않으며, 굶은 채 이주할 때의 정맥 연결이 0.38~0.78 에서 0.85~0.88 로 오른다.
   다만 **이 수축파는 손으로 넣은 것**이고 스스로 생긴 것이 아니다.
3. **풀이는 768² 까지 버틴다.** 통합 모델이 768² 에서 처음 돌았다(유량 오차 중앙값 0.07, 음수 두께 0). 고친 젖음 판정도 768² 에서 듣는다.
4. **통과하지 못한 것이 있다.** 먹이 넷을 서로 다른 거리에 둔 긴 실행에서는 먼 먹이에 늦게 닿거나 닿지 못했고, 늦은 시점에 몸이 갈라졌다(가장 큰 몸 성분의 부피 0.67~0.89).
   큰 격자에서는 수축파가 정맥 연결을 고치지 못했다.
5. **굶은 큰 몸은 고리가 된다.** 부피 보존에서 나오는 거동이고 격자 크기 선택에 영향을 준다.

## 1. 먹이 사이 관 (F1)

### 원인
| 구성 (먹이 둘, 192², 먹는 동안) | 두 덩어리 두께 맥동의 상관 | 같은 정맥 성분 | 경로 최소 전도도 |
|---|---|---|---|
| 두께를 천천히 올리는 저장소 + 주입 (같은 박자) | +0.94 | 0.29 | 0.6 |
| 위와 같고 박자만 180° 어긋나게 (시드 1, 2, 3) | −0.83, −0.98, −0.75 | 1.00, 1.00, 1.00 | 594, 434, 286 |
3차의 N3 에서 "먹이 자리를 4배 두껍게" 했을 때 관이 남은 것은 두께가 갑자기 뛰는 충격으로 두 덩어리의 박자가 우연히 어긋났기 때문이었다.
그 충격이 음수 두께도 만들었다(먹이 원반 옆의 갓 젖은 셀이 한 스텝에 비워짐). 두께를 천천히 올리면 음수 두께가 사라지지만 박자가 같아져 관도 사라진다.

### 박자를 어긋나게 하는 방법
| 방법 | 결과 |
|---|---|
| 압력 되먹임(압력이 높으면 수축이 느려짐)으로 스스로 어긋나게 | 실패. 덩어리의 맥동 진폭이 0.21 → 0.01~0.07 로 죽는다 |
| 덩어리마다 박자 빠르기를 조금씩 다르게(40~80 시간단위에 한 바퀴 어긋남) | 듣는다. 먹이 셋 9쌍 모두 이어짐(시드 3개) |
| **몸 전체 수축파**: 수축 위상에 몸 크기만 한 파장의 기울기를 더하고 20주기에 한 바퀴 돌림 | 듣는다. 먹이 전용 규칙이 아니고 이주 중의 정맥 연결도 고친다 |

### 확인 배치 (수축파 + 고친 젖음 판정 + 멀티그리드, 192², 시드 3개)
| | 수축파 없음 | 수축파 있음 |
|---|---|---|
| 먹이 셋: 같은 정맥 성분인 쌍(9쌍) | 0.14~0.93 | 9쌍 모두 1.00 |
| 먹이 셋: 경로 최소 전도도 | 1~10 | 345~716 (정맥 중앙값의 9~27배) |
| 먹이 셋: 가장 큰 몸 성분의 부피(최소) | 0.34, 0.65, 1.00 | 0.98~0.99 |
| 먹이 셋: 정맥 최대 성분 | 0.33~0.74 | 0.96~0.98 |
| 이주: 정맥 최대 성분(중앙) | 0.48, 0.78, 0.38 | 0.87, 0.88, 0.85 |
| 이주: 순환 수 | 6~12 | 17~25 |
| 이주: 이동 거리(셀) | 63~70 | 74~77 |
먹이 둘 + 수축파(시드 2개): 같은 성분 1.00, 경로 최소 전도도 706~1213.
멀티그리드의 유량 오차 중앙값은 0.05~0.08 이다. 먹이 덩어리가 있으면 2사이클의 순간 오차가 0.5~1.0 까지 튀고 관이 직접 풀이보다 가늘다.
3사이클은 직접 풀이와 같은 굵기를 낸다(경로 최소 전도도 781~826 대 752~966).

### 왜 듣는가 (작성자 해석)
수축 무늬가 고정돼 있으면 왕복 흐름이 0 인 자리(마디)가 한곳에 머물고 정맥이 거기서 끊긴다. 무늬가 움직이면 마디가 옮겨 다녀 끊기지 않는다.
2차 E6 의 "방향이 바뀌는 파만 그물을 남긴다"와 같은 현상이다. 몸 길이에 연동파 한 파장이 걸린다는 관찰(Alim 2013)과 어긋나지 않지만,
실제 점균에서는 이 파가 스스로 생긴다. 여기서는 실험실 좌표에 넣어 준 것이다.

### 음수 두께
- 순유출 제한은 듣지 않는다(통과 유량이 큰 얇은 셀).
- 음수가 된 셀을 바로 말리고, 마르는 셀의 부피를 젖은 이웃에게 두께에 비례해 나누면 대칭 배치에서 스텝 끝 음수가 0~1 셀·스텝이 된다. 패스는 늘지 않는다.
- 먹이 덩어리의 두께 배율을 "그 셀이 찬 만큼만" 올리면 늦게 닿은 먹이에서 나던 큰 음수(−0.30)가 −0.006 으로 준다.
- 이웃이 없는 외딴 셀 한두 개에 −0.005 안팎이 남는다.

### 통과하지 못한 시험 — 먹이 넷, 거리 40~75, 256², T=700
| 실행 | 먼 먹이 둘(거리 75, 60)에 닿은 시각 | 가장 큰 몸 성분의 부피(끝) |
|---|---|---|
| 수축파, 시드 1 / 2 | 531, 610 / 닿지 못함 | 0.89 / 0.85 |
| + 찬 만큼만 두꺼워짐, 시드 1 / 2 | 536, 607 / 닿지 못함, 405 | 0.77 / 0.72 |
| 수축파 없음, 시드 1 | 526, 447 | 0.60 |
유인장이 반경 25셀짜리라 먼 먹이를 끌지 못한 것이 늦게 닿은 직접 원인이다(시험 설계의 한계). 몸이 갈라지는 것은 모델 쪽 결함이다.

## 2. 큰 격자 (G1)

| | 384² | 512² | 768² |
|---|---|---|---|
| 유량 오차 중앙 / 최대 (2사이클 + 외삽) | 0.066 / 0.18 | 0.074 / 0.30 | 0.068~0.070 / 0.29~0.33 |
| 음수 두께 스텝 | 0 | 0 | 0 |
| 윤곽의 대각/축 비 (고친 젖음 / 원래) | 0.96 | 0.96 | 0.94 / 1.14 |
| 정맥 셀의 90% 가 가장자리에서 이 거리 안 | 14셀 | 35셀 | 48셀 |
| 몸 반지름 | 130셀 | 181셀 | 265셀 |
| 정맥 최대 성분 | 0.41 | 0.28 | 0.12~0.14 |

- 풀이와 고친 젖음 판정은 768² 까지 문제가 없다.
- 굶은 채 사방으로 퍼지는 몸은 가장자리 띠만 살아 있는 고리가 된다. 총 부피가 일정하므로 살아 있는 넓이가 V/0.45 로 고정되고, 반지름 R 까지 퍼지면 띠의 폭이 V/(2πR·0.45) 가 된다.
  192² 실행도 같은 단계에서는 가운데가 말라 있었다. 크기에 따른 새 결함이 아니라 같은 거동이다.
- 늙는 시간을 격자에 비례시켜도, 수축파를 넣어도 띠의 폭은 그대로다. 늙는 시간을 늘리면 한쪽으로 쏠리는 것은 빨라진다.

## 3. spec 에 반영할 것

규칙 (전부 "보고됨, 작성자 실험")
1. 규칙 2: 수축에 쓰는 위상에 몸 전체 수축파를 더한다.
2. 규칙 6: 막다른 끝부터 마른다. 음수가 된 셀은 바로 마른다. 마르는 셀의 부피는 이웃에게 두께에 비례해 나눈다.
3. 규칙 8: 먹이 덩어리의 쉬는 두께가 천천히(찬 만큼만) 4배까지 오른다.
4. 풀이: 먹이 덩어리가 있으면 3사이클.

0단계 기준
- B3: 수축파가 있으면 192² 에서 통과 수준(0.85~0.88)이다. 큰 몸에서는 통과하지 못한다.
- B5: "같은 정맥 성분인 시간 ≥ 90%, 경로 최소 전도도의 중앙값 ≥ 정맥 중앙값의 5배, 가장 큰 몸 성분의 부피 ≥ 0.9"로 다시 정한다.
  대칭 먹이 셋은 통과(9쌍 중 8쌍이 10배 이상), 비대칭 먹이 넷은 불통과다.
- 격자 크기: 블롭의 지름이 65~110셀이 되게 잡는다.

## 4. 남은 문제

1. **독립 검증이 없다.** 4차의 결과는 전부 주 세션 혼자 낸 것이다.
2. **수축파가 손으로 넣은 것이다.** 파장(100)과 회전 주기(80)는 192² 의 몸 크기에 맞춘 값이고, 몸 크기에 따라 어떻게 바꿀지 정하지 못했다.
   수축파가 전진의 위상 잠금, 점액 기피, 절단 반응을 어떻게 바꾸는지 보지 않았다.
3. **비대칭·장시간 먹이 배치에서 몸이 갈라진다** (가장 큰 몸 성분의 부피 0.67~0.89).
4. **굶은 큰 몸이 고리가 된다.** 큰 격자에서 먹이 덩어리 규칙은 돌린 적이 없다.
5. 먹이 사이 관이 처음 닿은 길을 따른다. 짧아지는지 재지 않았다.
6. 정맥의 격자 정렬, 입자층, WebGL2 실측은 손대지 않았다.
7. 먹이 유인장이 고정 가우스다. 게임의 확산장으로 바꾸면 먼 먹이 도달이 달라질 수 있다.

## 5. 버린 것
순유출 제한, 얇은 셀 강성(전진면의 채움을 늦춤), 먹은 만큼만 쌓이는 저장소(관이 안 생김), 압력 되먹임(맥동이 죽음),
멀티그리드 계층 줄이기(3차 말에 확인: 유량 오차 0.105 → 0.246), 늙는 시간을 몸 크기에 비례시켜 고리를 없애기(띠 폭이 그대로).
