# G1 — 큰 격자 (384²·512²·768²)

작성: 2026-11-15, 주 세션.
**독립 검증: `verify/REPORT.md`** (같은 날, 하위 에이전트 1명. 384² 새 시드 재실행 3회 + 실행 11개의 저장 배열 재측정). 틀렸던 곳은 본문에 "정정"으로 표시했고 0절에 모았다.
코드: n1g.py (round3 의 n1.py 사본 + 고친 젖음 판정 + 임의 방향 구배 + 몸 전체 수축파), anaG.py (요약).
설정: E10 대표 설정(선형 구배, 결합 진동자 맥동), 초기 원반 반지름은 격자에 비례(N/16), 구배 방향 27°,
멀티그리드 2사이클 + 외삽 0.5(50스텝마다 직접 풀이와 비교), 고친 젖음 판정(rho 0.92, 가우스 σ=2). 실행 11회.
정정: 실행 11개는 전부 최조 격자 Jacobi 20회, float64 였다(적지 않았다). spec 이 전제하는 구성은 4회, float32 다.

## 0. 독립 검증 뒤의 정정
| 절 | 적었던 것 | 검증 결과 |
|---|---|---|
| 1 | 풀이는 768² 까지 버틴다 | **부분 확인.** 384² 는 새 시드에서 재현(0.066 / 0.113 / 0.199, 음수 0). spec 구성(Jacobi 4회, float32)으로도 0.067 이고 부피 오차는 1.8e-7. 768² 는 로그와 저장 배열을 다시 집계했을 뿐 재실행이 없다. 512²·768² 는 spec 구성으로 재지 않았다 |
| 2 | 고친 젖음 판정은 768² 에서도 듣는다 | **수치는 확인**(0.940·0.944 대 1.136). 그러나 둥글지는 않다. 축 방향이 6~9% 빠른 치우침이 남는다(세 격자 크기, 시드 4개에서 같은 부호). 원래 판정의 대각 과속 14% 를 2.4배 줄이며 부호를 뒤집은 것이다 |
| 3 | 고리, 살아 있는 넓이 V/0.45 | **확인**(평균 두께 0.43~0.47). 식의 띠 폭은 직접 잰 값과 −17%~+29% 범위에서 맞는다 |
| 3 | 늙는 시간을 바꿔도 띠의 폭은 그대로 | **틀림.** 512² 에서 19.5 → 30~31.5셀로 넓어진다. 그대로인 것은 살아 있는 넓이다 |
| 3 | 정맥 셀의 90% 가 가장자리에서 48셀 안 (종합과 spec 은 이것을 "띠 폭 약 50셀"로 옮겼다) | 띠 폭이 아니다. 768² 의 바깥 띠 폭은 직접 재면 25~26셀, 식으로 29~30셀 |

## 1. 풀이는 768² 까지 버틴다
| 실행 | T | 유량 오차 중앙 / p90 / 최대 | 음수 두께 스텝 | 부피 오차 |
|---|---|---|---|---|
| 768², 고친 젖음, 시드 1 | 800 | 0.068 / 0.101 / 0.331 | 0 | 8e-16 |
| 768², 고친 젖음, 시드 2 | 800 | 0.070 / 0.105 / 0.292 | 0 | 1e-15 |
| 768², 원래 젖음, 시드 1 | 800 | 0.088 / 0.125 / 0.426 | 0 | 8e-16 |
| 512², 고친 젖음, 시드 1 | 700 | 0.074 / 0.116 / 0.299 | 0 | 8e-16 |
| 384², 고친 젖음, 시드 1 | 600 | 0.066 / 0.130 / 0.182 | 0 | 5e-16 |
| 384², 늙는 시간 100 | 600 | 0.095 / 0.229 / 0.772 | 3 | 5e-16 |
통합 모델이 768² 에서 돈 것은 이번이 처음이다. 3차 종합의 "큰 격자" 위험 가운데 풀이 쪽은 닫혔다.
정정: 닫혔다고 하기에는 이르다. 768² 는 독립 재실행이 없고, GPU 구성(Jacobi 4회, float32)으로는 384² 만 쟀다.
늙는 시간을 2배로 한 384² 실행에서만 음수 두께가 3스텝 나왔다.

| 실행 | 대각/축 | 4차 성분 |
|---|---|---|
| 768², 고친 젖음, 시드 1 / 2 | 0.940 / 0.944 | 0.032, −1° / 0.030, 0° (격자 축에 정렬, 축이 김) |

384² 는 실행 끝에는 몸이 이미 100~120셀 이주한 초승달이라 끝 윤곽으로는 두 판정이 갈리지 않는다(0.947 대 0.948). 팽창기의 발자국으로 재야 한다.

## 3. 몸이 크면 고리가 된다
| 격자 | 몸 반지름(셀) | 정맥 셀의 90% 가 가장자리에서 이 거리 안 | 정맥 최대 성분 | 떨어진 몸 조각 수 |
|---|---|---|---|---|
| 384² (T=600) | 130 | 14 | 0.41 | 460 |
| 512² (T=700) | 181 | 35 | 0.28 | 500 |
| 768² (T=800) | 265 | 48 | 0.12~0.14 | 1388~1538 |
가장자리 띠만 살아 있고 안쪽은 마른 흔적이다. 띠 안의 정맥은 짧은 방사형 가지이고 서로 이어지지 않는다.

원인은 부피 보존이다. 먹이가 없으면 총 부피 V 가 일정하고 살아 있는 셀의 평균 두께가 약 0.45 이므로, 살아 있는 넓이는 V/0.45 로 고정된다.
몸이 사방으로 반지름 R 까지 퍼지면 띠의 폭은 V/(2πR·0.45) 가 된다(512²: 9651/(2π·145·0.45) = 23.5셀, 관측 16~41셀).
정정: 이 대조 예는 늙는 시간 133 실행의 값이고, "관측 16~41"은 정맥 셀의 가장자리 거리(중앙~90%)라 식을 시험하기에는 범위가 너무 넓다.
검증자가 광선을 쏘아 바깥 띠의 폭을 직접 쟀다(중앙값): 384² 20.0, 512² 19.5, 768² 25.0~26.0. 식의 값은 15~16, 19~20, 29~30 이다.
위 표의 "정맥 셀의 90% 가 이 거리 안"(48셀)은 안쪽에 남은 조각 때문에 부푼 값이고 띠 폭이 아니다.
192² 실행도 같은 단계에서는 가운데가 마른 덩어리였다. 크기에 따른 새 결함이 아니라 같은 거동이 크게 보이는 것이다.
- 정정: "늙는 시간을 격자에 비례시켜도(512² 에서 133, 384² 에서 100) 띠의 폭은 그대로다"라고 적었으나 **틀렸다.**
  512² 에서 늙는 시간 50 → 133 이면 바깥 띠 폭이 19.5 → 30.0~31.5셀이 된다(몸 반지름 173 → 135). 그대로인 것은 살아 있는 넓이(V/0.45)다.
  고리인 것은 같다(젖은 셀의 2% 만 안쪽 절반에 있다).
  대신 한쪽으로 쏠리는 것은 빨라진다(512²: 이동 43 → 65~87셀, 뒤가 굵은 구배 −0.09 → −0.14~−0.22).
- 몸 전체 수축파(파장 133~267)를 넣어도 띠의 폭은 그대로다(검증자 측정 19.5~21.5). 정맥 최대 성분은 0.28 → 0.27~0.48 이다(새 시드로 다시 돌리지는 않았다).
그림: m_tau_scaling.png, m_512_variants.png.

## 4. 뜻
- 굶은 채 사방으로 퍼지는 큰 몸은 이 모델에서 얇은 고리가 된다. 먹이가 없는 큰 몸의 모습은 실제(한쪽으로 쏠린 부채)와 다를 수 있다.
- 검증된 모습(시트 전진면 + 뒤따르는 정맥망)은 몸 지름이 살아 있는 넓이에서 나오는 크기(반지름 √(V/(π·0.45)))의 1~2배일 때의 것이다.
  게임에서 블롭이 화면에서 차지할 크기를 정하고, 그 지름이 65~110셀이 되게 격자 크기를 잡는 편이 안전하다(예: 지름 400px 이면 384² 격자).
- 먹이가 있으면 사정이 다르다. 주입이 부피를 늘리고 먹이 덩어리에서 전진면까지 줄기가 유지된다(F1). 큰 격자에서 먹이 실험은 하지 않았다.

## 5. 한계
- 실행 11회, 시드는 구성당 1~2개다. 768² 은 T=800 까지라 이주 단계에 들지 못했다.
- 풀이 구성이 spec 과 다르다(최조 격자 Jacobi 20회, float64). spec 구성으로는 검증자가 384² 한 번을 쟀다.
- 먹이 점원, 먹이 덩어리 규칙, 막다른 끝부터 마르는 규칙은 이 코드에 없다. F1 의 규칙을 큰 격자에서 돌린 적이 없다.
- 수축파의 파장과 회전 주기를 몸 크기에 어떻게 맞출지는 정하지 못했다.
