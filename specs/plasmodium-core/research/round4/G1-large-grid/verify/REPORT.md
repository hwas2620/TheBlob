## 1. 코드 읽기 (n1g.py)
- 토러스가 아니다. 가장자리 3셀 안쪽만 젖을 수 있는 경계 있는 격자 + 선형 먹이 구배(food_grad=1, 방향 27°). `sage`·먹이 원반·bridge_keep·neg_dry 는 없다(보고서 5절이 밝힘).
- 유량 오차 = 같은 상태(W, h, h*)를 직접 풀이로도 풀어 `‖Q_mg − Q_exact‖/‖Q_exact‖` (check_every 스텝마다). 직접 풀이는 점검에만 쓰인다.
- 음수 두께 스텝 = 유량 갱신 직후 젖은 셀의 최소 h < 0 인 스텝 수(마름·젖음 전). 엄격한 정의다.
- 부피 오차 = 5스텝마다 `|Σh − V0|/V0`. 주입이 없으므로 맞다.
- 수축파: `θ_eff = θ + (2π/λ)·((X−cx)cos α + (Y−cy)sin α)`, α = 2πt/T_rot, (cx, cy) 는 10스텝마다 갱신하는 h-무게중심. F1 과 같은 꼴.
- **실험 설정이 spec 의 GPU 구성과 다르다.** G1 실행 11개 모두 `nc=20`(최조 격자 Jacobi 20회), `dtype=f8`(float64) 이다(params.json).
  spec 의 "압력 풀이"와 "GPU 비용 추정"은 최조 격자 Jacobi 4회, RGBA32F 를 전제로 한다. F1(f1.py/mgt.py)은 nc=4, float64 였다.
  → "768² 에서 유량 오차 중앙 0.07"은 nc=20·float64 에서 잰 값이다. nc=4·float32 는 384² 새 시드로 아래에서 따로 쟀다.

- **spec 과 SYNTHESIS4 의 "768² 에서 반지름 265셀에 띠 폭 약 50셀"은 같은 문서의 식(29셀)과도, 내 측정(25~26셀)과도 맞지 않는다.**

- REPORT 의 대조 예 "512²: 9651/(2π·145·0.45) = 23.5셀, 관측 16~41셀"은 tau_a=133 시드 2 실행의 값이다(R 축 도달 142, 정맥 셀의 가장자리 거리 중앙 16.6·90% 40.6).
  "관측 16~41"은 범위가 넓어 식을 시험하지 못한다.

## 4. 발견한 문제
1. **설정 불일치**: G1 실행은 전부 nc=20, float64. spec 은 nc=4, RGBA32F 를 전제한다. 384² 에서 따로 재 보니 차이는 없었다(3절). 512²·768² 에서는 재지 않았다.
2. **띠 폭 숫자**: SYNTHESIS4·spec 의 "768² 에서 띠 폭 약 50셀"은 정맥 셀 거리의 90% 분위수(48)를 띠 폭으로 쓴 것이다. 같은 문서의 식으로 29셀, 직접 측정 25~26셀.
3. **"tau_a 를 바꿔도 띠 폭은 그대로"**: 그대로인 것은 살아 있는 넓이다. 띠 폭은 몸 반지름에 반비례해 달라진다(512²: 19.5 → 30).
4. **고친 젖음 판정의 남은 치우침**: 축 방향이 6~9% 빠르다. 384²·512²·768², 시드 4개에서 같은 부호. "768² 에서도 둥근 윤곽"(spec)은 "원래 판정보다 2.4배 작은, 반대 부호의 치우침"이 맞다.
5. anaG.py 의 "관측 16~41셀"은 정맥 셀의 가장자리 거리(중앙~90%)이고 띠 폭 식의 시험으로는 범위가 너무 넓다.
6. 384² 실행 끝(T=600)의 윤곽 비는 두 젖음 판정을 가르지 못한다(이주한 뒤라서). 384² 를 비교에 쓰려면 팽창기에 재야 한다.
