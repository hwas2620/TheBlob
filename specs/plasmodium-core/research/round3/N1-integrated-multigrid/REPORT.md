# N1-integrated-multigrid — E10 통합 모델의 압력을 E9 멀티그리드로 풀기

상태: 완료 (2026-11-13 06:10 UTC). 판정: partial. 총 계산 시간(벽시계, 동시 2프로세스) 약 35분.

## 1. 가설
E10 통합 모델의 차폐 푸아송 p_i/(κ·dt) + Σ_e W_e(p_i − p_j) = (h_i − h*_i)/dt 를 E9 의 멀티그리드
(PᵀAP/1.5, V(2,2), ω=0.8, 스텝당 1~2사이클 웜스타트)로 풀어도 희소 직접 풀이와 같은 형태(이주, 시트 전진면, 뒤가 굵은 정맥, 맥동)가 나오고 두께가 음수가 되지 않는다.

## 2. 계획 (위에서부터 차례로, 못 한 항목은 못 했다고 적는다)
1. e10.py, e9.py 복사(orig/). n1.py = e10.py 사본 + MG 풀이(numba 스텐실 커널, E9 커널 사본을 차폐 연산자용으로 고침).
2. 정적 점검: 직접 풀이 실행 중 저장한 상태 몇 시점에서 MG 사이클 수별 잔차·유량 오차(전체 간선 / C>100 간선), Jacobi 40·160 과 비교.
3. 동적 점검: 시드 3개 × (직접, MG 1사이클, MG 2사이클). 10스텝마다 같은 상태에서 직접 풀이를 따로 풀어 유량 오차 기록.
4. 음수 두께가 나오면 양수 보존 유출 제한(강화에 제한 전/후 유량), p–h 관계 위반 비율.
5. N=256, 384(가능하면 512), float32 1회.
6. 주기당 스텝 수 × 사이클 수 같은 예산 비교 1~2쌍, 자동 Q0 정규화가 폭주를 막는지(고정 Q0 대조).
7. 통과 기준 판정, GPU 패스 수 계산.

## 3. 모델 식 (E10 대표 설정 그대로. e10.py 의 식을 바꾸지 않았다)
격자 N×N, 8이웃 간선 4채널(E, N, NE, SE; 길이 1, 1, √2, √2). 셀: wet, h, age, θ, slime. 간선: C. 정적 잡음: G_e = exp(0.5·N(0,1)), 항복 잡음 η.
- 위상: dθ/dt = ω(1 + 0.1(1 − e^(−age/τ_a))) + D_θ Σ_{젖은 8이웃} w_j sin(θ_j − θ_i), 부분 스텝 4회.
- 쉬는 두께: h* = [h0 e^(−age/τ_a)(1 − (1 − h_fill/h0)e^(−age/τ_f)) + min(β√Cn, cap)]·(1 + ε cos θ).
- 압력: p_i/(κ dt) + Σ_e W_e (p_i − p_j) = (h_i − h*_i)/dt, W_e = G_e (C_e + r)/L_e.
- 유량·두께: Q_e = W_e (p_i − p_j), h_i ← h_i − dt Σ_e Q_e.
- 강화: dC_e/dt = rate((|Q_e|/Q0)^γ − C_e), Q0 = 0.2·(활성 간선 평균 |Q|^γ)^(1/γ).
- 마름, 젖음(두께 항복): e10.py 와 같음.
값: κ=20, h0=1, τ_a=50, τ_f=2, β=0.05, cap=0.5, hy0=1.05, σ_y=0.02, λ=0.06, y_s=0.5, h_fill=0.2, h_min=0.15, grace=2, γ=1.5, rate=0.05, D0=2, r=0.05, dt=0.1, 주기 4, ε=0.1, D_θ=8.8, y_c=0.2, food=(x−중심)/N.
강화 입력은 순간 |Q| (tauQ=0). 종합 문서 2.2·2.4절의 권장 모델이 저역 통과를 두지 않기 때문이다(E10 담당자 대표 실행 b3 는 tauQ=4 였다. 차이를 밝혀 둔다).
초기 조건: 반지름 12 원반, h=3 균일, age=0, 위상 0, 정맥 없음. 잡음은 위 정적 백색 3종뿐. 구조를 그려 넣지 않는다.

## 4. 멀티그리드 (이 실험에서 옮기는 것)
미세 연산자: A = M + L_W, M_ii = 1/(κ dt) (젖은 셀), L_W = 간선 가중 그래프 라플라시안. 마른 셀은 대각 0 → 비활성(값 0 고정, 이웃과 간선 없음).
- 평활: 감쇠 Jacobi ω=0.8, p_i ← (1−ω)p_i + ω (b_i + Σ W p_j)/D_i, D_i = M_i + Σ W.
- 제한: 2×2 자식 잔차의 합. 보간: 조대 보정을 젖은 자식에 그대로 더함(nearest).
- 조대 연산자: 매 스텝 재구성. W_c = (2×2 집합체 사이를 건너는 미세 간선 합)/1.5 (E9 의 PᵀAP/1.5).
  차폐(질량) 항은 두 가지를 시험한다: (A) M_c = Σ_자식 M /1.5 (전체 PᵀAP/1.5, E9 그대로), (B) M_c = Σ_자식 M (질량 항은 조각 상수 보간에서 정확하므로 과보정하지 않음).
- 사이클: V(2,2), 최조 격자(3² 또는 4²) Jacobi 20회. 스텝당 1 또는 2사이클, 이전 스텝 p 로 웜스타트.
- 새로 젖은 셀: 부피를 준 이웃(공여 셀)의 p 를 물려받음(e10.py 의 기존 규칙). 마른 셀: p=0.
- 고립 조각: 차폐 항 때문에 성분마다 유일해가 있어 E9 의 합 0 조건·섬 제거가 필요 없다(시험해서 확인할 것).
전부 고정 크기 국소 스텐실(9점) + 2×2 축소/확대라 프래그먼트 셰이더 패스로 옮길 수 있다(리드백 없음). 패스 수는 9절에서 센다.

**결합 안정성 조건(이 실험에서 새로 나온 것).** 반암시적 스텝에서 풀이를 스텝당 한 번만 돌리면 (g=h−h*, q=p/κ)의 한 모드는
q_n = ρ q_{n−1} + (1−ρ) g_n/(1+s), g_{n+1} = g_n − s q_n (s = κ·dt·λ, ρ = 그 모드의 사이클당 오차 배율)로 움직인다. 이 2×2 사상의 행렬식은 ρ, 대각합은 s→∞ 에서 2ρ 다.
0 ≤ ρ < 1 이면 항상 안정이지만 ρ < 0 (과보정이 오차 부호를 뒤집는 모드)이면 뻣뻣한 모드(s ≫ 1; 여기서는 κ·dt·W ≈ 20·0.1·2500 = 5000)에서 **ρ < −1/3 일 때 불안정**하다.
위 표가 이 문턱과 정확히 맞는다: 최소 고윳값이 −0.19 인 상태는 1사이클로 안정, −0.36·−0.38 인 상태는 1사이클로 발산, c=1.33(−0.19)·c=1.25(−0.12)는 같은 상태에서 안정. 2사이클은 배율이 ρ² ≥ 0 이라 안정하다.

배치 E 해석
- **유출 제한은 필요 없고 해롭다.** 자동 Q0 를 쓴 MG 실행 어디에서도 음수 두께가 나오지 않아 제한이 필요한 상황이 없었다. 제한을 켜면(임무에 적힌 정의: 셀 총유출 ≤ h/dt) 스텝의 68~74% 에서 평균 20~25셀이 걸리고 총 |Q| 의 5.7~5.9%(최대 34%)가 잘린다. 얇은 정맥 셀은 들어온 만큼 내보내는 통과 유량이 h/dt 보다 커서, 순유출이 0 이어도 걸린다.
  직접 풀이에 같은 제한을 걸어도(e_s1_exact_limpre, 6.5절 표) 스텝의 65% 에서 걸리고 유량의 12%(최대 50%)가 잘리며 Cmax 가 1645 → 4020, 평균 속도가 0.204 → 0.181 로 바뀐다. 즉 이 제한은 근사 풀이의 안전장치가 아니라 모델 자체를 바꾼다.
  p–h 관계(|h_new − h* − p/κ|) 위반 정맥 셀 비율: 0.3·h0 초과 = 제한 없음 0%(mg1, 최대 0.3%) / 제한 전 유량 강화 최대 3.2% / 제한 후 유량 강화 최대 2.3% / 직접 풀이+제한 최대 4.4%. 0.05·h0 초과(평균) = mg1 1.7%, mg2 0.2%, 제한 2.7~3.3%. E8 의 56~60% 같은 붕괴는 아니다.
  강화에 제한 전/후 유량: 유량 오차(0.306 대 0.313)와 버스트(1.23 대 1.14)는 같고, 형태 차이는 시드 1회로는 가를 수 없다(끝점 202 대 240, 총/순 5.38 대 2.88).

- **고정 Q0**: 자동 정규화를 끄면 직접 풀이도 다른 모델이 된다(Cmax 3449, 순환 53, 분기 233). 그 위에서 mg1 은 Cmax 5283(직접의 1.53배), **최소 두께 −25.5**(6스텝, 최대 109셀, 음수 부피 283)의 버스트를 냈다. mg2 도 Cmax 5265, 최소 두께 −0.49(1스텝 1셀, 6.7절 표). 자동 Q0 에서는 MG 실행의 Cmax 가 같은 시드 직접 풀이의 0.65~1.79배이고(N=192, mg1·mg2·mg2_b·mg3 14회; 5시드 평균은 차이 없음) 음수 두께가 없다. 즉 자동 Q0 는 근사 풀이의 전도도 과대와 음수 두께를 실제로 눌러 준다.

### 6.8 고윳값이 음수인 모드는 어디에 사는가 (modes.py, log_modes.txt)

가설 문장에 대한 판정: **partial.** "E9 의 멀티그리드(PᵀAP/1.5)"를 그대로 쓰면 발산한다. 질량 항을 과보정에서 빼는 수정이 필요하다. 그 수정 뒤 "스텝당 1~2사이클" 가운데 1사이클은 유량 오차와 안정 여유에서 불합격이고, 2사이클은 유량 오차 기준을 근소하게 통과하며 음수 두께 없이 같은 부류의 형태를 내지만 작은 체계적 차이가 남는다.

## 8. 어디서 깨지는가 (분리)
- **차폐 항**: E9 구성을 그대로 쓰면 발산하는 직접 원인. 조대 질량 항을 /1.5 하지 않으면 해결된다(6.1절).
- **h–p 의 뻣뻣한 결합 + 과보정이 부호를 뒤집는 모드**: 1사이클/스텝의 선형 불안정(ρ<−1/3). 직접 풀이 실행의 후기 상태 2개(t=300, 350)에서 동결 기하 발산으로 확인, 고윳값 문턱과 일치(6.2절). ε=0 이어도 발산하므로 진동 우변이 원인이 아니다.
- **전도도 대비 자체가 아니라 정맥 토막의 기하**: W 최대는 t=100 (6272)이 t=350 (1593)보다 크지만 최소 고윳값은 t=350 이 더 나쁘다(−0.38 대 −0.19). 음수 모드는 본체 안의 짧은 굵은 정맥 토막에 있다(6.8절). E10 의 "맥동을 켜면 정맥이 조각난다"는 결함이 풀이 안정성까지 나쁘게 한다.
- **진동하는 우변**: 불안정의 원인은 아니고 추적 오차의 크기를 정한다. 스텝당 우변 변화가 7~23% 이고, 동결 기하에서 ε 을 0 으로 하면 mg2 오차가 0.108 → 0.028 로 준다(t=350). 2사이클의 유량 오차 0.09~0.15 는 대부분 이 추적 지연이다. 시간 외삽 웜스타트(β=0.5)가 이것을 절반으로 줄인다. β=1 은 발산한다.
- **자유 경계(젖은 집합 변화)**: 동적 실행의 유량 오차 중앙값(mg2, 구간별 0.07~0.22)은 직접 풀이 실행 상태의 동결 기하 값(0.06~0.13)과 같거나 조금 크다. 유량 오차와 10스텝 사이 젖은 셀 수 변화의 순위 상관은 −0.19~+0.02 로, 젖은 집합 변화가 버스트를 만든다는 증거는 없다. 가장 큰 버스트는 시드 1 에서 초기(t=53~95, 몸이 하나의 덩어리이고 정맥이 빽빽할 때), 시드 2 에서 t=252~284, 시드 3 에서 t=290~337(최대 0.29)에 있다. 버스트의 원인은 분리하지 못했다.
- **고립 조각**: 몸 조각이 50~117개(192), 약 400개(384)여도 발산하지 않았다. 차폐 항이 성분마다 해를 정해 주므로 E9 의 섬 인공물(합 0 조건)은 생기지 않는다. 음수 모드도 고립 조각에 있지 않다.
- **새로 젖은 셀의 웜스타트**: e10.py 의 규칙(공여 셀의 p)을 그대로 썼다. 다른 값(0, 이웃 평균)과의 비교는 하지 않았다.

## 9. GPU 비용 (코드 구성에서 센 값. WebGL2 실측 없음)
MG 커널은 전부 9점 스텐실 gather(자기 간선 4채널 + 이웃 셀이 가진 간선 4개) 또는 2×2 축소/확대다. 리드백, 전역 연산, 희소 직접 풀이가 없다. 조대 연산자 재구성은 조대 텍셀마다 미세 2×2 블록과 그 바로 옆 텍셀의 W·M 을 읽는 한 패스다(W_c 4채널 + M_c 1채널이라 렌더 타깃 2개).
V(2,2) 한 사이클: 최조 격자 아래 레벨마다 Jacobi 2 + 잔차 1 + 제한 1(조대 크기, 조대 p 초기화 포함) + 보간 가산 1 + Jacobi 2 = 7 드로콜, 최조 격자 Jacobi nc 회.

| 항목 (스텝당) | 512² 드로콜 | 768² 드로콜 | 격자 풀스크린 환산 |
|---|---|---|---|
| 위상 갱신(부분 스텝 4회) | 4 | 4 | 4 |
| h*·우변·질량 마스크 | 1 | 1 | 1 |
| W 텍스처(간선 가중치) | 1 | 1 | 1 |
| 조대 연산자 재구성 | 7 | 8 | 0.33 |
| V(2,2) 1사이클 (nc=20 / nc=4) | 69 / 53 | 76 / 60 | 8.33 |
| 외삽 웜스타트 혼합(첫 평활 패스에 합칠 수 있음) | 0~1 | 0~1 | 0~1 |
| 유량·h·나이 갱신 | 1 | 1 | 1 |
| \|Q\|^γ 전역 평균(밉 축소) | 9 | 10 | 1.33 |

- 풀이만: 2사이클 = 드로콜 113(512², nc=4)~160(768², nc=20), 격자 풀스크린 17.0회 분량. 잔차와 제한을 한 패스로 합치면 사이클당 7~8개 더 준다.
- 격자 풀스크린 약 32회는 1500² 풀스크린으로 512² 에서 3.8회, 768² 에서 8.5회 분량이다(면적비 0.117, 0.262). 채우기 비용은 "프레임당 풀스크린 60회" 안이다. **드로콜 수는 136~184 로 60 을 2~3배 넘는다.** 조대 레벨 패스는 채우기가 거의 없지만 FBO 전환 비용은 실측해야 안다.
- 유출 제한 패스는 넣지 않는다(6.4절).
- 마름·젖음·밉 축소의 패스 수는 E7/종합 문서의 추정을 그대로 옮긴 것이고 이 실험에서 다시 세지 않았다.

## 14. 한계와 확인하지 못한 것
- WebGL2 로 옮겨 돌리지 않았다. 패스 수는 numpy/numba 코드 구성에서 센 값이고 프레임 시간은 모른다.
- float32 실행은 상태 배열과 MG 배열이 float32 이지만 직접 풀이 점검과 일부 누적 통계는 float64 다. 2회(192², 512²)뿐이다.
- N=512 는 1회, T=300, 직접 풀이 기준선 없음, 이주 단계 전이다. N=384 와 256 은 시드 1 뿐이다. 768² 는 돌리지 않았다(레벨 수만 셌다).
- 형태 비교는 시드 5개의 짝 비교다. 차이의 방향은 일관되지만 표본이 작고 다중 비교 보정을 하지 않았다. mg1 은 시드 3개다.
- 강화 입력은 순간 |Q| 다(tauQ=0). E10 담당자 대표 실행의 저역 통과(tauQ=4)에서는 돌리지 않았다.
- 구배 방향은 +x 하나뿐이다(27°·45° 회전 없음). 격자 잠김은 직접 풀이와 MG 가 같은 수준이라는 것만 봤다(현 비율 0.27~0.42 대 0.32~0.42).
- Strahler 차수는 최대 C 신장 숲에서 직접 정의한 값이고(4~6), 유량 방향 그래프의 정식 차수가 아니다. 현 방향 지표도 10간선 조각으로 직접 정의했다.
- 버스트(유량 오차 최대 0.3~0.8)의 원인, mg2 의 형태 편향의 원인, 새 셀 웜스타트 값의 영향은 분리하지 못했다.
- 유출 제한은 임무에 적힌 총유출 기준 한 가지만 시험했다. 순유출 기준 제한은 시험하지 않았다.
- 무구배, 점 먹이, 토러스 장시간, 절단은 이 실험의 범위 밖이다.
- 자동 Q0 를 한 프레임 늦은 값으로 써도 되는지는 시험하지 않았다.
- 계산 시간: 벽시계 약 35분(동시 2프로세스). 그 가운데 약 5분은 스레드 경합으로 낭비됐다.

## 15. 다음 단계 제안
1. 0단계 프로토타입의 풀이는 "간선 /1.5 + 질량 정확, V(2,2), 스텝당 2사이클, 최조 격자 Jacobi 4회, 외삽 웜스타트 β=0.5(선택)"로 시작한다. 1사이클은 쓰지 않는다.
2. 드로콜을 줄이는 길을 실측으로 고른다: 조대 레벨을 아틀라스 한 장에 모아 FBO 전환을 줄이기, 잔차+제한 합치기, 스텝을 2프레임에 한 번.
3. 정맥이 토막 나지 않게 하는 대책(N3)이 풀이 안정 여유도 넓히는지 본다(최소 고윳값을 지표로).
4. mg2 의 "몸이 8% 길고 가지가 10% 적다"는 편향의 원인: 꼬리(늙은 가는 정맥)의 유량 오차를 따로 재고, 3사이클에서 사라지는지 시드 5개로 확인한다.
5. 음수 두께 안전장치가 필요하면 총유출이 아니라 순유출 기준(h + dt·유입 − dt·유출 ≥ 0)으로 설계해 직접 풀이를 바꾸지 않는지부터 확인한다.
