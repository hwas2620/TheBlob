# N3-food-trunk-connect — 점 먹이 저장소, 줄기, 먹이 사이 관 (3차 수치 실험)

상태: 완료 (2026-11-13). 실행 41회(스모크 1회 포함), 계산 시간 합계 2448초(40.8분, 각 실행 runtime 합). 판정: partial.

## 1. 가설
- H1. 점 먹이를 "늙지 않는 저장소"(변형: 유한한 양의 부피 주입)로 두면 저장소에서 전진면으로 이어지는 연결된 줄기가 생긴다(E1 의 점 소스 조건이 통합 모델 E10 안에서 재현된다).
- H2. 몸이 닿은 두 먹이 사이 경로가 굵은 관(C 중앙값이 전체 정맥 중앙값의 10배 이상)으로 50주기 이상 남는다.
- H3. E10 에서 뒤쪽 정맥이 굵어진 원인은 관 부피항 min(β√C, cap)에 곱한 맥동(pulse_tube=1)이다("상류라서 굵다"가 아니라 "오래돼서/스스로 펌프라서 굵다").

## 2. 모델 (e10.py 를 n3.py 로 복사해 고친 것. 직접 희소 풀이 그대로)
E10 규칙 1~7 은 그대로 둔다(κ=20, h0=1, τ_a=50, τ_f=2, β=0.05, cap=0.5, hy0=1.05, σ_y=0.02, λ=0.06, y_s=0.5, h_fill=0.2, h_min=0.15, grace=2, γ=1.5, rate=0.05, D0=2, r=0.05, dt=0.1, 주기 4, ε=0.1, D_θ=8.8, y_c=0.2, Q0 자동 0.2, 간선 잡음 σ=0.5, 순간 |Q| 강화).
바꾼 것:
1. 토러스: 내부 마스크와 경계 정지를 없앴다. 모든 이웃 연산은 np.roll(주기). 무게중심은 최소 이미지로 풀어 누적한다.
2. 먹이장(주기적 점원): c(x) = Σ_k a_k Σ_{3×3 이미지} exp(−|x − x_k − nN|² / (2σ_c²)), σ_c = 25셀(기본), a_k = 1. 선형 구배 없음. 젖음 문턱에는 E10 과 같이 −y_c·c 로만 들어간다(전용 규칙 없음).
3. 저장소(reservoir=1): 먹이 원반(반지름 food_r=4셀) 위의 젖은 셀은 노화 나이 sage 가 늘지 않는다. h* 의 수축 항은 exp(−sage/τ_a), 채움 항은 exp(−age/τ_f) 로 나눠서(원본은 나이 하나) 먹이 위 셀이 h*=h0 를 유지한다. reservoir=0 이면 sage=age 로 원본과 같다.
4. 소비·주입: 먹이 k 의 남은 양 M_k. 젖은 먹이 셀 하나가 단위 시간에 eat 만큼 먹고, 그 셀의 h 에 gain·eat·dt 를 더한다(gain=0 이면 주입 없는 유한 저장소). M_k=0 이 되면 저장소 효과가 꺼지고(셀이 다시 늙는다) 그 먹이의 유인장 진폭 a_k 가 exp(−(t−t_k)/τ_fade) 로 사라진다.
   질량 검사는 Σh − (V0 + 누적 주입량).
5. 조각남 대책(선택):
   - bridge_keep=1 (막다른 끝부터 후퇴): 마름 후보 셀은 3×3 고리의 젖은 이웃이 8연결로 한 덩어리일 때만 마른다(Yokoi 8연결수 ≤ 1). 2×2 색칠 4부분장으로 한 스텝에 한 색만 마르게 해 인접 셀 동시 제거를 막는다. 구멍 생성은 허용한다. 3×3 스텐실이라 셰이더 한 패스다.
   - tube_keep=Ck: 인접 간선 최대 전도도 Cn > Ck 인 셀은 마르지 않는다(굵은 관은 늦게 마름).
   - bridge_keep 의 예외: 다리 셀이라도 Cn < bridge_break(=1, 새 시트 전도도 D0=2 의 절반) 이면 마른다(전도도가 다 죽은 유령 다리 제거).
5b. 두꺼운 저장소(h_res, 가설 밖의 탐색 변형): 살아 있는 먹이 원반 위 셀의 쉬는 두께를 h0 대신 h_res·h0 로 둔다(먹이 위에 원형질이 모인다). h_res=1 이면 꺼짐.
6. 측정용 상태: 간선 나이 eage, 창(5주기) 평균 부호 있는 유량 Qmean 과 절대 유량 Qgross.

## 3. 지표 (전부 네이티브 간선 그래프, graphm.py)
- 정맥 간선 = C > 4 (= 2·D0, E10 검증자와 같은 문턱). 최대 연결 성분 비율(간선 수 기준), 성분 수, 끝점(차수 1), 분기 노드(차수≥3), 순환 수 E−V+comp.
- Strahler: 최대 성분의 최대 C 신장 나무를 저장소(없으면 최대 C 노드)에 뿌리 두고 계산.
- 위치–log C Spearman(뒤 0 → 앞 1, 축 = 무게중심 변위 방향과 먹이 방향 둘 다), 간선 나이 구간별 C 중앙값.
- "오래됨 대 상류" 분리: Spearman(logC, 간선 나이), Spearman(logC, log|Qnet|), Spearman(logC, log Qgross), 부분 상관, 구간별 gross/net, 진행축에 수직인 단면 6개의 순유량 집중도(n80 = 순유량의 80% 를 나르는 간선 수, 최대 간선 몫).
- 격자 방향: 분기·끝점 사이 정맥 현(길이 ≥5) 길이 중 격자 방향 ±7.5° 비율(등방 0.333).
- 먹이: 접촉 시각, 먹이 쪽/옆/반대쪽 새 젖음 수 시계열, 저장소 경계를 나가는 순유량·전도도, 저장소 중심 고리별 정맥 수와 C, 저장소를 포함한 정맥 성분이 전진면(나이<10 셀)에 닿는 비율.
- 먹이 둘: 모든 젖은 간선에 저항 L/(G(C+r)) 을 준 Dijkstra 최소 저항 경로의 C 중앙값 / 전체 정맥(C>4) C 중앙값, 경로 최소 C, 두 먹이가 같은 정맥 성분인지. 20 시간단위(5주기)마다 기록.
- 머무름: 모든 먹이 접촉 뒤 젖은 면적, 몸 성분 수, 최대 성분 부피 비율, 먹이 원반 반지름 3배 안의 부피 비율.

해석
1. **pulse_tube 는 굵기 구배의 원인이 아니다.** pulse_tube=0 에서도 Spearman 이 −0.38~−0.50 으로 pulse_tube=1 (−0.43~−0.52)과 같다(4쌍 차이 평균 0.03, 시점 간 흔들림 ±0.05 보다 작다). 가설 H3 은 문구대로는 틀렸다.
   관 맥동이 하는 일은 가장 오래된 정맥(나이 100 이상)의 C 를 0.96~1.8배 키우는 정도다(t=256, 100-200 구간 41.8 대 43.6, 64.2 대 39.8 / 200+ 구간 71 대 40, 24 대 22).
2. 맥동 자체(나이 항의 맥동만으로도)는 구배를 −0.21~−0.28 에서 −0.38~−0.52 로 키운다. 원인은 왕복 유량이다: 맥동 실행에서 총/순 유량 비가 간선 나이와 함께 1.04 → 3~5 로 올라간다. 강화는 순간 |Q|(= 총유량)를 따르므로 오래된 정맥이 순유량에 비해 굵어진다(부분상관 (나이|Qnet) 0.47~0.61, 맥동 없으면 0.14; (나이|Qgross) 는 −0.14~0.13 으로 사라진다).
3. **"상류라서 굵다"도 성립한다.** 모든 실행에서 C 는 순유량을 따른다(Spearman 0.74~0.83, 나이를 통제한 부분상관 0.77~0.86). 맥동이 없어도 구배는 음수(−0.21~−0.28)이고, 순유량이 뒤로 갈수록 소수 간선에 모인다(n80: 앞 20~44 → 뒤 2~4, 최대 간선 몫 0.09 → 0.5).
   다만 줄기 한 가닥이 나르는 순유량과 그 C 는 몸 가운데(f=3/6~4/6)에서 최대이고 맨 뒤에서는 다시 준다. 즉 구조는 "뒤에서 모여 가운데서 가장 굵고 앞에서 갈라지는" 삼각주형이다. E10 에서 관측된 음의 Spearman 은 (앞쪽에 가늘고 젊은 정맥이 많다) + (오래된 정맥에 왕복 유량이 얹힌다)의 합이다.
4. 정맥 조각남의 원인은 맥동 일반이 아니라 **결합 진동자 위상(osc)** 이다. uniform 과 맥동 없음은 네이티브 최대 성분 0.90~0.99, osc 는 0.42~0.96 을 오간다. osc 실행의 20 시간단위 간격 시계열을 보면 0.46 ↔ 0.86 을 번갈아 찍는다: 정맥망이 큰 줄기 계통 2개로 되어 있고 둘을 잇는 고리 하나가 문턱(C=4) 근처에서 깜빡인다.
   두 계통은 앞쪽 시트(h>0.5)로는 항상 이어져 있다: "정맥 간선 ∪ 시트 내부 간선" 그래프의 최대 성분(largest_ws)은 모든 실행·시점에서 0.95~0.99.
5. 먹이 반대쪽 전진면: t>40 부터 접촉까지 반대쪽 60° 원뿔(무게중심 기준 cos<−0.5)의 새 젖음은 0셀(예: 시드 1 osc+pt1 에서 먹이쪽 300 전후 / 옆 60~150 / 반대 0, 20 시간단위마다).

- **두꺼운 저장소 + bridge_keep 에서만 먹이 사이 관이 남는다.** 세 시드 모두 두 먹이가 창 전체에서 같은 정맥 성분이고(100%), 네이티브 최대 성분은 모든 표본에서 ≥0.8(중앙값 0.96), 최종 그림(m_F2_hres_final.png 아랫줄)은 두 먹이를 잇는 굵은 관 하나와 약간의 잔가지다. 경로의 C 중앙값은 141~943(새 시트 전도도 D0=2 의 70~470배)로 창 내내 유지된다.
- 그러나 "정맥 중앙값의 10배" 기준은 경계선이다: 창 중앙값 9.98 / 11.8 / 16.9, ≥10 표본 48~64%, 10배 이상 연속 유지는 60 / 120 / 140 시간단위(15 / 30 / 35주기)로 50주기(200)에 못 미친다. T=720 장시간(시드 1 한 번)에서도 최장 100.
  비가 떨어지는 구간은 경로가 가늘어져서가 아니라 분모가 커져서다: 가는 정맥이 사라지면서 전체 정맥 중앙값이 14 → 48(시드 1), 22 → 270(시드 2), 22 → 134(시드 3)로 오른다. 망이 관 하나로 가지치기될수록(시드 1 t=600: 정맥 간선 171개 중 경로가 54개) 이 상대 기준은 뜻을 잃는다.
- 이 관은 교류 관이다. 경로 간선의 창 평균 순유량 0.04~2.0, 총유량 3.6~27.5, 총/순 2.5~413(늦은 시점일수록 순유량이 0 에 가깝다). 맥동을 끄면(1회) 몸이 t=80 부터 얼어붙고(면적 1934 고정) 경로 최소 C 가 정맥 중앙값의 3배 → 0.02배로 단조 감소한다.
- bridge_keep 없이 두꺼운 저장소만 쓰면 시드 2·3 에서 두 번째 먹이에 닿자마자 몸이 둘로 갈라진다(젖은 경로 있음 0.14~0.21).
- **결함: 음수 두께.** h_res=4 실행 8회 전부에서 최소 두께 −0.22~−0.49 (실행 끝 상태에는 음수 셀 0). 저장소의 왕복 부피(ε·h_res·81셀 ≈ 32, 유량 진폭 약 50/시간)가 얇은 관 셀을 빨아 0 아래로 내린다. 질량 오차는 5e-16 이하.
- 머무름: 부피의 약 50% 가 두 먹이 위에 머문다(T=720 내내 0.45~0.52). 나머지 절반은 여전히 바깥으로 나가는 얇은 전진면에 있고, 일부는 본체에서 떨어져 나간다(최대 몸 성분 부피 0.55~0.83).

## 6. 통과 기준 판정
기준: "네이티브 최대 성분 ≥ 0.8 과 먹이 사이 경로 C ≥ 전체(정맥) 중앙값의 10배가 시드 3개 중 2개 이상". 창 = 두 먹이 접촉 뒤부터 T 까지(20 시간단위 간격). 두 가지로 읽어 둘 다 적는다.
(가) 창 중앙값 기준: 최대 성분 중앙값 ≥0.8 이고 경로 비 중앙값 ≥10. (나) 유지 기준: 최대 성분 중앙값 ≥0.8 이고 비≥10 이 200 시간단위(50주기) 이상 연속.

| 구성 | 시드별 최대 성분 중앙값 | 시드별 경로 비 중앙값 | 시드별 비≥10 최장 연속 | (가) | (나) |
|---|---|---|---|---|---|
| 저장소 (가설 원문) | 0.49 / 0.61 / 0.60 | 4.2 / 1.2 / 3.5 | 0 / 0 / 80 | 0/3 불통과 | 0/3 불통과 |
| 저장소 + 주입 (가설 원문 변형) | 0.48 / 0.86 / 0.47 | 7.5 / 5.3 / 7.3 | 80 / 120 / 140 | 0/3 불통과 | 0/3 불통과 |
| 저장소 + bridge_keep | 0.50 / 0.49 / 0.45 | 5.8 / 3.9 / 3.4 | 20 / 0 / 80 | 0/3 불통과 | 0/3 불통과 |
| 저장소 + tube_keep (시드 1만) | 0.56 | 7.0 | 60 | 0/1 | 0/1 |
| 두꺼운 저장소 | 0.95 / 0.56 / 0.50 | 5.8 / 0 / 0 | 40 / 0 / 0 | 0/3 불통과 | 0/3 불통과 |
| 두꺼운 저장소 + bridge_keep (가설 밖 탐색) | 0.96 / 0.97 / 0.96 | 9.98 / 11.8 / 16.9 | 60 / 120 / 140 | 2/3 (경계선: 셋째가 9.98) | 0/3 불통과 |

- 가설 원문 구성(저장소, 저장소+주입)은 어느 읽기로도 불통과.
- 가설 밖의 "두꺼운 저장소 + bridge_keep"은 최대 성분 기준은 3/3, 경로 비는 창 중앙값으로 2/3 이지만 50주기 연속 유지는 0/3, 그리고 음수 두께 결함이 있다. 통과로 치지 않는다.
- 최대 성분만 보면(먹이 1개): 저장소 9회 중 7회가 접촉 후 중앙값 ≥0.8 (0° 1/3, 27° 3/3, 45° 3/3), 저장소+주입 3/3 (0.81~0.86).

가설별 판정
- H1 (저장소 → 전진면으로 이어지는 연결된 줄기): **주입이 있으면 성립**(직류 점 소스 나무, 3/3 시드). 주입이 없으면 줄기는 생기지만 순유량이 아니라 맥동의 왕복 유량이 만든다(맥동을 끄면 사라짐, 1회).
- H2 (먹이 둘 사이 경로가 굵은 관으로 남는다): **가설 원문 구성에서는 틀렸다.** 관은 15~35주기 안에 가늘어지고 몸이 두 군체로 갈라지기도 한다. 먹이 위에 부피를 모으는 규칙 + 막다른 끝부터 후퇴를 더하면 관이 남는다(3/3 시드에서 같은 정맥 성분 100%, 1회는 160주기까지 확인).
- H3 (뒤쪽이 굵은 원인은 관 부피항 맥동): **틀렸다**(5.1).

## 9. GPU 비용 (추정, 실측 없음)
- 이 실험에서 더한 규칙은 전부 3×3 국소 스텐실이다. 저장소(노화 동결, h_res)와 주입은 기존 h*·두께 갱신 패스 안의 분기, bridge_keep 은 마름 패스 안에서 8이웃 wet 을 읽어 Yokoi 수를 세는 것(텍스처 읽기 약 12회 추가, 2×2 색칠은 프래그먼트 좌표 홀짝)이라 **추가 풀스크린 패스는 0**이다.
- 추가 상태: 노화 나이 sage 1채널, 먹이 양 1채널(게임의 기존 food 채널). 간선 나이 eage 와 창 평균 유량은 측정용이라 필요 없다.
- 고칠 점: 여기서는 먹이마다 남은 양 M_k 를 스칼라로 뒀다(젖은 먹이 셀 수 합산 = 리드백 또는 밉 축소 필요). GPU 에서는 셀별 먹이 밀도를 각 셀이 국소적으로 먹는 꼴로 바꿔야 한다(미시험). 유인장은 고정 가우스 대신 먹이 밀도의 확산장(기존 food 확산 패스)으로 대체해야 한다(미시험).
- 압력은 여전히 전역 풀이가 필요하다. 이 실험은 전부 CPU 희소 직접 풀이다. 스텝당 비용은 종합 문서의 추정(격자 풀스크린 19~26회, 드로콜 90~115)에서 달라지지 않는다. 두꺼운 저장소의 큰 왕복 유량(진폭 약 50)과 전도도 대비(C 최대 800~2400 대 r=0.05)를 멀티그리드가 감당하는지는 모른다.

## 11. 초기 조건·잡음·한계
- 초기 조건: 중심의 반지름 12 원반, h=3 균일, age=0, 위상 0, 정맥 없음. 잡음은 E10 과 같은 정적 백색 3종. 먹이는 가우스 유인장(σ_c=25, 진폭 1)과 원반(반지름 4, 두꺼운 저장소 실행은 5)뿐이고 정맥이나 경로는 그려 넣지 않았다.
- N=192, 몸 부피 1344(주입 실행 1944~2144), 직접 풀이, float64 뿐이다. 시드는 구성당 최대 3개다.
- 네이티브 최대 성분은 20 시간단위마다 0.45 ↔ 0.9 를 오가는 실행이 많다(줄기 계통 둘을 잇는 고리 하나가 문턱에서 깜빡임). 중앙값과 ≥0.8 표본 비율을 함께 적었다. 시트를 통한 연결(largest_ws)은 기준에 없는 보조 지표다.
- Strahler 는 유량 방향 그래프가 아니라 최대 C 신장 나무에서 계산했다(순환을 끊은 값).
- 경로 비의 분모는 정맥(C>4) 중앙값이다. 모든 젖은 간선의 중앙값(0.1~1.2)으로 나누면 비는 수백~수천 배가 되어 변별력이 없다.
- 두꺼운 저장소 변형은 가설에 없던 규칙이고 h_res=4, food_r=5 한 점만 시험했다. 음수 두께가 난다. 맥동 위상이 두 저장소 사이에 왕복 유량을 만드는 조건(동위상/역위상)은 측정하지 않았다.
- 전진면의 격자 이방성은 그대로다(같은 거리에서 대각선 접촉이 1.7배 빠름).
