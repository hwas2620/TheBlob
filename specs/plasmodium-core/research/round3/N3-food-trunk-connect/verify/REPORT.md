## 1. 그림 확인 (Read 로 직접 연 것: m_F2_hres_final, m_F2_hres_bk_s1_T720_time, m_B_final, m_A_mid, m_C_time_s1, m_F2_res_s1_time + 내 재실행 v_m_V1.png, v_m_V2.png)
- 먹이 1개(B, C): 부채꼴 전진면 + 뒤의 분기 정맥망은 보인다. 전진면 윤곽은 팔각형이고 몸 대부분은 마른 점액 자국(갈색)이다. 저장소가 있으면 몸이 먹이를 중심으로 사방으로 퍼진다.
- 먹이 2개, 두꺼운 저장소+bridge_keep: 끝 상태는 "먹이 원반 둘 + 그 사이 관 하나 + 잔가지 조금"이고, 얇은 노란 전진면 조각들이 관과 떨어져 바깥으로 계속 나간다. 내 새 시드 2회(먹이 위치를 바꾼 것 포함)도 같은 그림이다.
- 관은 구불구불하고(아래 4절: 직선 간격의 1.4~2.4배 길이) 한번 정해지면 움직이지 않는다. 격자 축·대각선에 붙은 긴 직선 정맥은 보이지 않는다.
- 가장 좋은 시드만 보여 준 흔적은 없다(대표 폴더는 경로 비가 가장 낮은 시드 1, 몽타주는 3시드 전부).

## 2. 코드 검토 (n3.py)
- 먹이는 젖음 문턱의 `- y_c*food` 항(가우스 유인장, σ=25)과, 먹이 원반 위의 노화 동결(`sage += dt*(1-resmask)`)·쉬는 두께 배율(h_res)·주입(`h[m] += gain*amt/n_`)으로만 들어간다. 먹이 쪽으로 부피를 옮기는 전용 이동, 경로·정맥을 그려 넣는 코드는 없다. 새 간선의 C 는 D0(1±0.3) 잡음뿐이다.
- 보고된 식과 코드가 일치한다(h*, 주입, bridge_keep 의 Yokoi 수와 2×2 색칠, tube_keep).
- 보존: 유량은 간선 반대칭으로 더하고 빼며, 마름은 남는 이웃에 나눠 주고, 젖음은 공급 셀에서 뺀다. 내 재실행의 float32 덤프에서 |Σh−(V0+주입)|/V0 ≤ 2.5e-9 (float32 반올림 수준), 마른 셀의 h≠0 은 0개.
- 음수 두께를 막는 장치가 없다. 암시적 풀이가 h_new = h* + p/κ 를 그대로 쓰므로 강한 흡입에서 h<0 이 된다. bridge_keep 은 h<h_min 인 다리 셀을 젖은 채로 남긴다(시드당 18만~25만 셀·스텝).
- 손으로 넣은 것: 유인장(고정 가우스), 먹이 원반(반지름 4~5), h_res=4 배율, bridge_keep 규칙. 관의 위치는 심지 않았다.

### 3.3 굵기 구배 원인 분리 (d)
- pulse_tube=1 − pulse_tube=0 의 Spearman 차이(C>4), 시드 1·2(담당자) + 시드 3(내 재실행), 시점 7쌍: +0.043, −0.063, −0.026, −0.046, −0.055, −0.041, −0.027. 평균 −0.031, 표준편차 0.035. osc 실행들 사이의 시드·시점 표준편차는 0.047 이다. 즉 pulse_tube 의 기여는 있어도 전체 구배(−0.46)의 7% 정도이고 편차 안이다. "원인이 아니다"는 유지된다.
- 맥동 유무 차이(C>4): osc 평균 −0.455(표준편차 0.047, 8개) 대 맥동 없음 −0.256(4개). 편차의 4배다.
- 그러나 구배 자체가 문턱에 의존한다. C>10 에서는 osc −0.23, 없음 −0.09. C>30 에서는 osc −0.11(표준편차 0.10), 없음 −0.04 로 0 과 구분되지 않는다. "뒤가 굵다"는 주로 앞쪽에 가는(C 4~10) 젊은 정맥이 많다는 뜻이고, 굵은 줄기끼리 비교하면 뒤가 더 굵지 않다.

## 5. 통과 기준 재판정
기준: 네이티브 최대 성분 ≥0.8 과 먹이 사이 경로 C ≥ 정맥(C>4) 중앙값의 10배가 시드 3개 중 2개 이상.
- 가설 원문(저장소): 불통과 0/3 (재계산 일치).
- 가설 원문 변형(저장소+주입): 불통과 0/3 + 내 시드 1개도 불통과(0.50, 7.4).
- 두꺼운 저장소+bridge_keep(가설 밖): 최대 성분 5/5 시드(담당자 3 + 내 2), 문턱 4·10·30 모두. 경로 비 중앙값(담당자 분모) 9.98/11.85/16.86/12.5/7.1 → ≥10 은 3/5. 10배 50주기 연속은 0/5. 경로 밖 분모로는 내 2시드 모두 중앙값 ≥10(42, 23.6)이고 연속 280/200.
  즉 "경계선"이라는 담당자 서술은 맞고, 판정이 분모 정의에 달려 있다. 관 자체는 접촉 뒤 260 단위(65주기) 이상 5/5 시드에서 유지된다(경로 C 중앙값: 담당자 시드 141~943, 내 시드 508~771. 병목 C: 담당자 시드의 저장 상태에서 19~680(가장 낮은 값은 시드 1 t=96 의 19), 내 시드의 창 220~480 에서 75~483). 음수 두께(최대 −0.71)와 몸의 분리 때문에 통과로 치지 않는다는 담당자 결론에 동의한다.
- H1(먹이 1개+주입): C>4 최대 성분 중앙값 ≥0.8 이 3/3 + 내 1/1. 단 C>10·C>30 에서는 성립하지 않는다(3.1).
- H3: 틀렸다는 결론이 시드 3개에서 유지된다.
- GPU 비용: 추가 규칙이 3×3 국소 스텐실이라는 주장은 코드와 맞다(bridge_keep 은 8이웃 wet 읽기, 2×2 색칠로 인접 셀 동시 마름 없음). 스칼라 M_k 와 고정 가우스 유인장은 GPU 에서 바꿔야 한다는 것도 담당자가 적었다. 압력은 여전히 CPU 희소 직접 풀이(splu)이고 실측은 없다. h_res=4 의 큰 왕복 유량에서 멀티그리드가 되는지는 아무도 확인하지 않았다.

## 6. 문제점 (담당자 verdict 는 유지하되 붙는 단서)
1. 두꺼운 저장소+bk 의 "최대 성분 0.96"은 정맥망이 관 하나로 줄어든 결과다(정맥 간선 166~320개). 분기 정맥망이 연결된 것이 아니다.
2. 같은 구성에서 몸이 갈라진다: 최대 몸 성분 부피가 0.55~0.83(담당자), 0.56~0.58(내 시드). 부피의 약 절반은 원반 둘, 나머지의 대부분은 관과 끊긴 전진면 조각에 있다.
3. 음수 두께가 보고 범위보다 나쁠 수 있다(새 시드 −0.71). 둘째 먹이 접촉 직후가 가장 심하고, V2 에서는 창 내내 이어진다.
4. 관은 직선의 1.4~2.4배 길이로 굳고 짧아지지 않는다(REPORT 에 없는 수치).
5. 먹이 1개의 줄기 연결(H1)은 C>4 문턱에서만 0.8 을 넘는다. 전진면 도달도 주입 중에는 젊은 셀의 24~58%(담당자 시드)다.
6. 뒤가 굵은 구배는 C>30 정맥만 보면 없다(−0.11±0.10).
7. 전진면의 격자 이방성: 같은 거리 45 에서 접촉 시각 0° 77~81, 27° 58, 45° 46 (대각선 1.7배). 정맥 현(길이≥5)의 격자 방향 ±7.5° 비율은 현이 30개 이상인 시점에서 0.19~0.54 이고 0.333 주위에 흩어져 있어 등방과 구분되지 않는다.
8. 확인하지 못한 것: 먹이 3개 이상, 큰 격자, 멀티그리드 풀이, h_res·food_r 의 다른 값, 두꺼운 저장소에서의 먹이 소진, T>480 의 새 시드.
