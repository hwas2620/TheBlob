# 3차 실험 종합

작성: 2026-11-13, 주 세션.
2차 종합(`../round2/SYNTHESIS.md`)이 0단계 전에 닫으라고 한 네 실험(N1~N4)의 결과다.

## 0. 결론 먼저

1. **권장 모델에 GPU로 옮길 수 있는 풀이 경로가 생겼다 (N1).** 2차의 가장 큰 미검증 이음매였다.
   E9 멀티그리드를 그대로 옮기면 발산하고, 두 가지를 고쳐야 한다: 조대 격자에서 차폐 항은 과보정하지 않는다, 스텝당 2사이클 이상 돈다.
2. **점 먹이에는 전용 규칙 없이 닿고, 부피를 주입하는 먹이는 줄기 나무의 뿌리가 된다 (N3).**
   먹이 둘 사이의 굵은 관은 가설대로의 규칙으로는 유지되지 않는다. 미해결이다.
3. **전진면의 방향별 속도 차이는 젖음 판정을 고쳐 1.68배에서 1.03배로 줄일 수 있다 (N2 일부).** 독립 검증이 없다. 정맥의 격자 정렬은 그대로다.
4. **몸이 2배 넘게 커져도 맥동 위상차는 0.9~1.2바퀴로 유지된다 (N1 실행 재분석).** 눈금 규칙을 따로 둘 필요가 이 범위에서는 없다.
5. numpy 로 먼저 닫아야 했던 가부 판정(N1)은 통과했다. 남은 가장 큰 불확실성은 WebGL2 에서의 실제 비용이고, 이것은 브라우저에서만 잴 수 있다.
   **0단계로 넘어가도 된다는 것이 작성자 판단이다.** 먹이 사이 관 규칙은 0단계와 나란히 numpy 로 더 다듬을 수 있다.

## 1. 무엇이 돌았나

3차 워크플로는 사용량 한도 때문에 에이전트 7개 중 3개만 끝났다.

| 실험 | 실험 | 독립 검증 | 비고 |
|---|---|---|---|
| N1 통합 모델 + 멀티그리드 | 끝남 (실행 43회) | 검증 에이전트가 재실행 2회 뒤 끊김 → **주 세션이 이어서 함** (재실행 9회) | `N1-integrated-multigrid/` |
| N3 점 먹이·줄기·관 연결 | 끝남 (실행 40회) | **끝남** (재실행 6회) | `N3-food-trunk-connect/` |
| N2 격자 잠김·몸 크기 | 끊김 → 주 세션이 전진면 부분만 함 (실행 114회) | 없음 | `N2-front-isotropy/` |
| N4 입자층 | **돌지 않음** | 없음 | |
| 종합 | 끊김 → 주 세션이 씀 (이 문서) | | |

주 세션의 N1 검증은 실험 담당자와는 독립이지만 워크플로의 독립 검증 에이전트보다는 약하다. 검증 에이전트가 짜 둔 독립 훅과 지표 스크립트를 썼다.

## 2. N1 — 통합 모델을 멀티그리드로 풀기

### 고쳐야 하는 것
| 항목 | E9 (순수 포아송, 미리 정한 원반) | 통합 모델 (차폐 포아송, 자유 경계) |
|---|---|---|
| 조대 연산자 | 전체를 /1.5 | 간선 가중치만 /1.5, 차폐(질량) 항은 자식 합 그대로. 차폐 항까지 나누면 발산 |
| 스텝당 사이클 | 1 | 2 이상. 1사이클은 유량 오차 0.26~0.41, 선형 불안정 문턱 근처 |
| 웜스타트 | 직전 해 | 직전 해. 선택: p₀ = p_n + 0.5·(p_n − p_{n−1}) 로 오차 절반. 계수 1.0 은 발산 |
| 최조 격자 Jacobi | 20회 | 4회로 충분 |
| 전도도 폭주 대책 | 전도도 상한 | 자동 Q0 정규화(기존 규칙)가 막는다. 고정 Q0 는 폭주하고 음수 두께가 난다 |
| 음수 두께 대책 | 해당 없음 | 필요 없음. 시험한 유출 제한은 직접 풀이의 결과도 바꾼다(유량 12% 삭감) |

1사이클이 안 되는 이유(담당자 분석, 다시 계산하지 않음): 과보정이 오차의 부호를 뒤집는 모드가 있고, 두께와 압력이 뻣뻣하게 묶여 있어
사이클당 오차 배율이 −1/3 보다 작으면 스텝마다 커진다. 2사이클이면 배율이 제곱이 되어 안정하다.

매 스텝 측정에서 0.3 을 넘는 스텝은 2사이클에서 2.1~2.6% 이고 길이는 2~4스텝이다. 10스텝마다 잰 담당자 표본이 버스트를 놓친 것은 아니다.

### 형태
- 직접 풀이와 같은 부류다: 이동 69~74셀(직접 72~76), 뒤가 굵은 구배(Spearman −0.50~−0.60), 위상 잠금 0.82~0.85, 두께 진폭 0.044~0.049.
- 같은 시드의 직접 풀이와 2사이클 실행은 t=100 에서 젖은 집합이 93%, t=300 에서 67% 겹친다. 정맥 셀의 87~97% 가 상대 실행의 정맥에서 1셀 안에 있다.
- 2사이클은 정맥 간선과 분기 수가 조금 적다(담당자 5시드: 분기 −15%, 검증 2시드: −3%, −31%).

### 비용 (코드 구성에서 센 값, WebGL2 실측 없음)
- 풀이: 2사이클 + 조대 연산자 재구성 = 드로콜 113(512²)~128(768²), 격자 풀스크린 17회 분량.
- 스텝 전체: 드로콜 136(512²)~152(768²), 격자 풀스크린 약 32회 = 1500² 풀스크린 3.8회(512²) 또는 8.5회(768²) 분량.
- 채우기 비용은 예산(프레임당 약 60패스) 안이다. 드로콜 수는 예산의 2배가 넘는다.
- 성긴 레벨을 일찍 끊어 드로콜을 줄이는 것은 안 된다. 계층을 7단에서 5단으로 줄이면 유량 오차 중앙값이 0.105 에서 0.246 으로, 4단이면 0.39~0.62 로 오른다(주 세션 점검, 시드 1개).

### 교훈
Jacobi 40회 실행은 자동 Q0 덕분에 전도도와 정맥 그래프 지표가 정상으로 나왔지만 유량 오차 0.93, 이동 속도 65%, 둥글게 퍼지는 몸이었다.
**풀이가 맞는지는 그래프 지표가 아니라 유량 오차와 이동 속도로 봐야 한다.**

## 3. N3 — 점 먹이, 줄기, 먹이 사이 관 (독립 검증 통과)

| 가설 | 판정 | 근거 |
|---|---|---|
| 점 먹이에 전용 규칙 없이 닿는다 | 성립 | 거리 45 에서 9/9 (3방향 × 3시드), 거리 60 에서 9/9. 먹이는 젖음 문턱을 낮추는 항으로만 들어간다(검증자가 코드 확인) |
| 주입하는 먹이 저장소가 줄기 나무의 뿌리가 된다 | 성립 (조건부) | 정맥 최대 성분 0.81~0.89 (3시드 + 검증자 새 시드·새 방향). 저장소가 최대 성분에 속함. 단 C>4 문턱에서만 0.8 을 넘는다(C>10 은 12개 상태 중 4개) |
| 저장소(+주입)만으로 먹이 둘 사이 관이 남는다 | **불성립** | 0/3, 검증자 새 시드도 불통과. 접촉 직후 7~34배이던 굵기 비가 15~35주기 안에 10배 아래로 떨어지고, 3시드 중 2시드는 몸이 두 군체로 갈라짐 |
| 뒤쪽 정맥이 굵은 것은 관 부피항 맥동 때문이다 | **불성립** | 켬/끔의 차이 −0.031 ± 0.035 로 시드 편차 안. 맥동 자체가 원인이다(맥동 있음 −0.45, 없음 −0.26) |

가설 밖에서 찾은 변형: 먹이 원반의 쉬는 두께를 4배로 하고, 마를 때 막다른 끝부터 마르게 하면(다리 셀은 남김) 두 먹이를 잇는 굵은 관이 5/5 시드에서 남았다(160주기까지 확인).
채택하지 않는다. 이유:
- 정맥망이 관 하나로 줄어든다(간선 약 900 → 170~320).
- 몸이 갈라진다(가장 큰 몸 성분의 부피 0.56~0.83).
- 직접 풀이에서도 음수 두께가 난다(−0.2~−0.7).
- 관이 직선의 1.4~2.4배 길이로 굳고 짧아지지 않는다.
- 값 한 조합만 시험했다.

그 밖에 확인된 것:
- 주입 없는 저장소로 모이는 줄기는 순유량이 아니라 맥동의 왕복 유량이 만든다. 맥동을 끄면 사라진다(대조 1회).
- 몸이 먹이에 머무르지 않는다. 먹이 반지름 3배 안의 부피는 5~9% 이고 고리 모양 전진면이 계속 밖으로 나간다.
- 뒤가 굵은 구배는 가는 정맥까지 셀 때만 뚜렷하다. C>30 인 정맥만 보면 0 과 구분되지 않는다.
- 0단계 기준 B5 의 "정맥 중앙값의 10배"는 망이 관 하나로 줄면 분모가 관 자신이 되어 뜻을 잃는다.

## 4. N2 (일부) — 전진면의 방향 치우침 (독립 검증 없음)

원인 둘을 찾았다. 대각 전진면에서는 마른 셀이 둘째 줄(더 오래 차오른 셀)을 보고 일찍 젖는다. 축과 대각 사이 각도에서는 계단 모서리가 곡률항의 보너스를 받아 빨리 채워진다.

고친 규칙: 대각 이웃의 두께를 그대로 쓰지 않고 거리 0.92 인 점에서 젖은 셀만으로 보간한다. 곡률항은 8이웃 개수 대신 젖은 마스크의 가우스 흐림(σ=2)으로 잰다.

| | 0° | 13° | 27° | 34° | 45° | 최대/최소 |
|---|---|---|---|---|---|---|
| 기준선: 먹이에 닿는 시각 | 78.2 | 74.9 | 57.8 | 47.0 | 46.4 | 1.68 |
| 고친 규칙 | 62.3 | 61.1 | 61.4 | 60.6 | 62.3 | 1.03 |

- 시드 2~3개의 평균, 변형당 실행 13회. 윤곽이 팔각형에서 둥근 모양으로 바뀐다.
- 부피 보존, 맥동 진폭, 정맥 수·굵기 분포, Strahler 차수는 기준선과 같은 범위다(27°, 3시드). 분기와 순환은 약 20% 적다.
- **정맥의 격자 정렬은 고쳐지지 않았다.** 45° 로 곧게 뻗은 평행한 정맥이 여전히 보인다.
- 먹이 없이 퍼지는 초기 단계에는 대각 치우침이 조금 남는다(대각/축 1.09 ± 0.04, 기준선 1.20 ± 0.05).
- 멀티그리드 풀이, 큰 격자, 먹이 둘에서는 돌리지 않았다.

## 5. 몸 크기 (N1 실행 재분석)

| 격자 | 몸 크기(셀) | 늙은 셀이 앞서는 위상(바퀴, 가장 큰 몸 성분) |
|---|---|---|
| 192 | 약 85×108 | 0.91~0.95 |
| 256 | 약 106×165 | 0.94~1.02 |
| 384 | 약 173×233 | 1.13~1.20 |
| 512 (이주 전) | 220×234 | 1.16 |

2차 검증자가 걱정한 "위상차 ∝ (몸 길이)²"는 이 범위에서 나타나지 않았다. 파라미터는 그대로였다.
384 격자에서는 뒤가 굵은 구배가 약하다(Spearman −0.17~−0.21). T=400 까지는 몸이 아직 넓게 퍼지는 중이기 때문으로 보인다(확인하지 않음).

## 6. spec 에 반영할 것

모델
1. 규칙 3 의 풀이를 2절의 구성으로 적는다.
2. 규칙 7 의 젖음 판정을 4절의 고친 규칙으로 바꾼다. "독립 검증 없음"을 표시한다.
3. 먹이 규칙을 넣는다: 먹이 위 셀은 늙지 않고, 먹는 만큼 부피가 늘어난다. 먹이 사이 관은 미해결로 둔다.
4. 미해결 문제 1번(통합 + 멀티그리드)을 닫고, WebGL2 실측을 1번으로 올린다.

0단계 기준
- 관문 A: 풀이 구성을 2절로 바꾼다. numpy 가 저장한 상태를 그대로 넣어 유량 오차를 재는 시험을 넣는다. 정확도 기준은 중앙값 ≤ 0.15, 99백분위 ≤ 0.4. 풀이 판정에 이동 속도를 넣는다.
- B2: 방향별 먹이 도달 시각의 최대/최소 ≤ 1.1 을 넣는다.
- B5: "먹이 사이 경로의 최소 전도도 ≥ 정맥 90백분위"와 "두 먹이가 같은 정맥 성분에 있는 시간 비율"로 바꾼다.
- B3: 정맥 최대 성분은 문턱에서 깜빡이므로 시간 평균으로 잰다.

## 7. 채택하지 않은 주장
- E9 멀티그리드를 그대로 쓴다: 발산한다.
- 스텝당 1사이클이면 된다(2차 종합의 비용 추정이 이 가정이었다): 불합격이다. 풀이 비용이 2배가 된다.
- 유출 제한으로 음수 두께를 막는다: 필요 없고 해롭다.
- 뒤쪽 정맥이 굵은 것은 관 부피항 맥동 때문이다(2차 종합의 후보 설명): 틀렸다.
- 먹이를 늙지 않는 저장소로 두면 먹이 사이 관이 남는다(2차 종합의 가설): 틀렸다.
- 위상차가 몸 길이의 제곱에 비례해 커진다: 이 범위에서는 아니다.

## 8. 남은 위험과 하지 못한 것

1. **WebGL2 실측이 없다.** 스텝당 드로콜 136~152 는 예산의 2배가 넘는다. 줄이는 방법(조대 레벨을 한 장에 모으기, 잔차와 제한 합치기, 2프레임에 한 번 풀기)은 어느 것도 시험하지 않았다.
2. **먹이 사이 굵은 관.** 게임의 핵심 장면인데 결함 없는 규칙이 없다.
3. **정맥이 조각난다.** 이주 실행에서 정맥(C>4) 최대 성분은 0.24~0.55 다. 풀이의 안정 여유도 깎는다(담당자 분석).
4. **몸이 먹이에 머무르지 않는다.**
5. **큰 격자.** 512² 는 1회(이주 전 단계, 기준선 없음), 768² 는 0회다. 통합 모델이 384 를 넘는 격자에서 이주까지 간 실행이 없다.
6. **풀이 여유.** 2사이클은 384 에서 중앙값 0.135~0.15 로 기준에 붙어 있다. 외삽이나 3사이클을 기본으로 잡는 편이 안전하다.
7. **N2 의 고친 젖음 규칙**은 독립 검증, 멀티그리드, 큰 격자, 장시간 실행이 없다. 정맥의 격자 정렬은 손대지 못했다.
8. **N4(입자층)는 돌지 않았다.** E2 의 결론도 여전히 미검증이다. 입자층은 구조 부품이 아니므로 0단계의 선택 항목(B8)으로 미룬다.
9. 3차의 N1·N3 는 서로 합쳐 돌린 적이 없다(N3 는 직접 풀이, N1 은 선형 구배). N2 의 규칙도 마찬가지다.
10. 점액 기피, 절단 반응, 토러스 장시간 지속성은 2차 이후 새로 시험한 것이 없다.

## 9. 직접 확인한 것과 못 한 것
직접 확인: N1·N3 의 담당자 보고와 N3 검증 보고 전문, N1 코드의 멀티그리드 경로와 젖음 규칙, 그림 8장(N1 2장, N3 2장, N2 4장),
N1 재실행 9회와 N2 실행 114회의 수치.
못 한 것: N1 의 고윳값 분석과 동결 기하 점검 재계산, N3 의 재실행(검증 에이전트가 6회 함), 512² 재실행, WebGL2.
