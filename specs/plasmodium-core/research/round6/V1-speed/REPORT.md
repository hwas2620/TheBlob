# 6차 실험 V1 — 맥동을 바꿔 스텝당 전진을 늘릴 수 있는가 (탐색)

작성자 실험이다(이 문서의 작성자가 설계·실행·분석을 모두 했다). 시드 2~6개, 격자는 192² 하나, 먹이 배치는 대칭 셋 하나다.
탐색이고 채택한 것은 없다.

**후보(dt 0.2 + 맥동 주기 8)는 독립 검증을 받았다(2026-11-18, 새 시드로 59회. [verify/REPORT.md](./verify/REPORT.md)). 이 문서보다 그 보고를 우선한다.** 검증이 고친 것:

검증이 짚은 이 문서의 약한 곳: "한 스텝의 위상 전진이 같으니 부담이 같다"는 추론은 근사다(두께 맥동의 진폭이 20%쯤 크고, 맥동이 아닌 흐름은 스텝당 2배다).
"스텝 끝 음수 두께"는 풀이의 부담을 재지 못한다(마르지 못한 고립 셀이 오래 남아 생기는 수다). 풀이 문제를 가른 지표는 "정맥 셀이 새로 음수가 되는가"였다.
굵은 쌍을 창의 중앙값으로 세면 늦게 난 끊김을 놓친다. 시드 6개로는 수십 회에 한 번 나는 사건을 볼 수 없다.
후보는 모습도 조금 바꾼다: 맥동 무늬가 더 고르고, 두께 맥동이 20%쯤 크고, 정맥 그물이 조금 성기다.
**몸이 큰 경우(384²에서 몸을 2배로)는 기준 설정도 시험을 통과하지 못해 판정하지 못했다. 게임의 몸은 그보다 크므로, 채택하려면 큰 몸에서 통하는 시험부터 있어야 한다.**

## 물음

D1에서 한 스텝의 시간 간격 dt를 키우는 길은 풀이의 정확도에 막혔다. 거기서 남은 물음이 둘이다.

1. 전진 속도를 정하는 것이 맥동인가. 진폭이나 주기를 바꾸면 스텝당 전진 거리가 늘어나는가.
2. 풀이를 무너뜨리는 것이 맥동이 한 스텝에 옮기는 부피라면, 맥동을 약하게(진폭) 또는 느리게(주기) 하고 그만큼 dt를 키울 수 있는가.

## 방법

- 모델과 설정은 D1과 같다: 5차 H1의 `h1.py`, 192² 토러스, 삼각 격자 무늬 P=96, 마름의 부피 나눔은 균등, 풀이는 멀티그리드 2사이클(따로 적은 것만 직접 풀이·3사이클).
  위상의 부분 스텝 간격은 0.025로 유지한다(dt 0.2 → 8회, 0.4 → 16회).
- 시험 둘: 굶은 이주(T=400), 대칭 먹이 셋(T=480). dt=0.1 기준값은 5차 작성자 실행(`Ym_tri96d`, `Y3_tri96d`, 시드 21~26)이다.
- 묶음마다 실행 전에 예측을 적었다(`prediction_speed.txt`).
  1. 진폭 0.2, 주기 2 — 각각 직접 풀이와 멀티그리드 (시드 21·22)
  2. 진폭 0.05, dt 0.2 + 진폭 0.05 (시드 21~23, 뒤의 것은 24~26 추가)
  3. dt 0.2 + 주기 8 (시드 21~26), dt 0.4 + 주기 16 (시드 21~23)
  4. dt 0.2 + 진폭 0.05에 3사이클 (먹이 셋만, 시드 21~26)
  dt 0.4 + 진폭 0.025는 예측만 적고 돌리지 않았다.
- GPU 대조: 가장 나은 구성(dt 0.2 + 주기 8)을 0단계의 WebGL2 코어로 돌려 같은 설정의 numpy 실행과 견줬다(0단계의 굶은 이주 설정, 모델 시간 400).

## 읽는 법

1. **전진 속도는 맥동이 정하지 않는다.** 직접 풀이에서 진폭을 2배로 하면 이주가 오히려 늦고(t=300에 35셀. 기준 43~52셀), 주기를 절반으로 하면 그대로다(52셀).
   진폭을 절반으로 하면 조금 빨라지고(59~61셀), 주기를 2배로 하면 조금 늦다(34~43셀). 왜 그런지는 따져 보지 않았다.
2. **풀이의 부담은 맥동이 한 스텝에 옮기는 부피를 따른다.** 진폭 0.2와 주기 2는 직접 풀이로는 유지되고(굵은 쌍 6/6) 멀티그리드 2사이클로는 무너진다(0/6, 1/6).
   진폭 0.2의 유량 오차 중앙값은 기준과 같았다(0.06~0.08). 거꾸로 진폭을 절반으로 줄이면 유량 오차(0.055~0.059)와 스텝 안 음수 두께(−0.004)가 준다.
3. **dt 0.2 + 주기 8은 여섯 시드에서 기준 시험을 지켰다.** 한 스텝의 위상 전진(9°)과 한 주기의 스텝 수(40)가 기준과 같은 구성이다.
   먹이 셋의 굵은 쌍 18/18, 몸이 갈라진 실행 0, 스텝 안 최소 두께 −0.014~−0.080, 유량 오차 중앙 0.079~0.106. 이주의 정맥 연결 0.88~0.90.
   D1의 통과 기준(굵은 쌍과 정맥 연결이 1개 넘게 줄지 않음, 몸이 갈라지지 않음, 스텝 끝 음수 두께가 늘지 않음, 유량 오차 중앙 ≤ 0.15)으로 보면 스텝 끝 최소 두께가 −0.006~−0.017로 기준(−0.003~−0.008)보다 조금 크다.
   값을 치르는 곳은 이주 속도다. 유인원에 닿는 시각이 시드별로 8~22% 늦다(중앙 13%. 269~285 대 233~256). 한 스텝이 모델 시간을 2배 가므로 스텝당으로는 1.6~1.85배 빠르다.
4. **dt 0.2 + 진폭 0.05는 스텝당 더 빠르지만 깨끗하지 않다.** 이주가 모델 시간으로도 빨라(t=300에 56~60셀) 스텝당 약 2.3배다.
   그러나 먹이 셋에서 굵은 쌍 16/18, 여섯 실행 가운데 넷에서 스텝 안 두께가 −0.25~−0.93, 유량 오차 중앙 0.145~0.167이다. 3사이클로 올리면(시드 6개) 굵은 쌍 18/18, 유량 오차 중앙 0.082~0.098이 되지만 스텝 안 두께가 −0.1 아래인 실행이 1개 남는다(최소 -0.44).
5. **dt 0.4 + 주기 16은 걸친다.** 이주는 기준과 같은 시각에 닿지만(스텝당 4배) 먹이 셋에서 굵은 쌍 7/9, 한 실행에서 스텝 안 두께 −1.4다.

## 후보와 그 한계

후보는 **dt 0.2 + 맥동 주기 8**이다. GPU 쪽은 설정값 셋(dt, 주기, 위상 부분 스텝 수)만 바뀌고 스텝당 드로콜이 4개 는다(384²에서 77 → 81).
같은 프레임당 스텝 수에서 화면의 전진이 약 1.7배가 되고(검증 뒤: 오래 달리는 속도로는 1.5~1.6배), 맥동의 화면 주기(40스텝)는 그대로다. 전진이 맥동 한 번에 가는 거리가 0.8셀에서 약 1.3셀로 는다.
