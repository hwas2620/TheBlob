# 원형질체 모델 연구 자료

`spec.md`의 모델 선택을 뒷받침하는 조사·실험 자료.

- `lit/` — 문헌 조사 노트 5건 (정맥 형성 모델, Jones 후속 연구, 연속체 채널화, 형태·성장·생물학 수치, 실시간 구현). 각 노트는 본문을 직접 읽은 것과 초록만 본 것을 구분해 적었다.
- `common/eval_morph.py` — 모든 실험에 쓰는 공통 형태 채점기 (분기점 수, 고리 수, 굵기 위계, 연결성).
- `interim/` — 1차 실험이 사용량 한도로 중단되기 전에 남긴 중간 산출물. 독립 검증 전이다.
  - `e1-front-sink.py`, `e1-tree-gamma1.5.png`, `e1-mesh-gamma1.0.png`: 전역 압력 풀이 + 전진면 싱크 + 간선 전도도 유량 강화.
  - `e2-jones.py`: 1024² 스케일 Jones 입자 모델 (점유 제한, 밀도, 감지각 스윕).
