## 1. 한 줄 결론

문헌에서 연속체(격자) 채널화가 나오는 모델은 예외 없이 **(i) 압력을 타원형 방정식으로 풀어 유량이 전역적으로 보존되고(∇·q = S), (ii) 고정된(또는 느리게 변하는) 총 유량을 평행 경로들이 나눠 갖는 경쟁이 있으며, (iii) 전도도가 유량에 대해 초선형(C ∝ Q^μ, μ>1 ⇔ 대사비용 지수 γ<1)으로 강화**된다. 스칼라 전도도냐 벡터/텐서냐는 채널화의 필요조건이 아니다(스칼라로도 분기 수형망이 나온다 — Facca 등, Derr 등, 그리고 아래 자체 점검).
우리 프로토타입은 (iii)은 갖췄지만 (i)·(ii)가 없다. 국소 탄성벽 압력 + 명시적 갱신에서는 진동 압력이 1~10셀밖에 전파되지 못해 몸 크기 규모의 유량 자체가 존재하지 않는다.

## 2. Hu–Cai 이산 모델과 Haskovec–Markowich–Perthame(HMP) 계열 PDE

### 2.1 Hu & Cai 2013, PRL 111, 138701 "Adaptation and optimization of biological transport networks"
- 접근: **본문 못 읽음.** 아래는 [2차] — Klemm & Martens 2023 (arXiv:2305.19401) 식 (1)–(4), Haskovec–Kreusser–Markowich 2018 (arXiv:1805.08526) 2절.
- 이산 모델 [2차, Klemm&Martens 식 (2)]: 간선 전도도 C̃_ij, 유량 Q_ij = C_ij (p_i − p_j), 마디마다 Kirchhoff `h_i = Σ_j Q_ij`.
  ```
  d C̃_ij / dt = c ( Q_ij² / C̃_ij^{γ+1} − τ_e² ) C̃_ij
  ```
- 에너지 범함수 [본문, 1805.08526 식 (2.5)]: `Ẽ[C] = Σ_(i,j) ( Q_ij[C]²/C_ij + (ν/γ) C_ij^γ ) L_ij` (펌핑 일률 + 대사 비용).
  기울기 흐름 [식 (2.8)]: `dC_ij/dt = ( Q_ij²/C_ij² − ν C_ij^{γ−1} ) L_ij`,
  가중 거리 일반형 [식 (2.9)]: `dC_ij/dt = ( Q_ij²/C_ij − ν C_ij^γ ) C_ij^{α−1} L_ij`, α = 2−γ 가 Hu–Cai 원형.
- γ의 의미 [본문, 1805.08526]: 혈관은 대사비용 ∝ 단면적, Poiseuille에서 C ∝ 단면적² ⇒ **γ = 1/2**. 잎맥은 **1/2 ≤ γ ≤ 1**.
- 정상 상태: `Q² = ν C^{γ+1}` ⇒ **C ∝ |Q|^{2/(γ+1)}**. γ<1 이면 지수 >1 (초선형 강화).
- 상전이 [본문, 1805.08526 4절, Hu–Cai를 인용하며 수치로 확인]: **γ = 0.5 → 정상 상태가 트리, γ = 1.5 → 모든 간선이 남는 "full network". γ = 1 에서 전이.** 정상 상태는 유일하지 않고 초기 조건에 강하게 의존(지역 최소 다수). γ=0.5에서는 초기에 넣은 고리가 시간이 지나면 열린다(트리로).
- 고리(loop) [초록 + 2차]: 흐름 분포에 **요동(fluctuation)** 이 강하면 최적망이 위계적 고리 구조를 가진다 (Hu–Cai 초록; Klemm&Martens도 "emergence of cycles ... on amplitude and frequency of flow fluctuations"). 요동 구현 예 [본문, Klemm&Martens II.B]: 싱크 하나를 무작위로 골라 큰 유출을 주고, 전도도 적응 시간보다 짧은 간격으로 다시 뽑는다.
- 연결성 유지 [본문, 1805.08526 Lemma 2/Theorem 1]: 두 마디 집합 사이에 순 유량 ΔS ≠ 0 이 있으면 그 사이 전도도 합은 0이 되지 않는다. 즉 **소스–싱크가 있는 한 관은 끊기지 않는다**.

### 2.2 HMP 벡터 모델 (m-모델)
- Haskovec, Markowich, Perthame 2015, Comm. PDE. arXiv:1405.0857 **[본문]**. https://arxiv.org/abs/1405.0857
- Haskovec, Markowich, Perthame, Schlottbom 2016, Nonlinear Analysis. arXiv:1510.03630 **[본문]**. https://arxiv.org/abs/1510.03630
- 식 (1510.03630 식 (1.1)–(1.2), 원문 표기):
  ```
  −∇·[(r I + m⊗m) ∇p] = S
  ∂m/∂t − D² Δm − c² (m·∇p) ∇p + α |m|^{2(γ−1)} m = 0
  ```
  p: 압력(스칼라), m: 전도도 벡터, r(x) ≥ r0 > 0: 등방 배경 투과율, D: 확산(재료의 무작위성), c: 활성화, α|m|^{2(γ−1)}m: 대사 이완. 경계: m = 0, p = 0 (또는 무유량).
- 에너지 (식 (1.5)): `E(m) = ½ ∫ [ D²|∇m|² + (α/γ)|m|^{2γ} + c²|m·∇p[m]|² + c² r |∇p[m]|² ] dx`, `dE/dt = −∫|∂_t m|² dx`.
- 부호의 중요성 (1405.0857 Lemma 2): 활성화 항 부호를 뒤집으면 유일한 정상해는 m ≡ 0 이고 지수적으로 0으로 수렴. 즉 **흐름 방향으로 전도도를 키우는 양의 되먹임**이 패턴의 원인.
- **확산 D 조건**
  - D → ∞ 이면 정상해 m → 0 (Proposition 1): "we cannot expect pattern formation when D is too large".
  - m ≡ 0 의 선형 안정성 (Lemma 14, γ>1): β := c²/D², σ1 := sup_n ∫|∇p0·n|² / ∫|∇n|². **β < 1/σ1 안정, β > 1/σ1 지수적 불안정.** 선형화: `∂_t n = D² (Δ + β ∇p0⊗∇p0) n`. 저자들은 이를 Turing 불안정으로 부른다. 대략 `c |∇p0| · (영역 크기/π) > D` 여야 한다는 뜻.
  - D = 0 이면 m의 지지집합(support)이 자라지 못한다(식이 x별 ODE). 그래서 초기 씨앗 m0 ≠ 0 이 필요하다 (1510.03630 5.5절, 2209.08292).
- **γ 범위**
  - γ < 1/2: 유한 시간 소멸/붕괴 (이완항이 m→0에서 특이). 수치 확인: γ=0, 1/10, 1/4, 2/5 에서 소멸 시간 5.3e-7 ~ 2.1e-4 (1510.03630 표 3).
  - 1/2 ≤ γ < 1: D=0 정상 상태 조건 `c|u| = |z|^{γ−1}(1+z²)` 가 **문턱 c|u| > Z_γ 이상에서만 0이 아닌 해 2개**(하나는 감소 가지, 하나는 증가 가지)를 가진다 (1510.03630 4절). 즉 쌍안정 — 0 상태와 "관" 상태가 공존 → 성긴(sparse) 망.
  - γ = 1: `|u| ≤ 1/c` 인 곳에서는 m = 0 이어야 한다(문턱 하나, 자유경계 문제).
  - γ > 1: 모든 |u|>0 에서 양의 해가 정확히 하나. 선형 안정한 망은 **영역 전체를 채운다** (meas(A+∪A−) = meas(Ω)). → 가는 망이 아니라 번진 분포. 텐서 모델에서는 γ ≥ 1 이면 에너지가 볼록 → 유일한 정상해, D=0·γ>1 이면 p-라플라시안 문제로 환원 (2111.03889).
- **수치 실험 (1510.03630 5절)** — 혼합 유한요소(p: P1, m: P0, σ=∇m: RT0), IMEX 오일러.
  - 기본값: `S = 1, r = 1/10, c = 50, D = 1/1000, γ = 1/2, ρ = 1e−12(절댓값 정칙화)`. 영역은 한 변이 잘린 마름모(지름 O(1)), 격자 102,905 꼭짓점 / 204,544 삼각형, **h ≈ 0.0032**. 초기값: 디리클레 경계 근처의 짧은 띠에서만 m1 = 1.
  - 시간 간격: `δ = 1/(2 c² ‖∇p‖²_∞)` (활성화 항의 성장률 c²|∇p|² 때문에 명시적 오일러는 원래 불안정; 이완항이 균형을 잡는 범위에서만 안정).
  - **D 변화 (γ=1/2)**: D ≥ 1/10 → 확산 지배, 미세 구조 없음. D = 1/100 → 아직 번져 있으나 큰 규모 구조가 보임. D = 1/1000 → 미세한 망. 희소성 지표 s = ‖u‖_L2/‖u‖_L1: D=1/2 → 1.344, 1/10 → 1.348, 1/100 → 1.576.
  - **격자 의존성**: D = 1/1000 에서 "strong mesh dependence" (D ≥ 1/2 에서는 없음). 저자 해석: 활성화가 강할 때 격자가 확산을 풀기엔 너무 거칠다. 더 고운 격자가 필요하지만 계산이 과도하게 오래 걸린다고 명시. 그래도 "D가 작을수록 더 미세하고 희소" 라는 정성적 경향은 맞다고 본다.
  - **γ 변화 (D=1/1000)**: 희소성 s — γ=3/5: 3.55, 3/4: 4.15, 1: 1.56, 3/2: 1.18, 2: 1.16. **γ > 1 에서는 미세 구조가 생기지 않는다.** γ = 1 은 긴 시간 뒤에 구조가 나타남. γ ∈ {1/2, 3/5, 3/4} 에서 미세 망. 초기 `c‖∇p‖_∞ ≈ 4000`.
  - 정상 상태까지 계산하지 못한 경우가 많다고 저자가 밝힘(D=1/1000 결과는 정상 상태가 아님).
- [자체 추정] D와 격자의 관계: 이완 시간 ~1/α 동안의 확산 길이 ℓ_D ≈ D/√α. HMPS의 D=1/1000, h=0.0032 는 ℓ_D/h ≈ 0.3셀(격자 이하 → 격자 의존). Astuto 등의 N=600, D=0.01, α=0.75 는 ℓ_D ≈ 7셀(가지가 보임), D=0.05 는 35셀(가지 없음), D=0.001 은 0.7셀(더 가늘고 많음). ⇒ **관 폭이 2~10셀로 풀리는 범위에서만 격자와 무관한 분기 패턴**을 기대할 수 있다. (논문이 이렇게 서술한 것은 아니고 그 수치에서 내가 뽑은 해석.)

### 2.3 텐서 모델 (C-모델)과 격자 유한차분 구현
- Haskovec, Markowich, Pilli 2021/22, "Tensor PDE model of biological network formation". arXiv:2111.03889 **[본문 1~2절]**.
- Astuto, Boffi, Haskovec, Markowich, Russo 2022, "Comparison of two aspects of a PDE model for biological network formation". arXiv:2209.08292 **[본문]**.
- Astuto 등 2023, "Asymmetry and condition number of an elliptic-parabolic system for biological network formation". arXiv:2301.12926 **[초록+수치 설정]**.
- 식 (2209.08292 식 (3),(6)):
  ```
  −∇·((r I + C) ∇p) = S
  ∂C/∂t − D² ΔC − c² ∇p⊗∇p + α |C|^{γ−2} C = 0        (|C| = Frobenius 노름, M(s) = (α/γ) s^γ)
  ```
  m-모델과의 차이: 활성화 항 `c²∇p⊗∇p` 가 **C에 곱해지지 않는다** → 씨앗 없이 0에서 자란다. 대신 γ<1 이면 `|C|^{γ−2}C` 가 C=0에서 특이 → `|C+ε|^{γ−2}` 로 정칙화(ε = 1e−3 권장, 1e−2 는 가지가 사라짐).
- **균일 직교 격자 유한차분**(우리와 가장 가까운 구현): 셀 중심, 2차 중심차분, 대칭 ADI 반암시적, Poisson 은 보존형 이산화(면 전도도 = 이웃 평균).
  - 파라미터(표 1): `α = 0.75, c = 5, r = 0.005, γ = 0.75, ε = 1e−3, t_fin = 15, N = 600`. D ∈ {0.05, 0.01, 0.001}, γ ∈ {1, 0.75, 0.5}. (후속 2301.12926 은 N = 600, Δt = h, t_fin = 10.)
  - 소스: `S = E − mean(E), E = exp(−1000 |x − x0|²), x0 = (0.1, 0.1)` (점 소스 + 균일 싱크). 초기값 m0 = [1,1], C0 = I (전 영역 균일).
  - 결과: D를 줄일수록 가지가 뚜렷하고 가늘어진다. **D = 0.05 에서 m-모델은 가지가 안 보인다.** γ = 1 은 망의 세부가 나오지 않고, **γ = 0.75 가 잎맥을 가장 잘 닮았다.** m-모델은 Y자, C-모델은 V자 — 두 모델은 정성적으로 비슷하지만 가지 수·위치가 다르고 몇 스텝 만에 멀어진다.
  - **조건수 문제** (2301.12926): r 을 1e−1 → 1e−3 으로 줄이면 타원 연산자의 조건수가 커지고 대칭성이 깨진다(비대칭도 1e−10 → 1e−5 → …). 격자를 세분하면 가지의 모양·위치·수가 바뀐다.
- **대각 텐서 = 격자 간선 전도도** (Haskovec, Kreusser, Markowich 2018, arXiv:1805.08526 **[본문]**; 엄밀한 Γ-극한은 arXiv:1808.01526 **[초록]**):
  직사각 격자 위 이산 Hu–Cai 모델의 형식적 연속체 극한은 **대각 텐서 c = diag(c¹, c²)** 이고
  ```
  E[c] = ∫ ∇p·c∇p + (ν/γ)|c|^γ dx ,  |c|^γ := Σ_k |c^k|^γ
  −∇·((r I + c) ∇p) = S
  ∂_t c^k = D² Δc^k + (∂_{x_k} p)² − ν |c^k|^{γ−2} c^k ,   k = 1, 2
  ```
  (식 (1.4)–(1.6)). 가중치가 모두 같아야(등간격 격자) 기울기 흐름이 이 꼴이 된다(Proposition 1). γ>1 에서 전역 약해 존재 증명.
  ⇒ **GPU 관점: 텍스처 2채널(가로 간선, 세로 간선 전도도) + 압력 1채널로 Hu–Cai를 그대로 올릴 수 있다.**
- Albi, Artina, Fornasier, Markowich 2016 (Analysis and Applications 14) / Albi, Burger, Haskovec, Markowich, Schlottbom 2017 (Active Particles Vol.1): **본문 못 읽음.** arXiv 판 없음. 위 논문들이 "모델 유도(Darcy + Carman–Kozeny)와 수치 예"의 출처로 인용.

### 2.4 스칼라 전도도 — Facca, Cardin, Putti
- "Branching structures emerging from a continuous optimal transport model", J. Comput. Phys. 2021. arXiv:1811.12691 **[본문]**. (전편: arXiv:1610.06325, SIAM J. Appl. Math. 2018 **[초록]**)
- 식 (2a)–(2c): Tero 2007 의 연속체 확장.
  ```
  −∇·(μ ∇u) = f = f⁺ − f⁻ ,   μ' = [ μ |∇u| ]^β − μ ,   μ(0) = μ0 > 0 ,  무유량 경계
  ```
- Lyapunov 후보: `L_β(μ) = ½∫ μ|∇u_f(μ)|² dx + ½∫ μ^{(2−β)/β} /((2−β)/β) dx` (β=2 는 ln μ).
  - **0 < β ≤ 1**: 둘째 항 볼록 → 집중을 벌함 → 번진(혼잡) 수송. β<1 은 p-Poisson (p = (2−β)/(1−β)), β=1 은 OT 밀도로 수렴.
  - **1 < β < 2**: 둘째 항 오목 → **좁은 지지집합으로 집중 → 분기(branched transport) 구조.**
- 수치: P1(h/2)–P0(h) 유한요소, **전진 오일러**, 매 스텝 PCG. β ∈ {1.1, 1.5, 2, 3}. 초기 μ0 ≡ 1(균일).
  - 결과: μ가 f⁺, f⁻ 지지집합을 잇는 좁은 채널로 자기조직. **큰 유량 채널이 반복해서 작은 채널로 갈라지는 위계**. 고리 없는 트리. β가 클수록 더 집중(중앙 채널 수: β=1.1 에서 3개 → β=3 에서 1개).
  - **채널 폭은 항상 삼각형 1개** — h에 비례해 줄고 μ 최댓값은 세분할수록 커진다(고유 길이 척도가 없음). 격자 정렬 문제, 격자 수준에 따라 위상이 바뀜, 초기 조건 민감(지역 최소).
  - 선형계가 극도로 나쁜 조건(μ가 1e−10 ~ 큰 값) → 전용 전처리기 필요, 고운 격자 + β ≫ 3 에서는 실패.
  - Δμ가 몇 자릿수씩 급변하므로 Δt를 그에 맞춰 조절.
- 시사점: **등방 스칼라 전도도 + 전역 타원 압력 + β>1 만으로 분기 트리가 나온다.** 방향성(벡터/텐서)은 필수가 아니다.

## 3. 다공질 매질의 흐름 유발 채널화 (스칼라 장, Darcy 압력)

Guy–Nakagaki–Wright 2011 의 본문을 못 읽어서, 같은 부류(흐름이 고체 분율을 깎아 투과율을 높임)의 공개 논문을 대신 정밀하게 읽었다.

### 3.1 Guy, Nakagaki, Wright 2011, PRE 84, 016310 "Flow-induced channel formation in the cytoplasm of motile cells"
- 접근: **[초록]** + 검색 도구가 돌려준 수락본 요약 + Le Verge-Serandour & Alim 리뷰(arXiv:2306.09063)의 한 문단 **[2차]**. APS 수락본·UC Riverside 사본은 이 세션에서 열리지 않았고, 저자 사이트·Boise State 사본은 시도하지 않았다(같은 방식의 실패가 반복되어 중단).
- 확인된 내용: Physarum 원형질 안의 흐름 채널 형성 모델. 고분자(액틴) 망을 지나는 압력 구동 흐름에서 **흐름이 빠를수록 탈중합 속도가 커진다**. 1차원 수치해와 점근 해석으로 "매우 일반적인 가정에서 흐름에 반응한 채널 형성"을 예측. 채널 안은 고분자 분율이 낮으므로 Darcy 대신 **Brinkman 방정식** 사용. 단순 항복응력 서술로는 채널 형성을 설명할 수 없다고 주장. 해는 가한 압력에 대해 **이력(hysteresis)** 을 보인다. 리뷰의 표현: "a critical pressure below which channels appear has been predicted" [2차 — 문장 그대로 옮김. 방향(below/above)은 원문으로 확인 못 함].
- **식·파라미터는 확인하지 못했다.** 채워 넣지 않는다.

### 3.2 Mahadevan & Mahadevan 2010/2012 "Flow-induced channelization in a porous medium" (EPL 98). arXiv:1009.0565 **[본문]**
- 3상(고정 고체 φ_s, 이동 입자 φ_g, 액체 φ_l) 모델:
  ```
  ∂_t φ_s = −e + d ,   ∂_t φ_g = e − d − ∇·(φ_g u) ,   ∇·(φ u) = 0 (φ = φ_g + φ_l)
  e = k_e φ_s [ (γ⁻¹∇p)² − σ(φ̄_s) ]_+ ,   d = k_d (φ_s − φ_s*) φ_g  (d ≥ 0)
  q = φ u = −D(φ)∇p ,  D = φ³ l_g² / (A μ (1−φ)²)   (Carman–Kozeny)
  σ = 0.5( tanh(2π(φ̄_s − 0.6)) + 1 ) ,  φ̄_s = 이웃 8칸 가중 평균(0.2 φ_s(i,j) + 0.1 φ_s(이웃))
  ```
- 핵심 관찰
  - **입구 압력이 아니라 입구 유량을 고정해야 한다.** 압력을 고정하면 "침식 없음" 아니면 "파국적 전면 침식" 둘 중 하나. 유량을 고정하면 침식된 곳으로 흐름이 쏠리고 **나머지 영역의 유량이 줄어든다(총 유량은 동일)** → 선택적 채널.
  - 임계 유량 q_c 미만이면 침식 없음, 임계 근처에서 가는 채널 1개, 증가하면 채널 수와 폭이 늘고, 과하면 전체가 씻겨 나감.
  - 채널 간격·폭은 영역 크기와 무관하고, 문턱 σ의 형태와 초기 불균일(잡음 표준편차 0.001 ~ 0.03)에 좌우.
  - 압력은 매 스텝 Poisson `∇·(D(φ)∇p) = 0` 반복 풀이, Δt = 1e−4. (격자 간격은 본문에 "Δ = 0.05" 로 적혀 있으나 영역 0.32 와 맞지 않아 오식일 가능성 — 확인 못 함.)

### 3.3 Derr, Fronk, Weber, Mahadevan, Rycroft, Mahadevan 2020, PRL "Flow-driven branching in a frangible porous medium". arXiv:2007.02997 **[본문]**
- 2상 최소 모델 (식 (2),(4),(5)):
  ```
  q = −κ(φ)∇p ,  κ(φ) = (1−φ)³/φ² ,   ∇·(κ(φ)∇p) = s
  ∂_t φ = −φ · max{0, ∇p·∇p − ψ(ϕ)} ,   ϕ = φ 를 길이 ξ 의 가우시안으로 뭉갠 값
  ψ(ϕ) = c0 tanh(ω(ϕ − ϕ*)) + c1 ∈ [0,1]
  초기: φ = φ0 + δφ, 〈δφ(x)δφ(y)〉 = σ_φ² exp(−r/ζ)
  ```
- 파라미터: 격자 **1000²(또는 1024²)**, 영역 [−5,5]², φ0 = 0.8, ϕ* = 0.7, σ_φ = 0.02, ζ = 0.1(0.08), ξ = 0.1(0.05), ω = 6.5 (1~15), 총 유량 F = 0.8(0.5), 유량을 0에서 T = 10 동안 서서히 올림. 2차 정확도 + Richardson 외삽 적응 시간 간격.
- 결과
  - **채널 폭**: `ζ² < w_c² < ξ² + ζ²`. 즉 폭은 격자가 아니라 **비국소 문턱의 평균 길이 ξ 와 잡음 상관 길이 ζ** 가 정한다. 채널 수 `N_c ~ F / w_c`.
  - **분기 조건은 경계 조건의 기하**: 입구·출구 폭이 둘 다 w_c 보다 크면 평행한 직선 채널 여러 개, 둘 다 작으면 채널 1개, **입구 < w_c < 출구(또는 체적 내 균일 싱크)이면 입구 채널 하나가 출구 쪽에서 N_c 개로 갈라지는 수형 분기.** "채널 머리 수가 입구와 출구에서 다르면 그 사이를 잇는 분기점이 생긴다."
  - 유량이 일정하면 침식은 유한 시간에 멈춘다. 유량을 **천천히** 올려야(T ≫ 1) 선택적 침식이 되고, 급히 올리면 전면 씻김.
  - 되먹임 두 가지: (a) 침식으로 문턱 자체가 낮아짐, (b) 투과율이 큰 곳으로 유량이 재분배 → 느리게 깎이던 곳은 유량을 빼앗겨 침식이 멈춤.

### 3.4 Ocko & Mahadevan 2015, PRL "Feedback-induced phase transitions in active porous media". arXiv:1402.1547 **[본문]**
- 격자 입자 모델: 정사각 저항망에 입자(저항 20배)가 밀도 ρ̄ = 1/4 로 놓임. 균일 구동. 입자는 `r(v) = v^{−α_R}` 확률로 제거되어 `a(v) = v^{α_A}` 확률로 빈자리에 추가(입자 수 보존, 매 이동마다 전류 재계산).
- 결과: α_R, α_A 가 충분히 음(= 전류가 센 곳의 입자가 제거됨 / 전류가 약한 곳에 쌓임)이면 **흐름 방향 채널**, 양이면 흐름을 막는 벽. 40×40 격자.
- 연속체 선형 응답 (본문): `∂J_z(k)/∂ρ(k) = (∂κ/∂ρ) · k_x² / |k|²` — **파수의 크기와 무관, 방향만의 함수**. "입자는 상·하류의 전류를 억제하고 옆쪽 전류를 키우는 쌍극자형 상호작용". 저자 명시: 연속체 모델에는 **고유 길이 척도가 없어** 가는 구조와 굵은 구조의 전환을 설명하지 못한다.

### 3.5 [자체 유도] 타원형 스칼라 모델의 선형 안정성
Facca 꼴 `−∇·(μ∇u) = f, ∂_t μ = (μ|∇u|)^β − μ + D_m Δμ` 에서 균일 흐름(유량 q0, x방향) 바탕 상태 `q0^β = μ0` 에 `δμ e^{ik·x}` 섭동을 넣으면
```
δ|q| = G0 · δμ · sin²θ      (θ = k 와 흐름 방향 사이 각, G0 = |∇u0|)
성장률  σ(k) = β sin²θ − 1 − D_m k²
```
- 흐름에 **평행한 줄무늬**(k ⊥ 흐름, sin²θ = 1): σ = β − 1 − D_m k² → **β > 1 이면 불안정**. 흐름에 수직한 띠(sin²θ = 0)는 항상 감쇠(직렬 연결은 유량이 보존되므로).
- D_m = 0 이면 모든 파장이 같은 속도로 자란다 → 가장 가는 척도(격자 1칸)가 그대로 살아남음 = Facca의 "폭 = 요소 1개", HMPS의 격자 의존성과 일치. D_m > 0 이면 차단 파수 `k_c = √(β−1)/√D_m`, 관 폭 ~ `2π√(D_m/(β−1))`.
- 3.4의 Ocko–Mahadevan 선형 응답(`k_x²/|k|²`)과 같은 구조임을 확인.

## 4. Physarum 고유의 흐름·적응 문헌

### 4.1 Alim, Amselem, Peaudecerf, Brenner, Pringle 2013, PNAS 110:13306 "Random network peristalsis in Physarum polycephalum organizes fluid flows across an individual"
- 접근: **본문 못 읽음.** [2차] — Alim 2018 리뷰(arXiv:1801.02464 본문), Le Verge-Serandour & Alim 2023 리뷰(arXiv:2306.09063 본문), Marbach 등 2016 (arXiv:1611.08306 본문), Marbach–Ziethen–Alim 2023 (arXiv:2303.01439 본문).
- 확인된 내용 [2차]
  - 관 수축은 개체 전체에 걸친 **연동파**로 조직되고, **파장이 개체 크기(가장 긴 축)와 일치**한다(2 mm ~ 2 cm 이상, 두 자릿수 범위). 수축 주기는 크기에 따라 조금만 변한다. λ ≃ 5 mm, T ≃ 1~2 분, 파속 c = λ/T ≃ 50 µm/s (2303.01439).
  - 유체역학적으로 **개체 크기와 같은 파장이 망 전체에서 가장 큰 유속**을 만든다(1801.02464).
  - 흐름 계산법: 관 반지름 `a_j² = a_{j,0}² + 2 a_{j,0} ε e^{i(φ_j − ωt)}` 로 주기 수축을 주고, **마디마다 Kirchhoff 법칙**(부피 변화율이 소스)으로 전 망의 유량을 푼다. 제약: `Σ_j ΔQ_j = 0` — 수축하는 관이 있으면 반드시 팽창하는 관이 있어야 한다(2306.09063 5.3절, 1611.08306).
  - 수십 주기 시간에서는 망 부피가 일정 → 순 수송 없이 왕복류. 반 주기 만에 ~2 cm 수송.
- 수치(2차): 관 반지름 ~50 µm, 유속 최대 ~1 mm/s, Re ~ 1e−3, Womersley ~ 1e−2~1e−3, ω ≈ 0.05 Hz.

### 4.2 Alim, Andrew, Pringle, Brenner 2017, PNAS 114:5136 "Mechanism of signal propagation in Physarum polycephalum"
- 접근: **본문 못 읽음.** [2차, 2306.09063 5.4절]: 먹이를 만나면 수축 진폭이 먹이 근처에서 먼저 커지고, 그 신호가 망 안의 Taylor 분산 속도로 퍼진다. 신호가 흐름에 실려 가므로 큰 관을 따라 불균일하게 퍼지고, 진폭 증가가 다시 흐름을 키우는 되먹임. 후속(Kramar & Alim 2021): 신호(연화제)가 닿은 관은 5~15분 안에 굵어지고 닿지 않은 관은 부피를 빼앗겨 가늘어진다 → 굵기 위계가 먹이 위치의 기억.

### 4.3 Julien & Alim 2018, PNAS "Oscillatory fluid flow drives scaling of contraction wave with system size". arXiv:1806.05933 **[본문]**
- 1차원 능동 점탄성 관(윤활 근사), 식 (1)–(3),(5):

  한계: 졸/겔 분율이 상수, 투과율 되먹임 없음 → **채널/관은 생기지 않는다.** 고정 경계, 작은 변형.
- Kulawiak, Löber, Bär, Engel 2018 "Oscillatory motion of a droplet in an active poroelastic two-phase model". arXiv:1803.00337 **[본문]**: 위 모델의 1차원 자유경계 + 기질 마찰 γ 판 (식 (8)–(11)), `σ_act = T0 − ξ c/(1+c)`, `Pe = ξ/(D_c β)`. 규칙/불규칙 진동은 나오지만 **순 이동은 없다.**
- Kulawiak 등 2019, PLoS ONE 14:e0217447 "Active poroelastic two-phase model for the motion of physarum microplasmodia": **[초록]**. 총 칼슘 보존을 깨는 칼슘 반응 + 기질과의 **비선형 마찰** 둘 다 있어야 순 이동이 나온다. 1차원. 길이 ≳ 120 µm 에서 순 속도가 길이에 따라 증가.
- 시사점: 다공탄성 모델군은 **맥동 패턴과 (조건부) 이동**을 설명할 뿐, 정맥 형성은 다루지 않는다. 다만 "투과율이 커서 압력이 전역적으로 결합될 때 파장 = 계 크기"라는 결론은 4.1의 실험 사실과 맞고 우리 진단(5절)의 근거가 된다.

### 4.5 관 적응 법칙 (Physarum 실측 기반)
- Marbach, Ziethen, Alim 2023 "Vascular adaptation model from force balance". arXiv:2303.01439 **[본문 1~2절]**; Marbach 등 2023 eLife 는 **[2차]**.
  - 관 내 질량 보존(식 (5)): `∂_t(πa²) = −∂_z( −(πa⁴/8μ) ∂_z p )`.
  - 현상론(식 (2)): `(1/a) da/dt = (1/t_adapt)( f(τ) − f(τ0) )`, τ = 전단율 = 4Q/πa³, Physarum 은 **f(τ) ∝ τ²**.
  - 리뷰(2306.09063 5.2절)의 형태: `d〈a〉/dt = (〈a〉/t_adapt)( τ_s²/τ0² − 1 )`, `dτ_s/dt = −(τ_s − 〈τ〉)/t_delay`. **관의 저항 R 이 나머지 망의 저항 R_net 보다 작으면 안정, 크면 사라진다(R > R_net → coarsening).** t_adapt, τ0 는 망 내 위치에 따라 완만히 변하고 τ0 는 국소 정수압과 관련.
  - 정상 상태 τ = τ0 ⇒ Q ∝ a³ (Murray) ⇒ **C ∝ a⁴ ∝ Q^{4/3}** (초선형, Hu–Cai γ = 1/2 와 같은 지수).
- Almeida & Dilão (석사논문 2021, arXiv:2305.12244 **[본문 3·5장]**; 관련 arXiv:2111.15350): **부피 보존을 내장한 적응 법칙.**
  ```
  V = β Σ √D_ij L_ij = const
  d√D_ij/dτ = (V/β) · g(|Q_ij|) / Σ_km L_km g(|Q_km|)  −  √D_ij        (3.19)
  최소 소산: g = Q^{2/3}  ⇒  D_ij ∝ Q_ij^{4/3}                              (3.32),(3.34)
  일반화 g = |Q|^γ: γ ≈ 1/2 에서 위상 전이 — γ < 1/2 고리 많은 중복망, γ > 1/2 트리(D ∝ Q^{2γ}, 지수 > 1)
  ```
  저자 논지: 비압축 유체로 찬 망에서는 **굵어지는 관이 가늘어지는 관의 부피를 빼앗는다** — 부피 보존이 전역 제약으로 작동해 경쟁을 만든다. Tero 원형은 부피를 보존하지 않는다.
  성장 모델(5장): 먹이 = 소스, **성장 전선(경계 마디) = 싱크**. 전선에 영양이 쌓여 새 간선을 켜고(초기 D0), 전체가 (3.19)로 적응. 결과: 먹이에서 전선으로 가는 수형망. 저자 스스로 "Physarum 의 망상(고리 있는) 위계 구조는 재현 못 했다 — 고정 소스/싱크 선택 때문"이라고 적음. 먹이 두 곳을 **번갈아**(비동기) 구동해야 먹이 사이 직결 관이 재현됨.
- Ronellenfitsch & Katifori 2016, PRL "Global optimization, local adaptation, and the role of growth in distribution networks". arXiv:1606.00331 **[본문]**:
  `dK_e/dt = a (F_e/F̂)^{2γ} − b K_e + c`, 균일 소스 + 점 싱크, 현실적 망은 1/2 < γ < 1. **성장(= 시간에 따라 증가하는 관류)** 이 있으면 큰 정맥부터 생기고 차례로 작은 정맥이 생기는 위계적·전역 최적에 가까운 망. 무차원 수 ρ = b/(rγδ) (적응/성장 시간비), κ = (c/a)(F̂/Ŝ)^{2γ} (배경 생성). ρ, κ 가 크면 초기 조건과 무관한 결정론적·최적화된 상, 작으면 무작위로 얼어붙은 상. 마디 435개.
- 리뷰가 전하는 형태 사실(2306.09063 4.1, 5.1절): 전선은 처음엔 구조 없는 넓은 원형질 시트이고, 전진하면서 시트 안에 채널이 생기고 관 사이 얇은 층이 사라져 망이 된다. **왕복류 방향의 정맥은 강화되고 나머지는 사라진다.** 팬은 상류 망의 수축에 따라 부풀고 꺼진다. 다중 전선은 임계 곡률 κ = 2.5 mm⁻¹ 이하에서 자발적으로 생기며 점성 지문을 연상(역학 모델은 아직 없음 — Baumgarten, Jones, Hauser 2015 인용). 시트→망 재구성을 다룬 모델로 Schenz 등 2017 (J. Phys. D 50, 강화 모델 + 반응확산 + 겔-졸)이 인용됨 — **본문 못 읽음**.

## 5. 진단 — 우리 연속체 프로토타입에서 채널화가 안 된 이유

대상: `continuum.py` (p = κ(h − h* − ηD) + A sin φ + …, q = −(m0 + m_D D) h_상류 ∇p, dD/dt = r_D( f/(1+f) − D ) + diffD ΔD, f = (q̄/q0)^γ, γ = 1.5).

### (가) 유체역학적 침투 깊이가 몸보다 한두 자릿수 짧다 — 몸 규모의 유량이 없다 [자체 유도, 프로토타입 파라미터 사용]
- 국소 탄성벽이면 압력 섭동은 확산 계수 `K_p = (m0 + m_D D)·h·κ` 로 퍼진다. 각진동수 ω 로 흔들 때 침투 깊이 `δ = √(2K_p/ω)`.
- 프로토타입 값: κ = 1, h ≈ 1~2.5, m0 = 0.02~0.1, m_D ≈ 1, ω = 0.05~0.1.
  관 없는 곳(K_p ≈ 0.02~0.25): **δ ≈ 0.6~3 셀.** 관이 꽉 찬 곳(K_p ≈ 1~2.5): **δ ≈ 4.5~10 셀.** 몸 반지름은 12~60 셀. (범위는 ω = 0.05 와 0.1 양쪽을 포함)
- 따라서 한 점의 유량은 반경 몇 셀 안의 위상 기울기로만 정해진다(q ≈ −M h A cos φ ∇φ). 실제 점균에서는 한 단면의 유량이 **그 하류 전체의 부피 변화율 적분**(4.1)이고, 이것이 "간선은 굵게, 말단은 가늘게"의 원천이다.
- 명시적 갱신으로는 못 고친다: 안정 조건 K_p·dt ≤ 0.25 에서 δ = R 을 맞추려면 주기당 스텝 수 ≳ 12.6·R² (R = 300 셀이면 주기당 ~1e6 스텝). ⇒ **압력을 타원형(또는 암시적)으로 풀어야 한다.** spec 의 "압력 포아송 방정식을 풀지 않는다"가 바로 이 실패의 뿌리다.
- 문헌 대응: Radszuweit 2014 — 항력이 작아 압력이 전역 결합될 때만 파장 = 계 크기. Alim 2013 — 파장 = 개체 크기일 때 유속 최대.

### (나) 경쟁이 없다 — 양의 되먹임만 있고 "남의 유량을 빼앗는" 구조가 없다
- Tero/Hu–Cai/Facca/Derr 모두에서 관이 가늘게 남는 이유는 **고정된 총 유량**(I0, S, F)을 평행 경로가 나눠 갖기 때문이다. 한 경로가 강해지면 다른 경로의 유량이 실제로 줄어든다(3.2, 3.3). Almeida–Dilão 는 여기에 **부피 보존**이라는 두 번째 전역 제약을 더한다.
- 프로토타입에서는 유량이 국소적으로 만들어지고 국소적으로 저장된다(압축성). D 를 올려도 이웃의 유량이 줄지 않는다. 그러면 `dD/dt = r_D(f/(1+f) − D) + diffD ΔD` 는 **쌍안정 반응-확산식**과 같아져, q̄ > q0 인 영역이 통째로 D → 1 로 가는 얼룩(전선 전파)만 남는다. 관찰된 "뭉툭한 얼룩"과 일치.
- 지수는 문제가 아니었다: γ = 1.5 > 1 은 이미 초선형이다.

### (다) 진동 패턴의 파장이 몸보다 훨씬 짧다
- 초기 위상이 무작위이고 결합 K = 0.05 (셀²/스텝)이라 파장 4~5 셀 정도의 동심 과녁파가 된다(`result-continuum.png` 맨 아래). 타원형으로 풀더라도 파장 λ 의 수축 패턴이 만드는 유량은 `|q| ~ 진폭 × λ/2π` 로 λ 에 비례한다.
- [자체 수치 점검] `peristalsis_check.py` (96², 타원 풀이, 같은 진폭 0.02): 파장 = 몸 지름 → 평균 유량 0.22, 관 형성. 파장 = 0.2×지름 → 평균 유량 0.04, D 최댓값 0.25 수준의 약한 줄무늬에 머묾(초기값 1 에서 감소). 방사 과녁파 파장 0.1×지름 → 평균 0.02, D ≈ 0.04 (동심 고리 무늬만, 관 없음). `montage2.png`.

### (라) 위계를 만드는 "수렴하는 기하"가 없다
- 균일 진폭 평면파는 타원형으로 풀어도 평행한 줄무늬 채널만 만든다(위 점검의 첫 그림). 굵기 위계는 **유량이 모이는 기하**(국소 소스 ↔ 넓게 분포한 싱크)에서 나온다 (Derr: 입구 < w_c < 출구; Almeida–Dilão: 먹이 → 전선; Ronellenfitsch–Katifori: 균일 소스 → 점 싱크).
- 실제 점균에서는 "뒤가 빠지고 앞이 나가는" 순 수송과, 팬이 크게 부풀고 꺼지는 진폭 비대칭이 이 기하를 준다.

### (마) 부수 요인
- 전도도 대비가 작다(m0 : m0+m_D ≈ 1:10 ~ 1:50). 문헌은 r = 0.005~0.1 대 |m|² ~ O(1~100), 또는 μ 가 여러 자릿수. 대비는 성장률과 선명도에 영향(필요조건은 아님).
- 고유 폭 척도가 없다: 타원형으로 바꾸면 이번엔 관이 1셀 폭으로 붕괴한다(Facca). 정칙화가 필요(6절).

### 스칼라 D 로는 왜 안 되는가/되는가 — 정리
- **된다.** 등방 스칼라라도 유량 보존이 방향 선택을 해 준다(3.5: δ|q| ∝ δμ sin²θ). Facca(β>1), Mahadevan², Derr 가 모두 스칼라 장이다.
- HMP 가 벡터 m 을 쓰는 이유는 투과율을 `rI + m⊗m` 로 두어 관 방향으로만 전도를 키우려는 모델링 선택이고(2111.03889: "the flow feels only r in directions orthogonal to m"), 텐서 C-모델은 그 일반화다. 벡터/텐서의 실익: 교차하는 관 표현, 격자 간선 전도도와의 정확한 대응(2.3), m-모델과 달리 C-모델은 씨앗 없이 성장.
- 스칼라의 약점: 고유 길이 척도 부재(폭 = 격자 1칸, 격자 정렬). 벡터/텐서 모델도 D 가 격자 이하이면 똑같이 격자 의존.
- **안 되는 경우**는 스칼라여서가 아니라 압력이 국소적이어서다(우리 경우).

## 6. 채널화에 필요한 조건 (구현 체크리스트)

1. **타원형 압력**: `∇·(C ∇p) = S`, ΣS = 0. C = r + D (스칼라) 또는 간선 전도도 (c_x, c_y). r > 0 필수(조건수: r/C_max ≳ 1e−3 권장 — 2301.12926 에서 r = 1e−3 이면 대칭 붕괴 시작).
2. **소스/싱크가 물리량에서 나와야 한다**: S = −(능동 부피 변화율). 직류 성분 = 후퇴하는 뒤(소스) → 전진면(싱크). 교류 성분 = 연동 수축, **파장 ≳ 몸 크기**.
3. **초선형 강화**: 정상 상태 C ∝ |q|^μ, μ > 1. 문헌 값: μ = 4/3 (Murray/Physarum/Hu–Cai γ=1/2), Facca β = 1.1~3 (1.5 가 대표), Tero μ = 1.8. HMP 표기로는 1/2 ≤ γ < 1 (γ = 0.75 가 잎맥형, γ > 1 은 망 없음, γ < 1/2 는 붕괴).
4. **고정 유량 구동**: 압력 고정이 아니라 유량(부피 변화율) 고정. 압력 고정은 "무반응 아니면 전면 씻김"(Mahadevan²).
5. **느린 적응**: 적응 시간 ≫ 압력 수렴 시간. 유량을 서서히 올릴 것(Derr T ≫ 1, Ronellenfitsch–Katifori 의 성장 효과). 급하면 무작위로 얼어붙은 저품질 망.
6. **폭 정칙화**(택1 또는 조합): (a) 확산 D_m Δ — 폭 ~ 2π√(D_m/(β−1)), 2~10셀이 되게; (b) 포화 `f = F_max q^β/(1+q^β)` — 셀당 전도도 상한 때문에 큰 유량 간선이 **넓어진다**(폭 위계) + 대비가 유한해 반복법 수렴에 유리; (c) Derr 식 비국소 문턱(가우시안 블러 길이 ξ) — ζ² < w² < ξ²+ζ²; (d) 잡음 상관 길이.
7. **씨앗/잡음**: 균일 초기값 + 1~5% 잡음이면 충분(Facca μ0 ≡ 1, Astuto C0 = I, Derr σ_φ = 0.02). m-모델을 쓸 때만 m0 ≠ 0 필요.
8. **고리**: 정적 소스/싱크는 트리만 만든다. 고리는 시간에 따라 바뀌는 소스/싱크(요동)에서 나온다(Hu–Cai, Klemm–Martens, Almeida–Dilão 의 교대 구동). 적응은 〈q²〉 의 시간 평균에 반응시키면 된다.
9. **수렴 기하**: 전진면을 넓은 싱크(띠), 몸 뒤쪽/먹이/핵 주변을 좁은 소스로.

## 8. 실험 담당자를 위한 제안 (우선순위 순)

1. **진단 재현**: 프로토타입에서 압력만 타원형으로 바꾼 최소 변형(고정 원판 몸, 소스 = 중심, 싱크 = 가장자리 띠)을 256²~512²로 올려 7절 결과가 유지되는지 확인. 반대로 암시적 탄성벽(차폐 Poisson `(1/(κ dt) − ∇·C∇)p = rhs`)에서 차폐 길이를 2셀 → 몸 크기로 키우며 관이 나타나는 문턱 δ/R 을 찾으면 5절 (가)의 직접 검증.
2. **소스를 h 동역학에서 유도**: S_DC = 전진면의 부피 흡수(+)와 후퇴부의 방출(−). 이것만으로 "뒤 굵은 간선 → 앞 잔가지"가 나오는지.
3. **페이저 압력**: 연동 소스를 복소 진폭(RG 텍스처)으로 두고 p̂ 을 풀어 `〈q²〉 = ½|C∇p̂|²`. p̂ 은 C 와 위상 패턴이 변할 때만 변하므로 웜스타트 Jacobi 가 프레임을 넘어 누적 수렴. 위상장은 몸 규모 파장이 되게(뒤→앞 선형 위상, 또는 결합을 크게).
4. **폭 정칙화 비교**: D_m 확산 / 포화 / 가우시안 블러 문턱(Derr) / 이질성 잡음. 지표: 관 폭 분포, 간선–지선 굵기 비, 격자 방향 편향(0°/45° 히스토그램).
5. **간선 전도도(대각 텐서) 판**: (c_x, c_y) 2채널 Hu–Cai 원형 `∂_t c^k = D²Δc^k + (∂_k p)² − ν|c^k|^{γ−2}c^k`, γ = 0.5~0.75, 정칙화 ε. 스칼라 판과 격자 정렬·교차 표현 비교.
6. **고리**: 소스/싱크를 시간에 따라 바꿈(먹이 쌍 교대, 위상 기울기 방향 회전). 〈q²〉 평균 창 길이 대 적응 시간의 비를 스윕.
7. **부피 보존형 적응**(Almeida–Dilão): 전역 합 Σ g(|q|) 는 밉맵 축소로 얻을 수 있다. D 를 h 의 목표 두께 h* 에 묶어 "굵어지는 관이 다른 곳의 부피를 빼앗는" 경쟁을 h 보존으로 구현하는 변형.
8. **침식형 대안**(Guy/Derr 계열): 겔 분율 φ, κ(φ) = (1−φ)³/φ², `∂_t φ = −φ·max(0, |∇p|² − ψ(φ̄)) + 재겔화`. 유량 고정 + 느린 램프 필수.
