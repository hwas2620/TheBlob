## 1. Marbach, Ziethen, Bastin, Bäuerle, Alim 2023, eLife 12:e78100
"Vein fate determined by flow-based but time-delayed integration of network architecture"

- 접근: https://pmc.ncbi.nlm.nih.gov/articles/PMC10234634/ (HTML 전문 + 부록 1~4 **[본문 정독]**)
- 로컬: `dl2/marbach2023-elife/pmc.html`, 텍스트 변환 `work_alim/marbach2023.txt` (MathML 을 직렬화. 식 표기는 아래에 그대로 옮김)
- eLife 는 쪽 번호가 없어 절 이름·식 번호로 표기.

### 1.1 계측 (본문 "Quantifying vein dynamics", 부록 1)
- 관 반지름 범위 `a = 5–70 μm`. 연동 수축 주기 `T ≃ 1–2 min`. 장시간 평균은 창 `t_ave ≃ 2–3 T (T ≃ 120 s)` 이동평균.
- 전단율 정의: `τ = (4/π) |Q| / a³`. (전단응력 = μτ. 점도를 몰라도 되므로 전단율 사용.)
- 유량 Q 는 수축 주기마다 방향이 뒤집히므로 0 주위로 진동, `τ` 는 |Q| 때문에 수축 진동수의 2배로 진동(부록 1—그림 1).
- 전체 망 유량 계산(부록 1 "Flow calculation from vein contractions", Alim 2013 방식):
  - 각 관 조각 i (노드 n–p) 에 수축이 만드는 유량 `Q_in,np = 2π a_i L_i ∂a_i/∂t`.
  - 노드마다 Kirchhoff: `Σ_p Q_0,np + Q_in,np = 0` (A1.1) → `Σ_p Q_in,np = −Σ_p Q_0,np = −Q_p` (A1.2)
  - Poiseuille: `P_n − P_p = −Q_0,np R_np` (A1.3), `Q_p = Σ_p (P_n − P_p)/R_np` (A1.4) → 선형계 `Q = G P` 를 풀어 노드 압력.
    (원문은 여기서 "R_np = π a_i⁴/8μL_i" 라고 썼는데 이것은 전도도 꼴이다. 본문·표의 저항 정의는 `R = 8μL/πa⁴`. 원문 표기 불일치.)
  - 관 조각 압력 `P_i = (P_n + P_p)/2`.
  - 실측 `a_i(t)` 를 그대로 넣되 (1) 매 시각 전체 원형질 질량이 보존되도록 보정(영상에서 잰 질량 변동 < 10%), (2) 프레임 사이 2점 선형보간, 시뮬레이션 간격 `Δt = 2 s`(촬영 간격 6 s 의 1/3).
  - 사라지는 조각은 사라지기 직전 `−π a_i² L_i / Δt` 의 유입을 추가(반지름 수축에 해당).
  - 새 관 생성은 다루지 않음("no substantial growth occurs in our data").
- 유속: 전형적으로 최대 1 mm/s (Bykov 2009 인용). 유속은 50–60 s 시간 규모로 변함.
- 표본: 무영양 1.5% 한천, 하룻밤 자란 망을 잘라 1시간 뒤 약 1시간 촬영(10 fpm). 전체 망 #1 은 관 조각 약 10,000 개, #2·#3 은 약 30,000 개.

### 1.2 적응식 (본문 식 1, 2, 3)
- 식 (1): `d⟨a⟩/dt = (⟨a⟩ / t_adapt) ( τ_s²(⟨τ⟩)/τ_0² − 1 )`
  - `⟨a⟩`: 수축 주기를 평균한 반지름. `τ_s`: 관 벽이 "감지한" 전단율. `τ_0`: 기준(목표) 전단율. `t_adapt`: 벽을 키우거나 해체하는 시간.
  - 2차 의존(`f(τ_s) ∝ τ_s²`)은 동반 논문(Marbach, Ziethen, Alim 2023 NJP)의 힘 평형 유도에서 옴. "our upcoming results are robust against the specific choice of f(τ_s), as long as f increases with |τ_s| and there exists a non-zero value of shear rate τ_0 ... such that f(τ_0)=0".
- 식 (2): `dτ_s/dt = −(1/t_delay)(τ_s − ⟨τ⟩)` — 1차 저역통과(지연).
- 정상상태: `⟨τ⟩ = τ_s = τ_0` = Murray 법칙(전단율 일정).
- 식 (3) (관 하나 + 나머지 망의 등가회로, Norton 정리):
  - 관 저항 `R = 8μL/(π⟨a⟩⁴)`, 나머지 망의 등가저항 `R_net` (그 관의 양 끝에서 본 나머지 전체).
  - 수축이 만드는 시간평균 순유량: `Q_in = ⟨| L d(πa²)/dt |⟩ ≃ 8π L ε ⟨a⟩²(t) / T` (ε: 상대 수축 진폭). `Q_net = −Q_in`.
  - Kirchhoff 2법칙 `Q R = −(Q + Q_net) R_net` → `Q = Q_in R_net/(R + R_net)` (A3.2)
  - `⟨τ⟩ ≃ 4|Q| / (π⟨a⟩³) = [4 Q_in(⟨a⟩) / (π⟨a⟩³)] · 1 / (1 + R(⟨a⟩)/R_net)` (3)
  - 풀어 쓰면 (A3.7): `⟨τ⟩(⟨a⟩) ≃ (32 L ε / T) · ⟨a⟩³ / (⟨a⟩⁴ + 8Lμ/(πR_net))`
- 힘 평형 원형(부록 2, 식 A2.1): `0 = 2πaL( (P − P_0) + σ_circum + σ_active + σ_r(μτ_s) ) − γL da/dt`
  - 시간평균 후 `⟨σ_circum⟩ ≃ 0`, `⟨σ_active⟩` 는 음수 상수(관을 줄이는 쪽 = 대사 비용), `σ_r(μτ_s) ≃ μ τ_s²/τ_c` (전단을 받은 가교 액틴 겔의 수직 응력, 관을 넓히는 쪽).
  - `τ_target = −(1/μ)⟨P − P_0⟩ + τ_active`, `τ_active = ⟨σ_active⟩/μ`, `τ_0 = sqrt(τ_c τ_target)`, `t_adapt = γ/(2πμτ_c)` (A2.2).
  - 즉 **목표 전단율이 국소 압력에 의존**: `τ_0 ∼ τ_active − ⟨P − P_0⟩/μ`. 압력이 높으면 τ_0 가 낮아져 관이 자라기 쉽다.
- Murray 와의 대응(A2.3): `E = ½Q²R + πbLa² = 4μLQ²/(πa⁴) + πbLa²` 최소화 → `a_optimal⁶ = 8Q²η/(bπ²)`, `τ_optimal = sqrt(b/μ)`.

### 1.4 안정/소멸 조건 (본문 그림 3, 부록 3·4)
- 계 (τ_s, ⟨a⟩) 의 고정점: 안정 (0,0) [관 소멸], 안정 (τ_0, ⟨a⟩_stable) [Murray 상태], 그 사이 안장점 (τ_0, ⟨a⟩_unstable).
- 고정점이 있을 조건: `max_⟨a⟩ ⟨τ⟩(⟨a⟩) ≥ τ_0`.
  - 원문 (A3.8): 최댓값 위치 `⟨a⟩ = (21μL/(R_net π))^(1/4)`, (A3.9): `(32πεR_net/(29μ)) (21μL/(R_net π))^(3/4) ≥ τ_0`.
  - [내 검산] (A3.7) 을 미분하면 `⟨a⟩⁴ = 3·8μL/(πR_net) = 24μL/(πR_net)`, 최댓값 `(επR_net/(Tμ)) (24μL/(πR_net))^(3/4)` 가 나온다. 원문의 21, 29 와 T 누락은 오식으로 보인다(원문 표기는 위 그대로).
- (0,0) 고윳값: `λ = −1/t_adapt, −1/t_delay` (항상 안정).
- 작은 반지름 극한: `⟨τ⟩ ≃ 4R_net ε π ⟨a⟩³/(Tμ)` (A3.11) → 안장점 `⟨a⟩_1 = ½ (2Tμτ_0/(R_net ε π))^(1/3)`.
- 큰 반지름 극한: `⟨τ⟩ = (32Lε/T)/⟨a⟩` → 고정점 `⟨a⟩ = 32Lε/(Tτ_0)`, 고윳값 (A3.14) `λ = (−√t_adapt ± √(t_adapt − 8 t_delay)) / (2 √t_adapt t_delay)`.
  - **`t_adapt > 8 t_delay` 이면 단조 안정, `t_adapt < 8 t_delay` 이면 안정 나선(시계 방향)**. 실측 t_delay ≈ 2 min → 경계는 t_adapt ≈ 16 min.
- **상대 저항 규칙**: `R/R_net > 1` 이면 줄어들고, `R/R_net < 1` 이면 안정/성장. R/R_net 은 관 굵기와 상관이 없고(부록 1—그림 6) 큰 관("highway")과의 위치 관계를 나타냄: 큰 관에 바로 붙은 작은 관은 R ≫ R_net (소멸), 작은 관들 사이의 작은 관은 R_net ≫ R (안정). 유량을 풀지 않고 구조만으로 계산 가능.
- **막힌 가지(dangling end)**: R_net 정의 불가. `⟨τ⟩ = 4⟨|Q_in|⟩/(π⟨a⟩³) ≃ 32Lε/(⟨a⟩T)` (A4.1). 안정 고정점 없음 → 사라지거나 무한히 자람. 임계 반지름 (A4.2) `a_c = 32Lε/(Tτ_0) ≃ 32Lμε/(T(μτ_active − ⟨P − P_0⟩))`. `⟨a⟩ ≥ a_c` 이면 성장. **국소 압력 ⟨P⟩ 가 크면 τ_0 가 낮아져 성장**, 작으면 소멸. 실측 압력 지도는 대체로 균일하고 막힌 가지 쪽에서만 차이가 큼. (그림 5A: 처음 반지름이 같은 ~23 μm 막힌 가지가 압력에 따라 갈림.)
- **평행 관**: (A4.7) `τ_i = [4/(πa_i³)] (Q_in,1 + Q_in,2)/(1 + R_i/R_net,i)`, `1/R_net,1 = 1/R_net + 1/R_2`. (a_c, a_c) 는 불안정 → 한쪽이 반드시 진다. `R_1 > R_2` 인 쪽이 소멸.
- **고리**: 고리 가운데(망과 이어진 노드에서 가장 먼 곳)부터 줄어듦. 가운데 조각이 줄면 질량이 바깥 조각으로 재분배되어 바깥 조각의 전단율이 올라가 버틴다. 가운데가 끊기면 양쪽이 막힌 가지가 되어 압력 규칙을 따른다. (A4.10–A4.12)
- **눈사태**: 관 하나가 사라지면 노드 2개가 없어지고 이웃 관이 "더 긴 관"이 되어 저항이 커짐 → R/R_net > 1 → 연쇄 소멸. 최소 모형(그림 6C): 모든 관 R = r, 섭동 관 2r, `r/R_rest = 0.1`. 드물게는 반대로 안정화(그림 6A 16 min).

### 1.5 한계
- 새 관의 생성·전진면은 다루지 않는다(자르고 굶긴 망의 자발적 재편만).
- t_adapt, τ_0 는 관마다, 시간 창마다 다르다(15–40 min 창에서는 상수로 볼 수 있으나 ≳ 40 min 에서는 아님).
- ε(수축 진폭) 실측값은 본문에 수치로 주어지지 않음(검증용 모형 자료에서 0.2 를 씀: `a(t)/a_0 = (1 + 0.2 sin[...])(1 + 0.2 cos[...])`).

### 1.6 우리 모델에 주는 시사점
- 간선 전도도 강화는 `dC/dt ∝ f(|Q|) − C` 한 줄이 아니라 **(i) 주기 평균한 전단율 τ = 4|Q|/πa³, (ii) 1차 지연 τ_s, (iii) a 에 비례하는 성장률**의 세 단계로 쓰면 원문과 같다. 반지름으로 쓰면 `da/dt = (a/t_adapt)(τ_s²/τ_0² − 1)`. 전도도 C ∝ a⁴ 로 바꾸면 `dC/dt = (4C/t_adapt)(τ_s²/τ_0² − 1)`.
- 시간 비: `T : t_delay : t_adapt ≈ 1 : 1 : 5–50` (T 2 min, t_delay 2 min, t_adapt 10–100 min). 관 소멸 15–40 min ≈ 8–20 T.
- `τ_0` 를 상수로 두지 말고 압력에 묶으면(`τ_0 = τ_active − κ(P − P_0)`) **압력이 높은 쪽의 막힌 가지가 자란다** — 전진면 쪽 막힌 가지를 살리고 뒤쪽 막힌 가지를 죽이는 규칙으로 바로 쓸 수 있다.
- 유량원은 "중심 소스 + 전진면 싱크"가 아니라 **모든 관이 스스로 펌프**(`Q_in = 2πaL ∂a/∂t`, 주기 평균 `8πLε a²/T`)라는 점이 원문 모델의 핵심. 굵은 관일수록 더 많이 퍼낸다(Q_in ∝ a²).

## 2. Kramar & Alim 2021, PNAS 118(10):e2007815118
"Encoding memory in tube diameter hierarchy of living flow network"

- 접근: https://pmc.ncbi.nlm.nih.gov/articles/PMC7958412/ (HTML 본문 전체 **[본문 정독]**. SI Appendix 는 못 읽음 — PMC 의 보충 파일·그림은 cdn.ncbi.nlm.nih.gov 에 있고 그 호스트는 프록시가 거절)
- 로컬: `dl2/kramar2021-pnas/pmc.html`, `work_alim/kramar-body.txt`. 식 번호는 원문 [1]–[4]. 그림은 캡션만 읽음.

### 2.1 관찰 (Results)
- 먹이 자극 후 **약 15 min 안에 관 지름의 새 공간 분포가 생기고 45 min(실험 끝)까지 유지**. 45 min 안에 자극 쪽으로 새 이주 방향이 생기고 90, 310 min 에 그쪽으로 이주. 먹이를 다 먹은 뒤에도 먹이 자리 둘레에 굵은 관의 고리가 남음(그림 1).
- 자극 가까운 관은 지름 증가(최대 2배, "up to twofold"), 먼 관은 부피 감소(유체 부피 보존). 자극을 향한 굵은 관은 굵어지고, 가는 관은 일반적으로 가늘어지되 자극에서 멀수록·굵은 관에서 멀수록 더 많이 줄어듦 → 지름 위계가 커짐. N(tubes) = 2,165.
- **확장 전선의 속도 `15 μm/s`** — 망 안에서 입자가 이류되는 속도와 같고, 압력 변화보다 몇 자릿수 느리고 확산보다 빠름. 전선이 불균일하게 퍼지므로 확산이 아님(SI 그림 S2, S3). 전단율이 원인이 아님을 직접 관찰로 배제(SI 그림 S4).
- 전체 망에서 수축 진폭이 일시적으로 증가(SI 그림 S5) — 벽 연화와 부합.
- 굵은 관이라도 자극에서 "유동 이동 시간"이 먼 것은 크게 줄어듦(지름 ≈ 50% 감소, 그림 5). 즉 단순한 "굵은 관 자기강화"가 아니라 **자극으로부터의 유동 도달 시간**이 결정.
- 반응 시간(자극 → 먼 관의 지름 최소)은 수축 진동수가 낮을수록 길어짐(10, 8, 6, 4 mHz 자료, 그림 4D). 수치는 그림에만 있음 [그림 미열람].
- 한가한 망은 가는 관부터 가지치기(인용 23, 24) → 기억을 담은 굵은 관이 가장 오래 남음.

### 2.2 모델 (Results "Mechanism of Encoding Memory...", 식 [1]–[4])
망 크기의 닫힌 관 하나(길이 L, 반지름 a(z,t)), 얇은 탄성 능동 껍질 + 비압축 저 Re 유체(Re ∼ 10⁻³).
- 벽 응력 `σ(z,t) = σ_T + σ_E`. 수축 응력 `σ_T = A cos(ωt − kz)`, 탄성 복원 `σ_E = E/h (a − a_0)`.
- [1] 윤활 근사 Stokes: `ū = −(a²/8μ) ∂/∂z (σ_T + σ_E)`
- [2] 연화: `E = E_0 − δE ⟨c⟩/(⟨c_0⟩ + ⟨c⟩)` (⟨c⟩: 시간평균 농도, ⟨c_0⟩: 자극 자리에서 방출된 농도의 시간평균)
- 시간평균(수축 2주기): `∂⟨c⟩/∂t = (⟨c⟩ − c)/τ` (원문 표기 그대로. 부호는 원문대로 옮김 — 완화식이라면 (c − ⟨c⟩)/τ 가 되어야 하므로 원문 오식 가능성) τ: 탄성률의 자극-반응 시간.
- [3] Taylor 분산 + 감쇠: `∂c/∂t = ∂/∂z{ −ū c + (κ + ū a²/(48κ)) ∂c/∂z } − k_deg c`
  (PMC 판 MathML 에는 ū 에 제곱이 없다. 표준 Taylor 분산과 Alim 2013/2017 의 식은 `ū² a²/(48κ)`. [원문 PDF 미확인])
- [4] 질량 보존: `∂a²/∂t = −∂/∂z (a² ū)`
- 한 번만 방출(감지 반응만. 먹이를 삼키는 수 시간 규모는 모델 밖).

### 본문 글에서 직접 확인한 것
- 왕복류 주기 "about 100 s". 형태 재편 시간 규모 "∼45 min" ≫ 유동 생성 시간 규모 "∼100 s". 그림 3A 개체의 수축 주기 평균 ± SD = **131 ± 43 s**. 수축 주기는 개체 전체·1.5 h 동안 크게 변하지 않음.

- 압력 풀이의 소스항은 **위상이 한 바퀴 도는 진동 소스** `S(x,t) = −∂h/∂t ∝ ε ω sin(ωt − φ(x))`, `∮ S = 0` (부피 보존)이어야 한다. 정적 "중심 소스 + 전진면 싱크"는 이 문헌들과 다른 가정이다(단, 성장/이주 때의 순이동은 아래 4절).

### 차원 해석과 모델 (p.3735, p.3737)
- 가정 v ∝ h, 그리고 v 가 {ρ, μ, p, τ, D} 중 h 를 포함한 최대 3개 양의 함수 → 유일해 **`v = constant × p h / μ`**.
- 돔 모형: 반지름 h 인 외질 피질이 졸을 감쌈. `p ∝ τ/h` (Laplace), Stokes 에서 `p/h ∼ μ v/h²` → `v ∝ (p/μ) h = τ/μ`. 따라서 (i) μ 가 h 와 무관하면 피질 장력 τ ∝ h, 또는 (ii) τ 가 일정하면 유효 점도 μ ∝ h⁻¹.
- 근거 실험(Takagi 2007 인용): **잘라낸 앞 끝은 규칙적인 두께 진동 없이도 한동안 같은 속도로 이주** → "migration ability can be localised at the frontal tip", "the engine in the frontal tip is a self-organised local structure". ATP 농도는 앞에서 높고 뒤로 낮아짐(Mori 1986, Ueda 1987).
- 반응-확산 모델(식 4, 5; Takagi 2007, Ueda 2011 을 따름):
  - (4) `c_t = D_C c_xx + f(c, h; a)`
  - (5) `h_t = D_h h_xx + ε g(c, h)`
  - c: 졸-겔 전환을 맡는 화학물질 농도, h: 몸 두께, a: C 의 활성 수준. `D_C ≫ D_h`, `ε ≪ 1` (τ_c ≪ τ_h; c 빠름, h 느림).
  - `f(c,h;a) = c(1−c)(c−a) − h`, `g(c,h) = c − h` (FitzHugh–Nagumo 형).
  - ε → 0 에서 전선 속도 **`v* = √(2 D_C) [(1/2) − a]`** (Kawahara & Tanaka 1983).
  - 확장: 전면 영역 `X_front = {x; c(x,t) > 0.05}` 에서만 `a_front(t) = 0.2 + 0.19 sin(20πt)`, 그 밖은 a = 0.2 → 진동하는 전선과 요철 있는 꼬리(그림 11). D_C, D_h, ε 수치는 본문에 없음.

### 시사점
- 전진면은 "앞이 가장 두껍고 뒤로 지수 감소하는 펄스"의 선두다. 게임에서 전진면 뒤에 두께가 `exp(−x/α)` 로 줄어드는 띠를 두고, α 와 h_max 를 보낸 부피(단위 폭당)로 정하면 실측과 맞는다: `h_max ∝ V_l^0.4`, `α ∝ V_l^0.6`.
- 전진 속도 규칙 `v ∝ h_max` (0.17 mm/min per mm) — 전면 두께에 비례. **전진면 폭(가로 확장)은 속도 결정에 직접 관여하지 않는다**는 것이 저자들의 결론.

## 5c. Ma, Johansson, Tero, Nakagaki, Sumpter 2013, J. R. Soc. Interface 10:20120864
"Current-reinforced random walks for constructing transport networks"

- 접근: https://pmc.ncbi.nlm.nih.gov/articles/PMC3565737/ (HTML 본문 글 전체 **[본문 글 정독]**. **식 2.1–4.1 은 전부 그림 파일이라 미열람**. 아래 식 꼴은 본문 문장에서 재구성한 것이며 [재구성] 으로 표시)
- 로컬: `dl2/ma2013-jrsi/pmc.html`, `work_alim/ma2013-body.txt`

### 규칙 (글로 확인)
- 변수(표 1): `l_ij` 길이, `N_i` 노드의 입자 수(= 전위 / Physarum 에서는 영양·압력), `I_ij` 전류(영양 흐름), `D_ij` 전도도(관 굵기 / 페로몬), `C_i` 용량(노드의 총 페로몬 밀도), `q` 강화 세기(관 확장률), `λ` 전도도 감소율(관 감쇠율).
- 흐름: Ohm 법칙 — 평균 유량이 `D_ij (N_i − N_j) / l_ij` 에 비례 [재구성, 식 2.7]. Δt 동안 실제로 옮겨 가는 입자 수는 그 평균의 **Poisson 난수**(식 2.5). 방향은 N_i − N_j 의 부호(한쪽으로만 흐름, I_ij = −I_ji).
- 노드 갱신(식 2.6): 들어오고 나간 입자 수만큼 N_i 갱신. 소스에는 일정률 유입, 싱크에서는 일정률 유출.
- **전도도 갱신(식 2.8)**: "at each step the conductivity of each edge decreases slightly, but the edges with current have their conductivity increased" — `D_ij ← D_ij + q |I_ij| − λ D_ij Δt` [재구성]. Δt → 0 평균장 극한(식 2.9) `dD_ij/dt = q |Ī_ij| − λ D_ij` [재구성] = Tero 의 Physarum solver.
- q, λ 가 작으면 D 는 느린 변수, N 은 빠른 변수 → N 을 평형(Kirchhoff)으로 두고 매번 푸는 것이 Tero 방식. 확률적 방식은 **전역 풀이 없이 국소 정보만** 쓴다(병렬 구현에 유리)는 것이 이 논문의 요점.
- **밀도 강화와의 차이**(2.3절): 밀도 강화는 i→j 와 j→i 통행량의 합으로 강화(식 2.13) → 입자가 자기 되먹임 고리에 갇혀 소스 근처에 머물고 최단 경로를 못 만든다(그림 3d). 전류 강화는 순유량(차)으로 강화 → 고리가 상쇄.
- **생물학적 변형**(2.4절): 전위를 입자 수가 아니라 `N_i / C_i` 로(식 2.16), `C_i = Σ_j D_ij / l_ij`(식 2.15, 문장: "the total pheromone density going in and out of node i"). 이렇게 하면 흐름이 없는 곳에 입자가 쌓여 있지 않게 된다. 2차 이웃 정보가 필요.
- 비대칭 solver(식 2.17): ij 와 ji 방향 전도도를 따로 두고 흐름 방향 쪽만 강화 → 최단 경로 수렴 증명(Ito 2011).
- **수송망(3절)**: 선형 강화는 "소스에서 각 싱크로 가는 1:1 최단 경로의 합집합"(경로 계수는 최소지만 총 길이가 큼). **비선형 강화(식 3.3) — 유량의 μ 제곱(μ > 1)으로 강화** `q |I_ij|^μ` [재구성] → 소스 근처에서 경로를 공유하는 줄기 + 가지 구조. μ > 1 인 최적화 문제는 NP-hard.

### 시사점

## 6. 종합 — 반드시 답할 것

### (a) 정맥 굵기 적응의 식과 실측 시간 상수
- 식(Marbach 2023, 식 1–3): `d⟨a⟩/dt = (⟨a⟩/t_adapt)(τ_s²/τ_0² − 1)`, `dτ_s/dt = −(τ_s − ⟨τ⟩)/t_delay`, `⟨τ⟩ = 4⟨|Q|⟩/(π⟨a⟩³)`.
- 실측: `T ≃ 1–2 min` (131 ± 43 s, Alim 2013), `t_delay ≃ 2 min` (1–3 min; 15–25% 의 관에서 측정 가능), `t_adapt ≃ 10–100 min` (맞춤 85–10000 s, 대표 37 min), `τ_0 ≈ 0.2–7 s⁻¹`. 관 소멸 15–40 min, 구역 눈사태 < 15 min. `t_adapt > 8 t_delay` 이면 단조, 아니면 감쇠 진동(시계 방향 고리).
- 운명 규칙: `R/R_net > 1` 소멸. 막힌 가지는 `a ≥ a_c = 32Lε/(Tτ_0)` 이면 성장, `τ_0 ∼ τ_active − ⟨P − P_0⟩/μ` (압력이 높으면 성장). 평행 관은 저항 큰 쪽 소멸. 고리는 가운데부터.
- 정상상태 스케일: Murray `r_0³ = r_1³ + r_2³`, 실측 지수 2.53–3.29, 전도도 강화 지수 `μ = 4/n = 4/3` (Akita 2017, `dD/dt = |Q|^μ − D`).
- 빠른 경로(먹이 반응, Kramar 2021): 연화제 c 의 이류·Taylor 분산·감쇠(`k_deg = 0.001 s⁻¹`), `E = E_0 − δE⟨c⟩/(⟨c_0⟩+⟨c⟩)` (최대 −20%), 15 min 안에 새 위계, 전선 15 μm/s. 전단율과 무관한 별도 경로.

### (b) 맥동과 유량의 정량 관계
- 국소 보존: `∂(πa²)/∂t = −∂Q/∂z`; 조각당 `Q_in = 2πaL ∂a/∂t`; 주기 평균 `⟨|Q_in|⟩ ≃ 8πLε⟨a⟩²/T`; 노드에서 Kirchhoff + Poiseuille(`R = 8μL/πa⁴`)로 압력·유량.
- 평균 전단율 `⟨τ⟩ ≈ 32Lε/(T⟨a⟩)` (막힌 가지·큰 반지름 극한), 망 안에서는 `× 1/(1 + R/R_net)`.
- 압력-유속(윤활 근사): `ū = −(a²/8μ) ∂/∂z(σ_T + (E/h)(a − a_0))`, `σ_T = A cos(ωt − kz)`, A = 10 Pa, E/h·a_0 규모 = 100 Pa.
- 위상: 몸 길이에 정확히 한 파장(3–21 mm 개체). 닫힌 망이면 `Σ` 수축 유량 = 0. 유속은 위상 구배의 중간에서 최대, 끝에서 0. 수송(분산)은 ū² 에 비례.
- 크기: 굵은 관 최대 유속 ∼1 mm/s; 수축만으로 계산한 유속은 실측의 1/10 (Alim 2013 — 바깥/안 반지름 차이). 올챙이 조각 내질 5–10 μm/s, 외질 0.15 μm/s.

### (c) 전진면 전진의 역학 — "정맥이 실어 온 부피로 구동"은 타당한가
**큰 틀에서는 타당하다. 단 "싱크를 지정"하는 방식은 문헌과 다르고, 세 가지를 고쳐야 한다.**
- 지지하는 직접 근거:
  1. Rieu 2015: 빠르게 넓어지는 앞쪽에는 견인력이 거의 없고(맨 가장자리의 안쪽 방향 힘만), 힘은 뒤쪽 수축 단위가 낸다. 역위상으로 수축하는 두 부분 중 "밀리는 쪽"이 전진면이 된다.
  2. Oettmeier 2019: "The front is pushed outwards passively by the flow." 부피 수지 Q_front ≈ 30 Q_back. 앞이 5배 무르면 유량이 그쪽으로 30–50배.
  3. Kuroda 2015: 원형질 대부분이 전면부에 몰려 있고(지수 꼬리), `v = const × p h/μ` (압력 구동 Stokes). 잘라낸 앞 끝은 잠시만 같은 속도로 간다(공급이 끊기면 멈춤).
  4. Kramar 2021: 전진면은 벽이 무른 곳, ATP 가 2배. 무른 곳이 부풀고 나머지는 부피 보존으로 줄어든다.
  5. Marbach 2023: 막힌 가지는 국소 압력이 높으면 자라고 낮으면 사라진다.
- 고쳐야 할 점:
  1. **구동은 정상(定常) 소스-싱크가 아니라 왕복류의 작은 비대칭**이다. 순전진 속도는 왕복 유속의 1/30–1/300. 확장:후퇴 시간 비 1.4–2.3 (Oettmeier 2019). 따라서 압력 풀이의 소스는 `−∂h/∂t` (진동, 적분 0)이고, 순이동은 "앞이 무르다"는 비대칭에서 나와야 한다.
  2. **부피가 어디로 가는지는 순응도(연성)가 정한다.** 전진면 셀을 싱크로 박아 두는 대신, 셀마다 강성 E(x) 를 두고 전진면(젊은 영역, 연화제·ATP 높은 곳)을 무르게 한다. 그러면 "어느 전진면이 자라는가"가 압력 풀이에서 저절로 나온다.
  3. **유량만으로는 전진이 결정되지 않는다**(Lewis 2015: 기울기 0.16, 45% 는 부호 반대; 접착 위상 φ ≈ 3π/2 가 필요; 균일 접착이면 순이동 0, 너무 끈끈하면 정지). 큰 개체에서는 덜 중요할 수 있으나, 최소한 전진면 셀의 "앞으로 나갈 조건"에 기질 마찰 항이 있어야 한다. 흔적(점액) 기피도 여기에 넣는다(Reid 2012: 속도가 아니라 방향 선택, 39/40).
- **전진면의 폭과 안정성을 정하는 것** (직접 다룬 정량 모델은 이번에 읽은 문헌에 없다. 아래는 읽은 사실의 조합이며 마지막 식은 내 유도):
  - 전진 속도는 세로 두께 윤곽이 정하고 가로 폭은 직접 관여하지 않는다: `v = 0.17 h_max` (mm/min, mm) (Kuroda 2015).
  - 전진면 둘레는 고르게 함께 움직인다(Oettmeier 2019) → 전진면 안은 압력이 균일하고, 가장자리에는 안쪽을 향한 피질 장력(5–20 mN/m, Rieu 2015)이 걸린다 → Laplace `p ∝ τ/h` (Kuroda 2015). 균일 압력 + 선장력 = 원호(부채꼴).
  - 폭은 공급이 정한다 [내 유도]: 순 부피 공급 `Q_net = v · h · W` → `W = Q_net/(v h) ≈ Q_net/(0.17 h²)`. 공급이 늘면 넓어지고, 줄면 좁아지거나 둘로 갈라진 뒤 한쪽이 죽는다.
  - 분기는 **속도가 떨어진 직후**에 일어나고, 갈라진 둘 중 하나는 다음 분기 전에 멈춰 사라진다(Kuroda 2015, 그림 9). 이는 Marbach 의 평행 관·막힌 가지 경쟁(압력 높은 쪽 승)과 같은 구조.
  - 크기 문턱: < ∼100 μm 정지, 100–500 μm 올챙이형, > ∼500 μm 가지 친 구조(Zhang 2017), ≳ 1 cm 부채꼴 + 정맥망(Kuroda 2015).
  - 관과의 결합: 주맥 2–3 개가 세로로 달리고 **앞쪽 마지막 1/3 에서만 분기**, 앞쪽 통로는 단명, 관은 기질에 고정(Oettmeier 2019). Akita 2017 의 배출 실험은 "면 전체가 소스, 한 점이 싱크"이면 μ > 1 에서 나무가 됨을 보인다 — 전진면이 면 싱크이고 뒤쪽 줄기가 점 소스인 경우의 거울상.
