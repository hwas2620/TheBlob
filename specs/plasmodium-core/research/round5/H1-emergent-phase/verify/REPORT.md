# H1 독립 심사 보고 (verify, 5차)

작성: 독립 심사자(하위 에이전트). 작성자 주장을 반박하려는 관점에서 작성.
이 파일은 심사자가 마지막 메시지로 돌려준 보고 전문을 주 세션이 그대로 옮겨 적은 것이다(심사자 쪽에서는 보고서 파일을 쓸 수 없었다). 11절의 경로만 저장소 기준으로 바꿨다.

상태: 실행 45회(192², 그중 1회는 T=100 짜리 확인), 실행 시간 합 76분, 벽시계 27분, 3개 병렬. 작성자 폴더와 저장소는 읽기만 했고 커밋·푸시는 하지 않았다.

용어: tri = 작성자의 `tri96d`(P=96, T=80, v=0.24), noise = `n03T320`. "굵은 쌍"은 작성자 정의 그대로(경로 최소 C ≥ 5 × 정맥 중앙 C)다.

## 1. 가장 약한 주장 3개

1. **M2.** 0.70 은 tri 실행이 생기기 전의 47개로 낸 값이다. phana.py 가 손으로 넣은 위상 항을 wave 에만 더해서, tri 20개는 진단 값이 base 수준(중앙 0.30, base 0.18)인데 정맥은 wave 수준(0.79~0.90)이다. 전체 96개로는 0.49 다. 같은 설정에서 시드만 다른 묶음 안에서는 관계가 없다(base +0.34 p=0.26, tri96d 0.00, 합쳐서 0.23). 변형 사이의 차이만 반영한다.
2. **M5 의 일반화.** 한 점(P=96, T=80, v=0.24)에서는 대체로 재현되지만 격자 주기에 의존한다. P=48 로 줄이면 굵은 쌍이 3/9 로 떨어진다(결과를 보기 전에 적어 둔 예측대로). 작성자 폴더의 요약 안 된 정지 격자 P=48, T=320 도 Y3 를 통과하지 못한다. "0.8 이상 12/12"는 새 시드에서 4/6 이고, "wave 와 같은 수준"은 통과 기준으로만 맞다. 대가도 Ym 만 적었다(Y3 에서 한 먹이에 닿는 시각이 중앙 +18%, 최대 +78%). tri 는 절대 좌표와 전역 시계를 쓰는 처방된 장이라 "국소 규칙"이라 하기 어렵다.
3. **M3.** 정적 잡음의 Y3 실패는 M5 와 같은 기준이면 4회 중 2회다(시드 13 은 경로 최소 C 66/454/60). 정지 격자는 P=96, T=80 한 가지만 적었다.

## 3. 코드 읽기

- h1.py 는 4차 검증자 코드에 새 옵션과 진단 `ph_ser` 만 더한 것이다. `mgt.py`, `graphm.py`, `vmet.py`, `vsum.py` 는 바이트 단위로 같다.
- **옵션을 끄면 base 와 같다.** 작성자의 `Ym_base_s11`, `Ym_wave_s11`, `Y3_base_s11`, `Y3_wave_s11` 의 최종 `h`, `C`, `wet`, `theta` 가 4차 검증자의 같은 실행과 완전히 같다.
- **tri**: `θ_eff += k·[cos(2πt/T)·Λ(X − v·t) + sin(2πt/T)·Λ(Y − 0.618·v·t)]`, 기울기 ±1, 꺾임선은 u ≡ 0, P/2. 무게중심을 쓰지 않는다. N 이 P 의 배수일 때 주기다. k=0.0628 은 wave 의 2π/100 과 같고, 꺾임선 사이 한 칸 안에서는 wave 와 같은 회전 기울기다.
- **시작 위치**: 격자 중심 95.5 는 t=0 에 x, y 두 꺾임선(96)에서 0.5셀이다.
- **om_noise**: 따로 둔 난수(`seed+7919`)를 쓴다. 같은 시드의 base·wave·tri·noise 는 간선 잡음, 초기 전도도, 문턱 잡음이 같다.
- **재현성**: 작성자의 `Y3_tri96d_s21` 을 내 사본으로 T=100 까지 돌리면 t=20~100 의 저장 상태, `hfood`, `ph_ser` 가 완전히 같다.
- 내가 사본에 더한 것(동역학 불변): `tri_x0`, `tri_y0`, `tri_vy`, θ_eff 기울기 4열, 스텝별 최소 두께 시계열. 뒤의 것은 시드 46 과 추가 실행부터 들어갔다. 새 코드의 `Y3_wave_s41r` 이 옛 코드의 `Y3_wave_s41` 과 같은 최종 배열을 낸다.
- `ph_ser` 는 θ 의 기울기만 잰다. θ_eff 의 기울기가 아니다.

- 정맥의 4겹 방향 지수(18시드 짝): Ym 에서 tri − base 는 −0.016 (p=0.13). **tri 가 정맥을 축 방향으로 몰지는 않는다.**
- Y3 에는 작지만 일관된 치우침이 있다. x 대 y 간선 몫이 base 보다 −0.029 (16/18 시드, p<0.001), 윤곽의 축/대각 도달 비가 0.96~0.98 (base·wave 1.02~1.04, p<0.001). 크기는 3~5% 다.

## 6. M6 덧붙임 — wave 의 큰 음수 두께가 생기는 때

`Y3_wave_s41` 을 스텝별 최소 두께 기록을 켜고 다시 돌렸다.
- −0.05 아래인 스텝은 4개뿐이고 모두 t=373.2~374.3 이다. 첫 먹이가 떨어진 시각이 373.0 이다. 그 밖의 구간 최소는 −0.039 다.
- 음수가 된 셀은 굵은 관 위의 셀이다(인접 전도도 2300~2440, 가장 가까운 먹이에서 8~34셀).
- 작성자의 시드 32(−0.99)는 저장 상태로 보면 t=460 과 480 사이에 생겼다.
- "4/12"는 맞는 수이지만 먹는 동안 창 안의 일이 아니다. tri 는 18회 모두 −0.047 이상이다.
