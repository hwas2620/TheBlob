## 판정 기준

정의와 창은 거르기(`SCREEN.md`)와 같다.

| 기준 | 확인 | 반박 |
|---|---|---|
| **A1** 한 몸 안 덩이 둘 이상 (t 100~1600) | ≤ 0.5 × 대조, 후보가 낮은 시드 ≥ 7/10 | ≥ 1 × 대조 |
| **A2** 실 아령 (t 200~1600) | ≤ 0.5 × 대조 | ≥ 1 × 대조 |
| **A3** 죽은 실 (t 1000~1600) | ≤ 1 × 대조 | > 1.3 × 대조 |
| **A4** 흐름 없는 가지 끝 (t 1000~1600) | ≤ 1 × 대조 | > 1.3 × 대조 |
| **A5** 얇은 막 (t 1000~1600) | ≤ 1 × 대조 | > 1.3 × 대조 |
| **A6** 부스러기 (5% 미만 조각 수, t ≥ 100) | ≤ 0.1 × 대조 그리고 ≤ 0.05 | ≥ 0.5 × 대조 |
| **T1** 갇힌 뒤(t ≥ 1800) 한 몸 안 덩이 둘 이상 | ≤ 1 × 대조 | > 1.5 × 대조 + 0.02 |
| **T2** 갇힌 뒤(t ≥ 1800) 가장 큰 몸의 둘레/√넓이 | ≤ 1 × 대조 | > 1.15 × 대조 |
| **T3** 균핵 모드에서 빠진 시간 > 1인 후보 long 실행 | 0 | ≥ 2 |
| **T4** 균핵이 된 지 150 시간 넘은 후보 long 실행의 끝 얇은 칸(h < 0.5) 몫 > 5% | 0 (그런 실행이 적어도 하나 있을 때) | ≥ 2 |
| **L1** 꼬리: 후보 long의 t 1000·1200·1400 가장 긴 외가닥 실(젖은 8-이웃 ≤ 2, h < 0.6) 평균, 자유 끝(젖은 이웃 ≤ 1) 평균 | ≤ 50칸 그리고 ≤ 10 | > 80칸 또는 > 20 |
| **L5** 긴 다리: 후보 long의 t 600~1600 매 200 시각(60개) 가운데 가장 긴 외가닥 실이 100칸 이상인 시각 수 | ≤ 3 (60개 모두 있을 때) | ≥ 8 |
| **L2** 원판 아님: 균핵이 된 지 150 시간 넘은 후보 long 실행 가운데 끝 가장 큰 몸 축비 ≤ 0.9인 몫 | ≥ 70% | < 40% |
| **L3** 맺힘 시각: 균핵 뒤 몸 부피의 90%가 h ≥ 1.5 칸에 드는 시각, 중앙값 | 60~300 | < 40 또는 > 400 |
| **L4** 이주 방향: mig 후보 방향 오차 절댓값 평균 | ≤ 12° | > 18° |
| **F1** food4 10쌍 | 모두 닿음 ≥ 대조 − 1, 늦음 ≤ 이름 + 2, 마지막 먹이 차이 중앙 ≤ +20 | 모두 닿음 ≤ 대조 − 3, 또는 늦음 ≥ 이름 + 5 |
| **F2** food3 4쌍 + asym3 4쌍 (먹이 24쌍) 늦음 | ≤ 1 | ≥ 3 |
| **M1** mig 8쌍 가운데 이동 ≥ 0.8배·넓이 ≤ 1.2배인 쌍 | ≥ 6 | ≤ 3 |
| **M2** mig 후보가 유인원에 닿은 수, 방향 오차 평균 | 8/8 그리고 ≤ 25° | ≤ 6/8, 또는 > 35° |
| **H1** 건강 (후보 36 실행) | 모두 지킨다 | 하나라도 어긴다 |

H1에서 지킬 것:
- 스텝 끝 음수 0
- 부피 오차 < 1e-10
- |버린 부피| < 0.1%
- 끝에 5% 미만 조각 0
- 끝까지 돎

**독립 검증으로 가는 조건**: A1~A6, T1~T4, L1~L5, H1이 모두 확인이고, F1·F2·M1·M2에 반박이 없다.
