## 무엇을 시험하나

- 대조 `s16c`: 지금 모델 그대로(관문 B 설정).
- 후보 `s16gh`: 지금 모델 + `keep_conn=3 ret_h=100 ret_glob=1 sup_age=100 sup_cap=2 sup_h=0.6 sup_fed=50 ret_fed=50 hang_age=4`.
  - 몸은 찢어지지 않는다. 고리는 열린다(`keep_conn=3`).
  - 굶을 때만 일하는 것:
    - 늙은 가장자리 오그라듦(`ret_*`, `ret_fed`)
    - 굵은 덩이(h ≥ 0.6)끼리의 흐름 경쟁(S7, `sup_fed`)
    - 매달린 조각의 빠른 늙음(`hang_age`)
- 둘 다 `S16-dumbbell/model/` 복사본으로 돈다.

## 판정 기준 (후보를 같은 시드의 대조와 견준다)

정의는 둘째 거르기(`SCREEN2.md`)와 같다.

long 10쌍:
- **F1 아령** (t ≥ 100, h ≥ 0.6 칸 조각 가운데 몸 부피 10% 이상이 둘 이상인 몫)
  - 확인: 후보 평균 ≤ 0.5 × 대조 평균, 그리고 후보가 낮은 시드 ≥ 7/10.
  - 반박: 후보 평균 ≥ 대조 평균.
  - 시드 하나의 값은 작은 흔들림에도 크게 바뀐다(0.30 → 0.51을 보았다). 그래서 시드 수 조건을 7/10으로 두었다.
- **F2 늦은 몸 밖 부피** (t ≥ 1600)
  - 확인: ≤ 0.5배. 반박: ≥ 1배.
- **F3 늦은 얇은 칸** (t ≥ 1600, h < 0.3)
  - 확인: ≤ 1배. 반박: > 1.3배.
- **F4 끝 줄 칸** (t = 2000)
  - 확인: ≤ 1배. 반박: > 1.3배.
- **F5 몸 안 죽은 실** (t 1000~1500, 가장 큰 조각 안 줄 칸 가운데 Cn < 9)
  - 확인: ≤ 1배. 반박: > 1.3배.

먹이·이주:
- **G3 mig 4쌍**: 이동 ≥ 0.8배이고 끝 넓이 ≤ 1.2배인 쌍의 수.
  - 확인: 3 이상. 반박: 1 이하.
- **G4 food3 4쌍 + asym3 2쌍**: 늦음(대조가 닿은 먹이에 50 넘게 늦거나 못 닿음).
  - 확인: 1 이하. 반박: 3 이상.
- **G5 food4 10쌍** (먹이 40쌍)
  - 확인: 아래를 모두 지킨다.
    - 모두 닿음 ≥ 대조 − 1
    - 늦음 ≤ 이름 + 2
    - 마지막 먹이 차이 중앙 ≤ +20
  - 반박: 모두 닿음 ≤ 대조 − 3, 또는 늦음 ≥ 이름 + 5.

건강:
- **G6** 후보 30 실행 모두 아래를 지킨다. 하나라도 어기면 반박이다.
  - 스텝 끝 음수 0
  - 부피 오차 < 1e-10
  - 버린 부피 몫 < 0.01
  - 끝 젖은 조각 1개
  - 끝까지 돎

**독립 검증으로 가는 조건**: F1~F5와 G6이 모두 확인이고, G3~G5에 반박이 없다.

**관문 아님(적기만 한다)**:
- 몸 안 줄 칸 전체, 살아 있는 관 수
- 끝 넓이
- food4 먹이별 평균 차이
- **끝 구간(t ≥ 1800)**:
  - 덩이 수: 한 칸 깎은 뒤 몸 부피 5% 이상 조각 수
  - 흐름 없는 굵은 실의 부피 몫: 가장 큰 조각 안 줄 칸 가운데 Cn < 9이고 h ≥ 0.3인 칸
  - 둘째 거르기 시드에서 둘 다 후보가 대조보다 많았다(덩이 1.9 대 1.4, 굵은 실 0.076 대 0.040). 약점으로 본다.
