# S16 아령 — 독립 검증 기준 (실행 전에 씀)

대조 `v16c` (덧붙인 설정 없음) 와 후보 `v16gh`
(`keep_conn=3 ret_h=100 ret_glob=1 sup_age=100 sup_cap=2 sup_h=0.6 sup_fed=50 ret_fed=50 hang_age=4`) 를
같은 시드끼리 짝지어 견준다. 모델은 `model/` 의 네 .py 를 고치지 않고 그대로 쓴다.

## 1. 실행 계획 (시드 271~290 안에서만)

|---|---|---|---|
| long  | 271~282 (12) | v16c, v16gh | 24 |
| long (촘촘 검사) | 271, 272 | v16ghd = v16gh 설정 + `gm_every=0.1 vsave=0` | 2 |

합 76 실행. 시드를 결과를 본 뒤에 늘리지 않는다. 다만 실행이 기계 탓(메모리, 디스크, 중단)으로 깨지면 같은 시드로 다시 돌린다.

`v16ghd` 는 몸이 "늘" 한 덩어리인지 스텝마다 보려는 것이다. `gm_every` 는 `graphm.quick` 을 부르는 간격일 뿐 동역학에 들어가지 않는다
(그래서 끝 상태 `h.npy` 가 같은 시드의 `v16gh` 와 비트까지 같아야 한다. 다르면 따로 적는다). `metrics.json` 의 `gseries[*].body.comps` 가 스텝마다 남는다.

## 2. 공통 정의

- 격자는 토러스. 연결은 8이웃 연결(대각 포함), 가장자리 건너 감김.
- 저장 상태: `vs_tNNNN.npz` (20 시간마다). 끝 상태: `wet.npy`, `h.npy`.
- 몸 부피 `V_b` = 젖은 칸의 Σh.
- 짝 차이 `d_i` = (후보 − 대조), 시드 i 마다. 평균은 시드 평균.
- 부호 뒤집기 시험(sign-flip permutation): 차이들의 부호를 모든 2^n 가지로 뒤집어 한쪽 p 를 정확히 낸다.
- 부트스트랩: 차이의 평균에 대한 90% 백분위 신뢰구간, 10000번 다시 뽑기, 난수 시드 0.

## 3. 주장별 지표와 판정

### 주장 1 — long 에서 몸이 찢어지지 않는다 (후보만)
- 대상: 후보 long 12 실행 + 촘촘 검사 2 실행.
- (a) 모든 저장 상태(t = 20, 40, …, 2000)와 끝 상태에서 젖은 칸의 8연결 토러스 성분 수 = 1.
- (b) 촘촘 검사 실행: `gseries` 의 모든 스텝에서 `body.comps` = 1.
- (c) `V_crumb` = 0 이고 `crumb_cells` = 0 (몸 밖으로 버려진 부피 없음).
- 판정: 모두 지키면 **맞음**, 한 번이라도 어기면 **틀림** (어긴 시드·시각을 적는다).
- 덧붙여 대조의 성분 수(찢어짐이 대조에서 실제로 일어나는지)를 함께 낸다. 대조가 한 번도 찢어지지 않으면 주장은 맞아도 "시험이 약함"으로 적는다.

### 주장 2 — long 에서 아령이 대조보다 드물다
- 굵은 칸: 젖은 칸 가운데 h > 0.5 (cap).
- 큰 덩이: 굵은 칸의 8연결 토러스 성분 가운데 부피(Σh) ≥ 0.05·V_b 인 것.
- D1 아령(상태 하나): 한 젖은 성분 안에 큰 덩이가 둘 이상.
- D2 실 아령(상태 하나): 같은 젖은 성분 안의 큰 덩이 짝 (A, B) 가운데 하나라도 "이음의 가장 좁은 곳" ≤ 3 칸.
  - R = 젖은 칸 − (모든 큰 덩이). A 에서 R 안으로 8이웃 BFS 거리 dA (A 에 붙은 칸 = 1), B 에서 dB.
  - L = min(dA + dB) − 1 (R 을 지나는 가장 짧은 길의 칸 수). 복도 = dA + dB ≤ min(dA + dB) + 2 인 R 칸.
  - 가장 좁은 곳 = k = 1..L 에서 (복도 칸 가운데 dA = k 인 칸 수) 의 최소. R 로 이어지지 않는 짝은 건너뛴다.
- 실행 값: 창 t ∈ [200, 2000] 의 저장 상태(91개) 가운데 D2 인 비율 `f_D2` (주 지표), D1 비율 `f_D1` (보조).
- 판정 (주 지표 `f_D2`, 12 짝):
  - 대조 평균 `f_D2` < 0.01 이면 시험이 아령을 만들지 못한 것 → **판정 못 함**.
  - 평균 d < 0 이고 한쪽 부호 뒤집기 p(d<0) < 0.05 → **맞음**.
  - 평균 d ≥ 0 → **틀림**.
  - 나머지 → **판정 못 함**.
  - 보조 `f_D1` 이 반대로 유의하게(평균 d > 0, p < 0.05) 늘면 "맞음"을 "판정 못 함"으로 낮춘다.
- 민감도(판정에 쓰지 않고 적기만): 큰 덩이 문턱 2%·10%, 굵기 h > 0.7, 창 [1000, 2000].

### 주장 3 — long 늦은 때 얇은 막, 죽은 실, 끝 줄 칸이 대조보다 적다
- 창: t ∈ [1500, 2000] 의 저장 상태 26개. 실행 값 = 창 안 평균 칸 수.
- 넓은 칸: 2×2 칸 묶음 넷이 모두 젖은 것에 드는 젖은 칸. 한 칸 폭 칸 = 넓은 칸이 아닌 젖은 칸.
- (a) 얇은 막 칸 `film`: 2×2 묶음 넷이 모두 젖고 모두 h < 0.3 인 것에 드는 칸.
- (b) 죽은 실 칸 `dead`: 한 칸 폭 칸 가운데 흐름이 거의 없는 칸.
  - 칸의 흐름 q = 그 칸에 닿는 8 간선의 `Qgross`(직전 다섯 주기의 |Q| 평균) 최댓값.
  - 기준 q_ref = 양 끝이 젖고 `Cmean` > 4 인 간선(정맥)의 `Qgross` 90 백분위. 정맥 간선이 10개 미만이면 양 끝이 젖은 모든 간선의 90 백분위.
  - 죽음: q < 0.01·q_ref.
  - 보조: 한 칸 폭 칸 가운데 닿는 간선의 `Cmean` 최댓값 < 0.5.
- (c) 끝 줄 칸 `endline`: 되풀이 가지치기로 떨어지는 칸 수. 한 번에, 젖은 8이웃이 1개이거나 2개이면서 그 둘이 서로 8이웃인 칸을 모두 떼고, 더 뗄 것이 없을 때까지(최대 400번) 되풀이한다.
- 판정 (지표마다, 12 짝):
  - 대조 평균 < 1 칸 → 그 지표 **판정 못 함**.
  - 평균 d < 0 이고 p(d<0) < 0.05 → **맞음**. 평균 d ≥ 0 → **틀림**. 나머지 → **판정 못 함**.
  - 주장 3 전체: 셋 다 맞음 → **맞음**. 하나라도 틀림 → **틀림**. 그 밖 → **판정 못 함**.
- 보조(판정에 쓰지 않음): 각 수를 젖은 넓이로 나눈 비율. 후보의 몸이 그냥 작아서 적은 것인지 보려는 것.

### 주장 4 — 먹이 찾기와 굶은 이주가 대조보다 나빠지지 않는다
- 차이 d 는 "나빠지는 쪽"이 + 가 되게 잡는다.
- food3, asym3, food4 주 지표 `t_all` = 모든 먹이에 닿은 시각 = max(`t_touch`). 하나라도 못 닿으면 T(480 또는 700)로 두고 "놓침"으로 센다. d = 후보 − 대조.
  여유 δ = max(15, 0.10 × 대조 평균 `t_all`).
  - 보조: `t_first` = min(`t_touch`) (δ = max(10, 0.10 × 대조 평균)), 먹은 비율 E = Σ(food_M − fM_end)/(먹이 수·food_M) (d = 대조 − 후보, δ = 0.05), 놓친 먹이 총수.
- mig 주 지표 `t_touch` (유인원 원반에 처음 닿은 시각, 못 닿으면 400). δ = max(15, 0.10 × 대조 평균).
  - 보조: `disp` (끝 무게중심 이동, d = 대조 − 후보, δ = 0.10 × 대조 평균).
- 판정 (지표마다): 부트스트랩 90% 구간 위 끝 < δ → **맞음**(나빠지지 않음). 평균 d > δ 이고 p(d>0) < 0.05 → **틀림**. 나머지 → **판정 못 함**.
  - 보조 "놓친 먹이": 후보가 대조보다 시나리오 합으로 2개 이상 더 놓치면 **틀림**.
- 주장 4 전체: 네 주 지표 모두 맞음이고 보조에 틀림이 없으면 **맞음**. 주 지표 하나라도 틀림 → **틀림**. 그 밖 → **판정 못 함**.

### 주장 5 — 후보 실행이 모두 건강하다
- 대상: 후보 실행 전부 (long 12, 촘촘 2, food3 6, asym3 6, food4 5, mig 8 = 39).
- 실행마다: `neg_end_cellsteps` = 0, `mass_err_max` < 1e-10, `V_crumb` = 0, `stop` = '' (발산이나 다 마름 없음), 끝 `wet.npy` 의 8연결 토러스 성분 수 = 1.
- 모두 지키면 **맞음**, 하나라도 어기면 **틀림**.

## 4. 예측 (실행 전)
- 주장 1: 맞음. `keep_conn` 이 짜임새로 찢어짐을 막는다. 다만 음수로 바로 마르는 칸이 여럿 붙어 마르면 `V_crumb` 이 0 보다 클 수 있다고 본다(드묾).
- 주장 2: 맞음일 것 같지만 자신 없다. 대조가 아령을 만들기 전에 찢어져 버리면(조각이 떨어짐) 대조의 아령 수가 적어 판정 못 함이 될 수 있다.
- 주장 3: 얇은 막과 끝 줄은 맞음(ret_h=100 이 테두리를 끌어들임). 죽은 실은 틀림일 수 있다: 후보는 몸을 찢지 않으려고 실을 붙잡아 두고, 대조는 그냥 끊는다.
- 주장 4: 후보는 먹기 전(t_eat 없음)에도 "굶은 몸" 규칙(ret, sup, hang)이 켜져 있다. 처음 탐색이 느려져 food4(먼 먹이)에서 판정 못 함이나 틀림이 나올 수 있다.
- 주장 5: 맞음.
