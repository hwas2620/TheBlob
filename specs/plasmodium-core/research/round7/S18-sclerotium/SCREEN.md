# 7차 S18 거르기 — 균핵 + 매달린 조각 되돌리기 + 조각 문턱 + 냄새 쪽 경쟁 (`s18i`), 실행 전에 적음

> 2026-11-23. 이 파일은 이 거르기의 실행을 하나도 돌리기 전에 썼다. 판정 스크립트: `scripts/screen_s18.py` (sha256은 `screen_sha256.txt`).
> 진단 기록: `NOTES.md`, `diag*.txt`, `mig_direction*.txt` (이미 쓴 시드, 판정 아님).
> 사용자와 정한 것:
> - 기준은 진짜 점균이다.
> - 큰 조각으로 나뉘는 것은 괜찮다.
> - 갇힌 때(판이 점액으로 덮여 갈 곳이 없을 때) 한 덩어리로 굳는 행동까지 넣고 GPU로 간다.

## 무엇을 견주나

- 대조 `s18c`: 지금 모델 그대로.
- 후보 `s18i` = S17 후보 `s17fs` 위에 다음을 바꾸고 더한 것.
  - `fis_min=0.10`: 갈라짐은 닿은 조각이 모두 몸 부피 10% 이상일 때만이다. 3~5% 조각이 떨어지던 것을 막는다.
  - `hang_C=20`: 부스러기를 막으려고 지켜진 실은 적어도 전도도 20으로 흐른다. 매달린 조각이 늙으며 원형질을 본체로 되돌린다.
  - `sup_scent=2`: 굶을 때 덩이끼리의 경쟁에서 승자를 "부피 몫 + 2 × 평균 냄새"로 정한다. 이주 방향이 크게 틀어지던 것을 막는다(진단: 53° → 17°).
  - 균핵: `scl_f=0.02 scl_H=3 scl_age=5 scl_C=20 scl_disc=1 scl_thin=0`
    - 들어가는 조건: 굶은 몸의 가장자리 바깥에 점액 없는 새 땅이 2% 미만인 상태가 30 시간 이어진다.
    - 들어가면 일어나는 일:
      - 가장 큰 굵은 덩이의 무게중심에 둥근 핵이 생긴다.
      - 핵은 늙지 않고 쉬는 두께가 3배다. 나머지는 6배 빨리 늙는다.
      - 몸 전체 간선이 적어도 전도도 20으로 흐르고, 얇은 칸 흐름 제한은 꺼진다.
      - 핵 안으로만 젖는다. 갈라짐은 막는다.
  - 전체 설정: `keep_conn=4 fis_min=0.10 ret_h=100 ret_glob=1 sup_age=100 sup_cap=2 sup_h=0.6 sup_fed=50 ret_fed=50 hang_age=4 sup_min=0.05 neg_fill_global=1 sup_size=2 hang_C=20 scl_f=0.02 scl_H=3 scl_age=5 scl_C=20 scl_disc=1 scl_thin=0 sup_scent=2`

## 측정

S17과 같다. 두 독립 검증자의 코드를 그대로 쓴다(`../S16-dumbbell/verify/scripts/vlib.py`, `../S16-dumbbell/verify2/scripts/measure.py`). 관문은 옮겨 다니는 구간(t ≤ 1600)과 갇힌 뒤(t ≥ 1800)를 따로 둔다.

바뀐 것:
- 부스러기 문턱을 3%에서 **5%**로 올렸다. 셋째 검증자가 5%를 썼다.
- 갇힌 뒤 조건(T1, T2)을 더했다.
- 이주 시드를 4에서 8로 늘리고 방향 조건(M2)을 더했다.

## 넘김 조건

long 10쌍:
- **A1** 한 몸 안 덩이 둘 이상인 비율(t 100~1600) ≤ 0.5 × 대조, 그리고 후보가 낮은 시드 ≥ 7/10.
- **A2** 실 아령(t 200~1600) ≤ 0.5 × 대조.
- **A3** 죽은 실(t 1000~1600) ≤ 대조.
- **A4** 흐름 없는 가지 끝(t 1000~1600) ≤ 대조.
- **A5** 얇은 막(t 1000~1600) ≤ 대조.
- **A6** 부스러기(몸 부피 5% 미만 조각 수, t ≥ 100 평균) ≤ 0.1 × 대조, 그리고 후보 ≤ 0.05.
- **T1** 갇힌 뒤(t ≥ 1800) 한 몸 안 덩이 둘 이상 비율 ≤ 대조.
- **T2** 갇힌 뒤(t ≥ 1800) 가장 큰 몸의 둘레/√넓이 ≤ 대조(작을수록 둥글고 뭉쳤다).

먹이·이주:
- **F1** food4 6쌍: 모두 닿음 ≥ 대조 − 1, 늦음 ≤ 이름 + 2, 마지막 먹이 차이 중앙 ≤ +20.
- **F2** food3 2쌍 + asym3 2쌍(먹이 12쌍): 늦음 ≤ 1.
- **M1** mig 8쌍: 이동 ≥ 0.8배이고 끝 넓이 ≤ 1.2배인 쌍 ≥ 6.
- **M2** mig 후보 8개가 모두 유인원에 닿고, 처음 → t 200 무게중심 이동 방향이 유인원 방향에서 벗어난 각도의 평균 ≤ 25°.
  - 진단에서 대조 5°, S17 후보 52°, 이 후보 17°였다.
  - **대조보다 덜 정확하다는 것은 알고 둔 문턱이다.**

건강:
- **H1** 후보 28 실행 모두 아래를 지킨다.
  - 스텝 끝 음수 0
  - 부피 오차 < 1e-10
  - |버린 부피| < 0.1%
  - 끝에 몸 부피 5% 미만 조각 0
  - 끝까지 돎

**모두 넘으면 결승(새 시드)으로 간다.**

**관문 아님**: 가지 끝 줄 전체, 끝 구간(t > 1600)의 죽은 실·가지 끝, 몸 수, 갈라짐 횟수, 균핵 모드에 들어간 시각.

- A1·A2·A6: 넘는다. S17 결승과 같은 규칙이 옮겨 다니는 동안 일한다. 냄새 쪽 경쟁이 더해진 것만 다르다.
- A3~A5: 넘는다.
