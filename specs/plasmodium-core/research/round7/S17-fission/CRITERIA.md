## 판정 기준

정의와 창은 거르기(`SCREEN.md`)와 같다. 관문은 옮겨 다니는 구간(t ≤ 1600)에 둔다.

| 기준 | 확인 | 반박 |
|---|---|---|
| **A1** 한 몸 안 덩이 둘 이상 (t 100~1600) | ≤ 0.5 × 대조, 후보가 낮은 시드 ≥ 7/10 | ≥ 1 × 대조 |
| **A2** 실 아령 (t 200~1600) | ≤ 0.5 × 대조 | ≥ 1 × 대조 |
| **A3** 죽은 실 (t 1000~1600) | ≤ 1 × 대조 | > 1.3 × 대조 |
| **A4** 흐름 없는 가지 끝 (t 1000~1600) | ≤ 1 × 대조 | > 1.3 × 대조 |
| **A5** 얇은 막 (t 1000~1600) | ≤ 1 × 대조 | > 1.3 × 대조 |
| **A6** 부스러기 (3% 미만 조각 수, t ≥ 100) | ≤ 0.1 × 대조 | ≥ 0.5 × 대조 |
| **F1** food4 10쌍 | 모두 닿음 ≥ 대조 − 1, 늦음 ≤ 이름 + 2, 마지막 먹이 차이 중앙 ≤ +20 | 모두 닿음 ≤ 대조 − 3, 또는 늦음 ≥ 이름 + 5 |
| **F2** food3 4쌍 + asym3 2쌍 (먹이 18쌍) 늦음 | ≤ 1 | ≥ 3 |
| **M1** mig 4쌍 가운데 이동 ≥ 0.8배·넓이 ≤ 1.2배인 쌍 | ≥ 3 | ≤ 1 |
| **H1** 건강 (후보 30 실행) | 모두 지킨다 | 하나라도 어긴다 |

H1에서 지킬 것:
- 스텝 끝 음수 0
- 부피 오차 < 1e-10
- |버린 부피| < 0.1%
- 끝에 3% 미만 조각 0
- 끝까지 돎

**독립 검증으로 가는 조건**: A1~A6과 H1이 모두 확인이고, F1·F2·M1에 반박이 없다.

**관문 아님**:
- 가지 끝 줄 전체
- 끝 구간(t > 1600)의 덩이 둘 이상·죽은 실·가지 끝
- 몸 수
- 갈라짐 횟수
