## 판정 기준 (후보를 같은 시드의 대조와 견준다)

long 10쌍:
- **F1. 갈라진 시간**(S4 `long_stats`의 `split_frac`).
  - 확인: 후보 평균 ≤ 0.5 × 대조 평균, 그리고 후보가 대조보다 0.05 넘게 큰 쌍이 없다.
  - 반박: 후보 평균 ≥ 대조 평균.
- **F2. 늦은 몸 밖 부피**(t ≥ 1600, 가장 큰 젖은 덩어리 밖 부피 몫의 평균).
  - 확인: ≤ 0.5배. 반박: ≥ 1배.
- **F3. 큰 두꺼운 덩어리 둘 이상인 몫**(t ≥ 100, h ≥ 0.3 덩어리 중 몸 부피의 10% 이상이 둘 이상).
  - 확인: ≤ 0.5배. 반박: ≥ 1배.
  - S7 검증이 짚었듯 이것은 "모였다"가 아니라 "두꺼운 몸이 한 덩어리로 이어져 있다"를 잰다. 이 결승은 "하나로 모인다"를 주장하지 않는다.
- **F4. 늦은 얇은 칸 수**(t ≥ 1600, h < 0.3).
  - 확인: ≤ 1배. 반박: > 1.3배.
- **F5. 끝 줄 칸 수**(t = 2000, 두께와 상관없이 마르면 둘레가 나뉘는 칸 = 실 + 레이스).
  - 확인: ≤ 1배. 반박: > 1.3배.

먹이·이주(S7 결승과 같은 정의):
- **G3. 굶은 이주 (mig 4쌍).** 띠 = 대조 4개의 [최소 − 폭/2, 최대 + 폭/2].
  - 확인: 모든 지표(t_touch, disp300, veinT, vein4, gross_net)에서 3/4 이상 띠 안.
  - 반박: 어느 지표든 0/4가 띠 안이고 나쁜 쪽으로 움직였다.
- **G4. 가까운 먹이 셋 (food3 4쌍 + asym3 2쌍).**
  - 확인: 통과 수 ≥ 대조, 그리고 늦음(대조가 닿은 먹이에 50 시간 넘게 늦거나 못 닿음) ≤ 1.
  - 반박: 통과 수 ≤ 대조 − 2, 또는 늦음 ≥ 3.
- **G5. 먼 먹이 넷 (food4 10쌍).**
  - 확인: "모두 닿음" 수 ≥ 대조 − 1, 그리고 몸 밖 최대 평균 ≤ 대조.
  - 반박: "모두 닿음" 수 ≤ 대조 − 2.

건강(후보 30 실행):
- **G6.**
  - 확인: 아래를 모두 지킨다.
    - 스텝 끝 음수가 있는 실행 0
    - 부피 오차 < 1e-10
    - 버린 부피 몫 < 0.01
    - 끝 젖은 덩어리가 1개인 실행 30/30
  - 반박: 위 넷 가운데 하나라도 어기고, 그 정도가 아래 중 하나다.
    - 음수 실행이 대조보다 2개 이상 많다
    - 부피 오차 ≥ 1e-10
    - 버린 부피 몫 ≥ 0.01
    - 끝 덩어리가 1개가 아닌 실행이 있다

**다음 단계(독립 검증)로 가는 조건**: F1~F5와 G6이 모두 확인이고, G3~G5에 반박이 없다.

**판정과 따로 적을 것(관문 아님)**:
- 끝 넓이 배수
- 끝 실 칸
- 끝 몸 둘레/√넓이: 모양이 얼마나 울퉁불퉁한지
- 조각 하나 최대 < 0.10인 실행 수
- food4 먹이별로 놓친 수
