# 7차 S8 거르기 — 가는 이음도 지켜 얇은 막이 몸으로 빠지게 하기 (실행 전에 적음)

> 2026-11-22. 이 파일은 거르기 실행을 하나도 돌리기 전에 썼다. 판정 스크립트: `scripts/screen_s8.py`.
> 같은 때 S7 독립 검증이 시드 151~170으로 돈다(코어 3개). 그래서 이 거르기는 코어 하나로 차례로 돈다. 시드 171~180은 남겨 두고, 거르기는 181~183을 쓴다.

## 무엇을 바꾸나

`bridge_break`(지금 1.0)를 낮춘다. 마를 차례가 된 칸이 다리 칸이고(그 칸이 마르면 둘레의 젖은 칸이 둘 이상으로 나뉜다) 관 굵기가 이 값 이상이면 말리지 않는다. 낮추면 더 가는 이음까지 지킨다.

- GPU에 이미 있는 값이라 비용은 없다.
- 음수가 된 칸은 다리라도 곧바로 마른다(`neg_dry=1`). 그러니 지킨 이음이 음수로 남지는 않는다.

## 실행 (long, 시드 181~183, 꼬리표마다 3, 모두 15)

| 꼬리표 | 설정 | 견줄 기준 |
|---|---|---|
| `s8c` | 지금 모델 (관문 B 설정) | |
| `s8k` | `sup_age=100` (S7 후보) | `s8c` |
| `s8k3` | `sup_age=100 bridge_break=0.3` | `s8k` |
| `s8k1` | `sup_age=100 bridge_break=0.1` | `s8k` |
| `s8c3` | `bridge_break=0.3` | `s8c` |

## 넘김 조건 (후보마다 기준과 3 시드 평균으로 견준다)

1. 떨어진 얇은 조각(t ≥ 1600, 두꺼운 칸이 하나도 없는 젖은 덩어리의 부피 몫)이 기준의 절반 이하.
2. 늦은 얇은 칸 수(t ≥ 1600)가 기준의 0.85배 이하.
3. 갈라짐이 나빠지지 않는다. 갈라진 시간과 큰 덩어리 둘 이상인 몫 모두 기준 + 0.03 이하.
4. 스텝 끝 음수 0, 부피 오차 < 1e-10.

넘긴 후보는 먹이와 이주를 짧게 확인한다(food3 181, food4 181~182, mig 181). 그다음 새 시드로 결승을 한다. 결승 기준은 그때 실행 전에 따로 적는다.

## 예측

- `s8k3`·`s8k1`: 1은 넘을 것 같다. 2는 경계다. 몸에 붙은 막이 더 오래 이어져 있어, 늦은 얇은 칸이 오히려 늘 수도 있다.
- 3이 가장 위험하다. 가는 이음을 지키면 갈라짐은 줄어야 한다. 하지만 부채 여럿을 실로 묶어 두는 S6의 모습이 돌아올 수 있다(큰 덩어리 둘 이상인 몫이 늘어남).
- `s8c3`도 1은 넘을 것 같다.
