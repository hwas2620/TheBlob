# verify5 판정 기준 (실행 전에 정함)

독립 검증자가 모델 코드(`model/ref_model.py`, `export_ref.py`, `mgt.py`, `graphm.py`)만 읽고 정한 기준이다.
S19 폴더의 다른 문서·스크립트·그림·기록과 남의 실행 폴더는 읽지 않았다. 측정은 모두 `verify5/scripts/` 의 내 코드로 한다
(`v5lib.py` 측정 도구, `measure.py` 실행 하나 측정, `judge.py` 판정, `run_one.sh`·`run_all.sh`·`jobs.txt` 실행).
측정 코드는 실행 전에 가짜 상태(손으로 만든 원판·아령·부스러기)로만 시험했다.

## 2. 공통 정의

- **이어짐**: 토러스 위 8-이웃(모델의 몸 이어짐과 같다). `wet` 마스크의 8-이음 조각이 "조각", 그 부피는 조각의 h(음수는 0으로)의 합. "몸 부피"는 판 전체 젖은 부피의 합이다.
- **몸**: 부피가 전체의 5% 이상인 조각. **부스러기**: 5% 미만인 조각.
- **굵은 셀**: 그 몸 안에서 h ≥ 0.5 × (그 몸의 부피 가중 평균 두께 Σh²/Σh). 모델의 `sup_h` 같은 절대 문턱을 쓰지 않고 몸마다 상대로 잡는다(균핵의 두께 3 도, 얇은 몸도 같은 잣대로 본다).
- **덩이**: 굵은 셀을 반지름 약 2 의 원판(21셀, 폭 5)으로 열기(opening)한 뒤 남은 8-이음 조각 가운데 부피가 그 몸 부피의 10% 이상인 것. 폭 5 보다 좁은 목으로만 이어진 두 굵은 덩어리는 둘로 센다.
- **넓은 부분**: 젖은 마스크를 같은 원판으로 열어 남은 곳(폭 5 이상). **아령**: 한 몸에 덩이가 둘 이상이고, 그 가운데 두 덩이가 서로 다른 '넓은 부분' 조각에 있다(둘 사이가 폭 5 미만의 좁은 실로만 이어짐).
- **실**: 젖은 마스크를 3×3 정사각으로 열어 사라지는 셀(폭 1~2). **꼬리 몫**: 몸의 셀 가운데 '넓은 부분'에 들지 않는 셀의 몫.
- **흐름**: 셀에 닿은 8 간선의 `Qgross`(직전 20 시간 단위의 |Q| 평균) 중 최댓값 F. **흐름 없음**: F < 0.05 × (나이 ≥ 20 인 젖은 셀들의 F 90백분위), 같은 스냅샷 안에서.
- **모양** (몸마다, 토러스는 원형 평균 중심에서 편다): 축비 = √(작은 고윳값/큰 고윳값) (넓이 관성), 볼록채움 = 넓이 / 볼록 껍질 넓이(픽셀 모서리 기준), κ넓이 = (같은 넓이 원판의 회전 반지름) / (몸의 회전 반지름), κ부피 = 같은 것을 h 로 가중.
- **균핵**: 덩이 1개 이고 그 덩이가 몸 부피의 80% 이상, 축비 ≥ 0.6, 볼록채움 ≥ 0.85, κ넓이 ≥ 0.85, 꼬리 몫 ≤ 0.05. (픽셀 원판은 볼록채움 ≈ 0.95, κ ≈ 1.0; 축비 0.6 타원의 κ ≈ 0.94.)
- **갇힘 시각 T_trap**: 점액 위치는 끝 상태(`slime.npy`)에만 있어서, "지금까지 스냅샷에서 한 번이라도 젖었던 셀(처음 원판 포함)의 합집합 U(t)"를 점액의 아래 어림으로 쓴다. 둘레(젖은 몸에 8-이웃한 마른 셀) 가운데 U(t) 에 없는 셀의 몫 r(t) 를 "새 땅 몫"이라 하고, **r(t) < 0.05 이고 그 뒤 모든 스냅샷에서 r < 0.10 인 첫 스냅샷**을 T_trap 으로 둔다. 어림이 점액을 덜 보므로 T_trap 은 늦게 잡히는 쪽이다. 끝 점액 가운데 U 가 놓친 몫도 적는다. 모델 자신의 `t_scl` 은 참고로만 적고, 아래 4c 와 주장 2·3 의 창 끝에만 쓴다.
- 스냅샷은 20 시간 단위마다(`vs_tNNNN.npz`)다. 그 사이에 생겼다 사라진 것은 못 본다(주장 1 은 `metrics.json` 의 `crumb_cells`, 즉 외톨이로 말라 버린 셀 수를 참고로 함께 적는다).

## 3. 통계

- 짝: 같은 시나리오·같은 시드의 대조와 후보.
- "후보가 더 적다/좋다": 짝 차의 한쪽 Wilcoxon 부호 순위 검정(0 차는 뺌), α = 0.05. 하위 항목마다 **L**(좋은 쪽이고 p < 0.05), **N**(짝 차의 평균이 0 이거나 나쁜 쪽), **U**(좋은 쪽이지만 유의하지 않음, 또는 양쪽 모두 0 이라 견줄 사건이 없음).
- "나빠지지 않는다"(비열등): 나쁜 쪽을 + 로 둔 효과 e 와 짝을 다시 뽑는 붓스트랩(20000번, 시드 고정) 90% 구간. **NI**: 구간의 나쁜 쪽 끝 < 여유. **W**(나쁨): 구간 전체가 나쁜 쪽(아래 끝 > 0)이고 e > 여유. 나머지 **U**. 여유: 시각·거리는 대조 평균의 15%, 닿은 먹이 수는 실행당 0.25 개.

## 4. 주장별 측정과 판정

### 주장 1. 부스러기가 없다
- 측정: 모든 시나리오, 모든 실행. t ≥ 100 인 스냅샷마다 부스러기(5% 미만 조각) 수, 그 합("조각-스냅샷"), 앞 스냅샷의 부스러기와 한 셀도 겹치지 않는 "새 부스러기" 수, 끝 상태(`wet.npy`, `h.npy`)의 부스러기 수.
- 판정: **맞음** = 후보 전체에서 t ≥ 100 스냅샷과 끝 상태의 부스러기가 0 이고, 대조가 "많이 만든다"(대조 실행당 조각-스냅샷 평균 ≥ 5 이고 대조 실행의 절반 이상에서 보임). **틀림** = 후보 실행 하나라도 부스러기가 보이거나, 대조가 위 "많이" 조건을 채우지 못함. 실행이 없으면 판정 못 함.

### 주장 2. 옮겨 다니는 동안 덩이가 갈리지 않는다
- 창: `long`, 20 ≤ t ≤ 1600 이고, 짝 두 실행의 T_trap 과 후보의 `t_scl`(있으면) 이전. 창이 스냅샷 20개(400 시간 단위) 미만인 짝은 뺀다.
- 측정(실행마다): 창 안 스냅샷 가운데 (a) 덩이가 둘 이상인 몸이 있는 몫, (b) 아령인 몸이 있는 몫.
- 판정: (a), (b) 각각 위 통계로 L/N/U. **맞음** = 둘 다 L. **틀림** = 하나라도 N. 나머지(또는 쓰인 짝 < 4) **판정 못 함**.
- 민감도(판정에 안 씀): 굵은 셀 문턱 0.4, 0.6; 창 100 ≤ t.

### 주장 3. 죽은 구조가 적다
- 창: 주장 2 와 같다.
- 측정(스냅샷마다, 창 평균): (a) 얇은 막 = '실'이 아니고(폭 3 이상) 나이 ≥ 20 이며 h < 0.35 인 셀의 몫(젖은 넓이에 대한), (b) 흐름 없는 실 = 실 이면서 나이 ≥ 20 이고 흐름 없음인 셀의 몫, (c) 흐름 없는 가지 끝 = 젖은 마스크 골격(skeletonize)의 끝점 가운데 실 위에 있고 나이 ≥ 20 이며 흐름 없음인 것의 개수.
- 판정: (a), (b), (c) 각각 L/N/U. **맞음** = 셋 다 L. **틀림** = 하나라도 N. 나머지 **판정 못 함**.
- 민감도(판정에 안 씀): 막 문턱 0.25·0.5, 흐름 문턱 0.02·0.10, 절대 셀 수, 실 전체 몫, 흐름과 상관없는 가지 끝 수.

### 주장 4. 갇히면 균핵이 된다 (`long`)
- **4a 둥글고 촘촘한 한 덩어리**: T_trap ≤ 1800 인 후보 실행의 끝 상태에서 몸마다 위 '균핵' 판정. 그런 몸의 몫 ≥ 90% **맞음**, < 70% **틀림**, 사이는 판정 못 함. 그런 실행 < 4 이면 판정 못 함.
- **4b 꼬리가 남지 않는다**: 같은 몸들에서 꼬리 몫 ≤ 0.05 인 몸의 몫. 같은 90%/70% 규칙.
- **4c 다시 풀리지 않는다**: 후보 실행마다 시작 t0 = min(T_trap, t_scl). t0 이후 처음으로 모든 몸이 균핵인 스냅샷을 '맺힘'으로 둔다. 그 뒤 스냅샷이 3개 이상인 실행만 본다. '풀림' = 그 뒤 (모든 몸이 균핵은 아님)이 2 스냅샷 연속, 또는 (덩이 둘 이상인 몸)이 2 스냅샷 연속, 또는 젖은 넓이가 맺힐 때의 1.5배를 넘음. 볼 수 있는 실행 ≥ 3 이고 풀린 실행이 0 이면 **맞음**, 하나라도 풀리면 **틀림**, 볼 수 있는 실행 < 3 이면 판정 못 함. (`long` 에는 먹을 먹이가 없으므로 '먹지 않는 한'은 늘 해당한다.)
- **4d 나뉜 몸은 각자 균핵이 될 수 있다**: T_trap 스냅샷에 부피 10% 넘는 몸이 둘 이상인 후보 실행에서, 그 몸마다 끝 상태에서 가장 많이 겹치는 몸을 찾고, 그것이 균핵이며 다른 몸과 합쳐지지 않았는지 본다. 그런 몸의 80% 이상이면 **맞음**, 50% 미만이면 **틀림**, 사이는 판정 못 함, 그런 경우가 없으면 판정 못 함.
- **4e 갇힌 뒤 대조보다 덩이가 적고 더 둥글고 촘촘하다**: 짝 둘 다 T_trap ≤ 1900 인 짝만. 창 1900 ≤ t ≤ 2000 의 스냅샷(6개)에서 몸과 스냅샷을 부피 몫으로 가중한 평균: 덩이 수 max(n, 1)(작을수록; 덩이가 하나도 없는 그물 몸이 이득을 보지 않게), 축비(클수록, '둥근'), κ넓이(클수록, '촘촘한'). 셋 다 L 이면 **맞음**, 하나라도 N 이면 **틀림**, 나머지 또는 짝 < 4 이면 판정 못 함. 볼록채움, κ부피, 꼬리 몫은 참고.
- **주장 4 전체**: 4a~4e 중 하나라도 틀림이면 **틀림**; 4a, 4b, 4c, 4e 가 맞음이고 4d 가 틀림이 아니면 **맞음**; 나머지는 판정 못 함.

### 주장 5. 먹이 찾기와 이주는 나빠지지 않는다
- `food4`, `food3`, `asym3` 마다: (i) 닿은 먹이 수(`t_touch` 가 있는 먹이 수, 여유 0.25 개/실행), (ii) 먹이마다 닿은 시각의 평균(못 닿은 먹이는 T 로, 여유 15%).
- 이주(`mig` 8짝 + `long` 12짝의 t ≤ 400): (iii) t = 400 의 몸 중심 이동 거리(출발점에서 직선, 여유 15%), (iv) 유인원 원판에 닿은 시각(400 넘으면 400, 여유 15%).
- 판정: 8개 하위 항목이 모두 NI 이면 **맞음**, 하나라도 W 이면 **틀림**, 나머지 **판정 못 함**.
- **이주 방향(판정에 안 씀, 크기만 잰다)**: 몸 중심이 출발점에서 처음 35셀 벗어난 때(없으면 t = 400)의 중심 이동 방향이 유인원 방향(27°)에서 어긋난 부호 있는 각. 대조·후보의 평균(부호 있음), |각| 평균, 짝 차, 같은 쪽으로 휜 실행 수.

### 주장 6. 후보 실행은 모두 건강하다
- 실행마다 `metrics.json`: `neg_end_cellsteps == 0` 이고 `h_min_end_of_step ≥ 0`(스텝 끝 음수 두께 없음), `mass_err_max < 1e-10`, `|V_crumb| < 0.001 × (V0 + Vinj)`(버린 부피), `stop == ''` 이고 `steps_done == T/dt + 1`(끝까지).
- 판정: 후보 실행 모두 통과하면 **맞음**, 하나라도 못 하면 **틀림**. 대조도 같은 표로 적는다(판정에 안 씀).

## 5. 예측 (실행 전)

- 주장 1: 후보는 `keep_conn=4` 로 몸이 찢기는 마름을 막고 10% 이상 조각으로만 나뉘므로 부스러기 0 일 것. 대조는 부스러기를 꽤 만들 것. → 맞음 예상.
- 주장 2: `sup_size`, `sup_age` 로 작은 덩이가 늙어 빠지니 덩이 둘 이상은 줄 것. 다만 `keep_conn` 이 찢김을 막아 두 덩이가 실로 이어진 채 남는 '아령'이 오히려 늘 수도 있다. → 불확실(덩이 수는 맞음 쪽, 아령은 반반).
- 주장 3: `ret_h=100` 의 가장자리 거둠으로 얇은 막은 줄 것. 그러나 `keep_conn` 이 지키는 실은 죽은 채 남을 수 있고 `hang_C=20` 이 그 실에 흐름을 억지로 줄 수 있다. → 막은 맞음, 죽은 실·가지 끝은 불확실.
- 주장 4: `scl_disc` 가 몸을 원판 안으로만 적시게 하므로 끝 모양은 둥글 것(그려 넣은 원판에 가까움). `scl_stay` 로 풀리지 않을 것. 꼬리는 `scl_rundry`, `scl_notube` 로 거둬질 것. 대조는 갇혀도 모이지 않아 덜 둥글 것. → 맞음 예상, 4d 는 사례가 없어 판정 못 함일 수 있다.
- 주장 5: 먹이 실험은 크게 다르지 않을 것(먹으면 sup·ret 가 꺼짐). 이주는 휨이 알려져 있어 거리·닿는 시각이 조금 나빠질 수 있다. → 판정 못 함 또는 맞음.
- 주장 6: `dlim_all` 로 음수가 막히고 부피 오차는 반올림 수준일 것. → 맞음 예상.

## 6. 알려진 한계

- 점액은 스냅샷 합집합으로 아래 어림한다. 스냅샷 사이에 잠깐 젖었다 마른 셀은 빠진다(끝 상태로 놓친 몫을 적는다).
- 덩이·실·흐름의 문턱은 코드에서 읽은 물리 크기(새 막 두께 ≈ 1, 관 두께 ≤ 0.5, 마름 문턱 0.15, 흐름 창 20)로 정했고, 실제 분포를 보지 않고 정했다. 그래서 민감도를 함께 적는다.
