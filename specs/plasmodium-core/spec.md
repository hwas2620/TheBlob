# 원형질체 코어 — 부피 보존 두께장 + 유량 구동 전진면 + 전도도 강화 정맥

블롭의 생김새·움직임·행동을 실제 황색망사점균(*Physarum polycephalum*)에 가깝게 만들기 위해
시뮬레이션 코어의 모델을 교체한다. 인프라(WebGL2 핑퐁, 듀얼 캔버스, config 플레이스홀더, 게임 레이어)는 유지한다.

**문서 상태 (2026-11-13): 연구 단계.** 문헌 조사, numpy 수치 실험 2차(실험 7개, 실행 약 400회), 독립 검증 6건까지 끝났다.
모델의 뼈대는 정해졌지만 구현 전에 닫아야 할 이음매가 남아 있다("미해결 문제" 절).
근거 자료는 `specs/plasmodium-core/research/`에 있고, 종합은 `research/round2/SYNTHESIS.md`다.

이 문서에서 "검증됨"은 실험 담당자와 별개의 검증자가 새 난수 시드로 다시 돌려 같은 결과를 얻었다는 뜻이다.
"보고됨"은 담당자 보고만 있다는 뜻이다.

## 현재 상태

### 관련 파일
- `src/gpu/shaders/glsl/agent_update.frag.glsl` — 에이전트 갱신 (Jones SENSE→ROTATE→MOVE + 휴리스틱 5종)
- `src/gpu/AgentGPU.ts` — 에이전트 상태 텍스처(512×256 RGBA32F), occupancy 맵, deposit
- `src/gpu/TrailMapGPU.ts` — trail / food 채널 핑퐁 (R32F 1500×1500, 3×3 평균 확산 + 감쇠)
- `src/gpu/SceneRenderer.ts` — 렌더 패스: 등고선 → `blob_body` → `veins` → `cubic_glow` → 에이전트 점
- `src/gpu/shaders/glsl/blob_body.frag.glsl`, `veins.frag.glsl` — 본체/정맥 렌더링
- `src/simulation/PhysarumSimulation.ts` — `update()` 오케스트레이션, CPU 폴백 경로, 미니맵
- `src/hooks/useGameLoop.ts` — 먹이 → `depositAtPosition`, 흡수 판정(`getParticleDensity`), `addAgents`, 포자화
- `src/config.ts` — `AGENT`, `FOOD`, `CONNECTIVITY`, `BLOB_BODY`, `VEINS`

### 현재 동작
- **몸 = 에이전트 트레일.** 10만 에이전트가 trail을 남기고, `blob_body`가 trail을 임계값 + 색 보간으로 칠한다.
- **Jones 규칙 위에 휴리스틱이 쌓여 있다** (`agent_update.frag.glsl`):
  고립 복귀(섹션 2), 경계 지터·랜덤 탐험·의사족 추종(섹션 3), 16방향 먹이 스캔(섹션 4),
  25% 스카우트 + 밀도 압력(섹션 5), 스카우트/추종자 15배 deposit.
  이들은 Jones의 "가장 진한 쪽으로 회전" 규칙을 프레임마다 덮어쓴다.
- **충돌은 사실상 꺼져 있다**: `AGENT.OCCUPANCY_MULT = 500`.
- **맥동은 전역 사인파 하나**다: `update()`에서 deposit ±40%, speed ±20%를 주기 약 3초로 변조. 공간 구조(파동)가 없다.
- **질량 개념이 없다**: 먹이 흡수 시 `addAgents()`로 에이전트 수만 늘어난다.
- **렌더링은 평면**이다: 두께·법선·광택 정보가 없다.

## 문제 정의

Jones 2010은 수송 네트워크의 **패턴**을 근사하는 모델이고, 점균의 **몸**은 다루지 않는다.
그래서 실제 점균을 점균답게 보이게 하는 요소가 구조적으로 빠져 있고, 휴리스틱으로는 메울 수 없다.

| 실제 점균 | 현재 | 원인 |
|---|---|---|
| 부채꼴 전진면(시트) + 뒤따르는 정맥망 | 굵기가 균일한 그물 | 몸(두께)이라는 상태가 없음 |
| 굵은 간선 → 가는 지선의 위계, 가지치기 | trail 농도만 있음 | 유량·관 굵기 개념이 없음 |
| 1~2분 주기 두께 진동, 연동파, 왕복 원형질 흐름 | 전역 사인파 | 국소 진동자·압력·흐름이 없음 |
| 부피 보존: 앞이 나가면 뒤가 빠진다 | 에이전트가 흩어질 뿐 | 보존량이 없음 |
| 지나간 자리에 점액을 남기고 기피 | trail은 유인만 함 | 세포 밖 흔적 채널이 없음 |
| 젖은 광택, 두께에 따른 투과 | 임계값 + 색 보간 | 높이 정보가 없음 |

## 연구로 밝혀진 것

### 첫 프로토타입이 실패한 이유
첫 모델(`prototype/`)은 압력을 두께의 국소 함수로 두고 포아송 방정식을 풀지 않았다. 여섯 차례, 변형 18종에서
분기 정맥은 한 번도 나오지 않았다. 원인은 모델 구조였다.

분기·위계 정맥이 생기려면 네 가지가 함께 있어야 한다(문헌 + 실험 E1):
1. **몸 전체에서 유량이 보존되는 압력 풀이.** 한 곳의 소스가 먼 곳의 싱크까지 이어져야 유량이 줄기로 모인다.
2. **셀이 아니라 간선(이웃한 두 셀 사이)에 놓인 전도도.** 셀 값으로는 관의 방향이 표현되지 않아 얼룩이 된다.
3. **초선형 강화** `dC/dt = rate·((|Q|/Q0)^γ − C)`, γ > 1. γ ≈ 1이면 고리 많은 그물, γ < 1이면 전체가 찬다. 실측 범위는 1.22~1.58이다.
4. **모인 소스와 퍼진 싱크.** 소스가 점이고 싱크가 전진면 전체일 때 나무가 된다.

### 문헌에서 확인한 것
- 원문을 읽은 어느 모델도 열린 평면에서 부채꼴 전진면이 **스스로** 생기게 하지 못했다(Schenz 2019의 통합 모델은 폭 5mm 채널에서만 돌렸다).
  전진면을 유량으로 미는 방식은 관찰(절단 실험, 전진 속도 ∝ 두께, 수동적으로 밀리는 시트)에 근거한 이 프로젝트의 가설이다.
- 실제 원형질체의 유량은 대부분 왕복이다. 몸 길이에 연동파 한 파장이 걸리고, 관 굵기는 주기 평균 유량에 5~50주기 지연으로 적응한다(Marbach 2023, Alim 2013).
- 점액 기피는 접촉 감지다. 빈 땅과 자기 흔적 중 고를 수 있으면 40번 중 39번 빈 땅을 고르고, 사방이 흔적이면 속도 변화 없이 지나간다(Reid 2012).
- 식과 수치 24개를 원문과 대조했고 옮겨 적은 오류는 없었다. 원문에 근거가 없는 해석 17개는 `research/lit/FULLTEXT-IMPLICATIONS.md`에 따로 적었다.

### 채택하지 않은 주장
검증에서 반박됐거나 근거가 한 번뿐이라 이 문서에 쓰지 않은 것들이다. 전체 목록은 `SYNTHESIS.md` 3.2절.
- 침투 깊이 문턱 δ0/R ≈ 0.2~0.4 (E8): 모델이 눈금 변환에 정확히 불변이라 스윕이 실제로 바꾼 것은 전도도 상한과 정규화였다.
- Jacobi 30~40회로 구현 가능 (E7, E8, E10): 같은 상태에서 직접 풀이와 유량이 34~52% 다르고, 굵은 정맥 유량을 1.8배 과대평가하며, E8 계열에서는 망이 깨졌다.
- 주기 평균 유량으로 강화하면 굵기 구배가 바로잡힌다 (E10): 순간 유량으로도 같다. 원인은 결합 진동자 위상 쪽이다.
- 공통 채점기(`common/eval_morph.py`)의 통과 판정: 폭주 중인 실행과 유량이 거의 없는 대조도 통과했다. 정맥 판정은 간선 그래프 지표로 한다.

## 목표 모델

뼈대는 E10(E7 + 맥동), 강화 법칙과 등방화는 E1, 압력 풀이는 E9에서 가져온다.
**이 셋을 한 실행에서 합쳐 돌린 적은 아직 없다.**

### 상태

격자는 토러스 G×G(G = 512 또는 768, 지도 1500px에 셀 하나가 약 2.9px 또는 2.0px). 멀티그리드 때문에 2의 거듭제곱에 가까운 크기가 필요하다.

| 기호 | 위치 | 의미 |
|---|---|---|
| `wet` | 셀 | 몸이 덮고 있는가 |
| `h` | 셀 | 원형질 두께. **보존량.** 먹이 흡수로만 늘고 대사로만 준다 |
| `age` | 셀 | 젖은 뒤 지난 시간 |
| `θ` | 셀 | 수축 진동자 위상 |
| `slime` | 셀 | 세포 밖 점액 흔적. 몸이 말라 떠난 자리에 남는다 |
| `C` | 간선 | 관 전도도. 8이웃 간선 4방향(E, N, NE, SE)을 RGBA 한 장에 저장 |
| `p` | 셀 | 압력. 매 스텝 풀어서 얻는 값 |
| `c` | 셀 | 먹이 화학물질 (기존 food 채널) |
| 잡음 | 간선, 셀 | 정적 텍스처 두 장. 간선 잡음 `G = exp(0.5·N(0,1))`, 항복 잡음 `η` |

### 규칙 (E10 대표 설정)

```
1 위상    dθ/dt = ω·(1 + 0.1·(1 − e^(−age/τ_a))) + D_θ·Σ_젖은 8이웃 w·sin(θ_j − θ_i)
          늙은 셀이 조금 빨라 뒤에서 앞으로 가는 진행파가 생긴다. 새로 젖은 셀은 부피를 준 이웃의 θ를 물려받는다

2 쉬는 두께  h* = [h0·e^(−age/τ_a)·(1 − (1 − h_fill/h0)·e^(−age/τ_f)) + min(β·√C_인접최대, cap)]·(1 + ε·cos θ)
          새 셀은 차오르고, 늙은 셀은 수축해 부피를 내놓는다(이주의 원인). 관이 있는 셀은 더 두껍다

3 압력    p_i/(κ·dt) + Σ_e W_e·(p_i − p_j) = (h_i − h*_i)/dt,   W_e = G_e·(C_e + r)/L_e
          몸 전체에서 한 번에 푼다 (차폐 포아송)

4 유량    Q_e = W_e·(p_i − p_j),   h_i ← h_i − dt·Σ_e Q_e          유량형 갱신이라 Σh가 정확히 보존된다

5 강화    dC_e/dt = rate·((|Q_e|/Q0)^γ − C_e),   Q0 = 0.2·(활성 간선 평균 |Q|^γ)^(1/γ)

6 마름    h < h_min 이고 age > grace 이면 마른다. 남은 부피는 젖은 이웃에 나눠 주고 slime = 1

7 젖음    마른 셀 j는 젖은 8이웃의 최대 h가
          hy0·(1 + σ_y·η_j) + λ·(3 − 젖은 이웃 수) + y_s·slime_j − y_c·c_j
          를 넘으면 젖는다. 그 이웃에서 min(h_fill, 0.5·h/후보 수)를 받고 age = 0, 새 간선 C = D0·(1 ± 0.3)
```

값: κ=20, h0=1, τ_a=50, τ_f=2, β=0.05, cap=0.5, hy0=1.05, σ_y=0.02, λ=0.06, y_s=0.5, h_fill=0.2, h_min=0.15,
grace=2, γ=1.5, rate=0.05, D0=2, r=0.05, dt=0.1, 맥동 주기 4, ε=0.1, D_θ=8.8, y_c=0.2 (모델 단위).
시간 비: 맥동 주기 40스텝, 관 적응 시간 5주기, 나이 수축 12.5주기.

화면의 관 굵기는 `C^(1/4)`에 비례해 그린다(Poiseuille 관에서 전도도 ∝ 반지름⁴).
모델 안의 정맥은 모두 1셀 폭이고, 굵기 위계는 전도도 값과 이 렌더 규칙으로만 드러난다.

### 입자의 역할
몸은 두께장 `h`가 되고, 정맥은 전도도 `C`가 만든다. Jones 에이전트는 더 이상 몸도 관 형성자도 아니다.
남긴다면 젖은 영역에 갇혀 원형질 흐름을 보여 주는 **표시층**이다(선택 사항). 구조에 관여시키지 않는다.

### 기존 휴리스틱이 무엇으로 대체되는가

| 현재 휴리스틱 | 대체 메커니즘 |
|---|---|
| 스카우트 25%, 의사족 추종, 15배 deposit | 전진면은 규칙 7(두께 항복)이 담당 |
| 16방향 먹이 스캔, 먹이 직행 | 먹이가 항복 문턱을 낮춰 그쪽 전진면이 먼저 나간다 |
| 고립 복귀 탐색 | 입자는 젖은 영역 밖으로 나갈 수 없다 |
| 밀도 압력, 경계 지터 | 실제 압력장 `p`와 항복 잡음 `η` |
| 전역 사인 맥동 | 위상장 `θ`의 진행파 |
| trail 능선으로 그린 정맥 | 간선 전도도 `C` |

## 미해결 문제

위험이 큰 순서다. 1번이 실패하면 이 모델은 구현 경로가 없다.

1. **통합 모델을 멀티그리드로 푼 적이 없다.** E9의 풀이는 순수 포아송과 미리 정한 원반에서만, E7/E10의 몸은 CPU 희소 직접 풀이로만 돌았다.
   자유 경계, 고립 조각 150~190개, 주기적으로 진동하는 우변은 E9에 없던 조건이다.
2. **먹이 점원과 먹이 사이 굵은 관.** 통합 모델의 먹이는 선형 구배 하나뿐이었다. 게임의 핵심 장면(먹이를 찾아 관으로 잇기)이 이 모델에서 시험되지 않았다.
3. **정맥이 조각난다.** 맥동을 켜면 최대 연결 성분이 96%에서 40~51%로 떨어지고 줄기 뒤끝이 마른 흔적 속에서 끊긴다.
4. **격자 방향 잠김.** 창발 전진면에서는 정적 간선 잡음만으로 부족하다. 구배를 27° 돌리면 정맥이 45°와 0° 빗살로 정렬된다.
5. **몸 크기 눈금.** 통합 모델은 192 격자, 몸 길이 약 65셀에서만 돌았다. 맥동 위상차는 (몸 길이)²/D_θ에 비례하므로 몸이 커질 때 D_θ와 τ_a를 어떻게 바꿀지 정해야 한다.
6. **줄기가 어디서 오는가.** 부피 보존에 맞는 퍼진 소스에서는 줄기가 없고(E1), 왕복 유량만으로도 줄기가 없는데(E6), E10에서는 뒤쪽 정맥이 가장 굵다.
   관 부피항에 맥동을 곱한 것이 원인일 수 있다(미시험).
7. **먹이 위에 머무를 때.** 모든 셀의 쉬는 두께가 나이와 함께 0으로 가므로 몸은 계속 새 땅으로 나가야 한다. 먹이 위 셀을 늙지 않는 저장소로 두는 규칙은 코드에만 있다.
8. **WebGL2 실측이 없다.** 아래 비용은 전부 numpy 코드 구성에서 센 추정이다.

구배 없는 환경에서 한 방향으로 이주하지 않는 것(여러 엽으로 사방 팽창)은 결함으로 치지 않는다.
게임에는 항상 먹이가 있고, 무구배 실행의 모습(가운데로 모이는 굵은 줄기 + 여러 전진 엽)은 접종점에서 퍼지는 실제 군체와 어긋나지 않는다는 것이 작성자 판단이다.
대신 점 먹이 쪽으로의 이주를 0단계 기준(B2)에 넣었다.

## GPU 비용 추정 (실측 없음)

스텝당 구성(512² 또는 768² 격자, RGBA32F):

| 단계 | 드로콜 | 격자 풀스크린 환산 |
|---|---|---|
| 위상 갱신 | 1~4 | 1~4 |
| 쉬는 두께·우변 | 1 | 1 |
| 멀티그리드 조대 연산자 재구성 | 7~8 | 0.3 |
| 멀티그리드 V(2,2) 1사이클 | 62~90 | 8~13 |
| 유량·두께 갱신, 전도도 갱신 | 2~3 | 2~3 |
| 정규화용 전역 평균(밉 축소) | 약 10 | 1.3 |
| 마름·젖음 | 5 | 5 |
| 합계 | 약 90~115 | 약 19~26 |

격자 풀스크린 19~26회는 1500² 풀스크린으로 환산하면 768²에서 5~7회, 512²에서 2~3회 분량이다.
채우기 비용은 현재 예산(프레임당 약 60패스) 안으로 보이지만 드로콜 수는 그보다 많다.
전도도를 한 스텝에 5% 넘게 바꾸면 근사 풀이가 따라가지 못해 폭주한다(E9).

## 요구사항

0단계가 통과해야 1~4단계로 간다. 1~4단계는 0단계 결과에 따라 다시 쓴다.

### 0단계 전 — numpy 3차 실험
- [ ] N1. E10 통합 모델의 직접 풀이를 E9 멀티그리드로 바꿔 256²·512²에서 같은 형태가 나오는지. 통과: 직접 풀이 대비 유량 오차 중앙값 ≤ 0.15, 음수 두께 0, 형태 지표가 시드 편차 안
- [ ] N3. 점 먹이를 늙지 않는 저장소로 두었을 때 저장소–전진면 정맥이 이어지는지, 먹이 둘 사이 경로가 굵어지는지. 굵기 구배의 원인 분리(관 부피항 맥동 유무). 통과: 최대 연결 성분 ≥ 0.8, 먹이 사이 경로 전도도 ≥ 전체 중앙값의 10배
- [ ] N2. 등방 젖음 규칙(반지름 2~3 곡률 추정, 공간 상관 잡음, 격자 지터)과 몸 크기 눈금 규칙. 통과: 구배 0°/27°/45°에서 격자 방향 비율 ≤ 0.45
- [ ] N4. (입자층을 남길 경우) E2의 세 주장 재현과, 창발한 젖은 마스크 위에서 입자 그물이 유지되는지

### 0단계 — 브라우저 프로토타입 (게이트)
게임과 분리된 디버그 페이지에서 WebGL2로 구현한다. 정맥 판정은 리드백한 간선 그래프로 하고 렌더 채점은 쓰지 않는다.

관문 A — 풀이 (미리 정한 원반 + 점 소스, E1/E9 복제)
- [ ] A1. 안정성: 1만 스텝, 시드 2개에서 NaN 없음, 최대 전도도가 numpy 기준 실행의 3배 이내
- [ ] A2. 정확도: 200스텝마다 CPU 직접 풀이와 비교한 유량 오차 중앙값 ≤ 0.15, 최댓값 ≤ 0.4
- [ ] A3. 형태: 반지름 0.25/0.5/0.75/0.9R 고리를 지나는 정맥 수가 5~6 / 7~13 / 15~21 / 39~50의 ±20% 안
- [ ] A4. 시간: 내장 GPU에서 스텝당 시뮬레이션 시간과 드로콜 수를 실측. 목표는 프레임 평균 4ms. 못 맞추면 격자를 512²로 낮추거나 k프레임마다 풀고 A1~A3을 다시 통과

관문 B — 몸 (목표 모델 전체)
- [ ] B1. 질량: 1만 스텝에서 총 부피 상대 오차 ≤ 0.1%, 음수 두께 셀 0, 최대 연결 성분 밖 부피 ≤ 10%
- [ ] B2. 전진면: 점 먹이 쪽으로 한 방향 이주(최근 성장의 80% 이상이 120° 구간 안)가 시드 5개 중 4개 이상. 먹이 방향 0°/27°/45° 모두에서 격자 방향 비율 ≤ 0.45
- [ ] B3. 정맥: 최대 연결 성분 ≥ 0.8, Strahler 차수 최대 ≥ 4, 반지름(C^(1/4)) p90/p10 ≥ 2, 전진면에서 멀수록 굵음
- [ ] B4. 맥동: 정맥 총유량/순유량 ≥ 3, 뒤→앞 위상 지연 0.5~2바퀴가 몸 길이를 2배로 바꿔도 유지, 시트 두께 진폭 ≥ 3%
- [ ] B5. 먹이: 점 먹이 3개 이상에 전용 규칙 없이 도달. 도달한 먹이 사이가 정맥 경로로 50주기 이상 이어지고 그 경로 전도도 중앙값이 전체의 10배 이상
- [ ] B6. 점액: 빈 땅과 자기 흔적 중 고를 수 있을 때 빈 땅 쪽 전진이 80% 이상, 사방이 흔적이면 멈추지 않음
- [ ] B7. 지속성: 토러스에서 500주기 동안 몸이 사라지거나 얼어붙지 않고 B1, B3 유지
- [ ] B8. 입자층(선택): 켜도 B1~B7과 A4가 유지되고 몸 밖 입자 1% 미만

관문 A가 실패하면 관문 B로 가지 않는다. B3 또는 B5가 실패하면 방식 D나 "먹이 = 점 소스" 구간만 쓰는 축소안을 검토한다.
이 단계만 먼저 `/plan` → `/implement` 한다.

### 1단계 — 장 파이프라인 (잠정)

## 접근 방식 비교

| 방식 | 장점 | 단점 |
|---|---|---|
| A. 현재 구조 유지 + 튜닝/휴리스틱 추가 | 작업량 최소 | 몸·보존·흐름이 없어 구조적 한계가 그대로 |
| B. 국소 압력 연속체 (두께장 + 셀 전도도) | 풀이가 없어 가장 싸다 | 프로토타입 18종에서 관이 생기지 않음. 구조적으로 불가 |
| C. 하이브리드 (두께장 + Jones 입자가 관 형성) | 기존 에이전트 파이프라인 재사용 | 관이 하나로 뭉치거나 흩어짐. 굵기 위계 없음(E2) |
| D. 그래프 기반 Tero 솔버 (랜덤 메시 + 선형계 풀이) | 정맥 위계가 논문 수준 | 전진면·맥동과 따로 놀고 GPU로 옮기기 어려움 |
| E. 격자 간선 전도도 + 전역 압력(멀티그리드) + 유량 구동 전진면 | 분기·위계 정맥(E1), GPU용 풀이(E9), 창발 전진면·맥동·보존(E7, E10)이 각각 검증됨 | 셋을 합친 실행이 없음. 정맥 조각남, 격자 잠김, 먹이 사이 관 미시험. 풀이 비용이 큼 |

→ **선택: E.** 시험한 것 중 분기 정맥, 전진면, 맥동, 부피 보존을 모두 낸 유일한 계열이다.
확정은 아니다. N1(통합 + 멀티그리드)이 실패하면 구현 경로가 없으므로 D를 다시 검토한다.
