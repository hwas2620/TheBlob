# 원형질체 코어 — 두께장 + 진동 + 관 형성 하이브리드 모델

블롭의 생김새·움직임·행동을 실제 황색망사점균(*Physarum polycephalum*)에 가깝게 만들기 위해
시뮬레이션 코어의 모델을 교체한다. 인프라(WebGL2 핑퐁, 듀얼 캔버스, config 플레이스홀더, 게임 레이어)는 유지한다.

## 현재 상태

### 관련 파일
- `src/gpu/shaders/glsl/agent_update.frag.glsl` — 에이전트 갱신 (Jones SENSE→ROTATE→MOVE + 휴리스틱 5종)
- `src/gpu/AgentGPU.ts` — 에이전트 상태 텍스처(512×256 RGBA32F), occupancy 맵, deposit
- `src/gpu/TrailMapGPU.ts` — trail / food 채널 핑퐁 (R32F 1500×1500, 3×3 평균 확산 + 감쇠)
- `src/gpu/SceneRenderer.ts` — 렌더 패스: 등고선 → `blob_body` → `veins` → `cubic_glow` → 에이전트 점
- `src/gpu/shaders/glsl/blob_body.frag.glsl`, `veins.frag.glsl` — 본체/정맥 렌더링
- `src/simulation/PhysarumSimulation.ts` — `update()` 오케스트레이션, CPU 폴백 경로, 미니맵
- `src/hooks/useGameLoop.ts` — 먹이 → `depositAtPosition`, 흡수 판정(`getParticleDensity`), `addAgents`, 포자화
- `src/config.ts` — `AGENT`, `FOOD`, `CONNECTIVITY`, `BLOB_BODY`, `VEINS`

### 현재 동작
- **몸 = 에이전트 트레일.** 10만 에이전트가 trail을 남기고, `blob_body`가 trail을 임계값 + 색 보간으로 칠한다.
- **Jones 규칙 위에 휴리스틱이 쌓여 있다** (`agent_update.frag.glsl`):
  고립 복귀(섹션 2), 경계 지터·랜덤 탐험·의사족 추종(섹션 3), 16방향 먹이 스캔(섹션 4),
  25% 스카우트 + 밀도 압력(섹션 5), 스카우트/추종자 15배 deposit.
  이들은 Jones의 "가장 진한 쪽으로 회전" 규칙을 프레임마다 덮어쓴다.
- **충돌은 사실상 꺼져 있다**: `AGENT.OCCUPANCY_MULT = 500`.
- **맥동은 전역 사인파 하나**다: `update()`에서 deposit ±40%, speed ±20%를 주기 약 3초로 변조. 공간 구조(파동)가 없다.
- **질량 개념이 없다**: 먹이 흡수 시 `addAgents()`로 에이전트 수만 늘어난다.
- **렌더링은 평면**이다: 두께·법선·광택 정보가 없다.

## 문제 정의

Jones 2010은 수송 네트워크의 **패턴**을 근사하는 모델이고, 점균의 **몸**은 다루지 않는다.
그래서 실제 점균을 점균답게 보이게 하는 요소가 구조적으로 빠져 있고, 휴리스틱으로는 메울 수 없다.

| 실제 점균 | 현재 | 원인 |
|---|---|---|
| 부채꼴 전진면(시트) + 뒤따르는 정맥망 | 굵기가 균일한 그물 | 몸(두께)이라는 상태가 없음 |
| 굵은 간선 → 가는 지선의 위계, 가지치기 | trail 농도만 있음 | 유량·관 굵기 개념이 없음 |
| 1~2분 주기 두께 진동, 연동파, 왕복 원형질 흐름 | 전역 사인파 | 국소 진동자·압력·흐름이 없음 |
| 부피 보존: 앞이 나가면 뒤가 빠진다 | 에이전트가 흩어질 뿐 | 보존량이 없음 |
| 지나간 자리에 점액을 남기고 기피 | trail은 유인만 함 | 세포 밖 흔적 채널이 없음 |
| 젖은 광택, 두께에 따른 투과 | 임계값 + 색 보간 | 높이 정보가 없음 |

## 목표 모델

상태를 다섯 개의 장(field)과 입자 한 종류로 나눈다. 장은 모두 토러스 격자 위에 있다.

| 기호 | 의미 | 비고 |
|---|---|---|
| `h` | 원형질 두께 | **보존량.** 먹이 흡수로만 늘고 대사로만 준다 |
| `φ` | 수축 진동자 위상 | 복소수 `z = e^{iφ}` 2채널로 저장 |
| `D` | 관 전도도 (0~1) | 입자 trail에서 유도: `D = trail / (trail + T0)` |
| `s` | 세포 밖 점액 흔적 (0~1) | 몸이 있던 자리에 쌓이고 아주 느리게 사라짐 |
| `c` | 먹이 화학물질 | 기존 food 채널 그대로 |
| 입자 | Jones 에이전트 | **몸 안에 갇힌 관 형성자.** 더 이상 몸 자체가 아님 |

### 지배 식 (프로토타입에서 사용한 형태)

```
압력   p = κ·(h − h* − η·D)          탄성벽 + 관은 더 두껍게
         + A·sin φ                    능동 수축 (맥동)
         + Q·clamp(1 − h/h_thin, 0,1) 얇은 곳은 짜낸다 (후퇴)
         + P_s·s                      점액 위는 불편하다 (이주)
         − χ·c                        먹이 쪽은 이완된다 (화학주성)

유량   q = −(m0 + m_D·D)·h_상류·∇p    관이 있으면 잘 흐른다
전진   마른 셀로는 p > 항복압(y0 + y_s·s − y_c·c + 잡음)일 때만 유입
보존   ∂h/∂t = −∇·q                   flux-form, 질량 정확히 보존

위상   ∂φ/∂t = ω0·(1 + w_c·c + w_h·(h* − h) − w_s·s) + K·(이웃과 결합)
점액   ∂s/∂t = +r_s·[h>0] − s/τ_s
입자   Jones SENSE→ROTATE→MOVE, 감지값 = trail + a·c − b·s
       이동은 h > h_min 인 셀로만 허용, 추가로 원형질 속도 q/h 에 실려 이류
```

핵심은 **압력 포아송 방정식을 풀지 않는다**는 점이다. 벽을 탄성체로 두면 압력이 `h`의 국소 함수가 되어
전체가 명시적 확산형 갱신(패스당 3×3 이웃 참조)으로 끝난다. 처음 제안했던 Jacobi 압력 풀이는 필요 없다.

### 기존 휴리스틱이 무엇으로 대체되는가

| 현재 휴리스틱 | 대체 메커니즘 |
|---|---|
| 스카우트 25%, 의사족 추종, 15배 deposit | 전진면은 `h`의 압력 구동 전진이 담당 |
| 16방향 먹이 스캔, 먹이 직행 | `−χ·c` 이완 + 항복압 감소 → 원형질이 먹이 쪽으로 흐름 |
| 고립 복귀 탐색 | 입자는 몸 밖으로 나갈 수 없음 (갇힘 규칙) |
| 밀도 압력, 경계 지터 | 실제 압력장 `p` |
| 전역 사인 맥동 | 위상장 `φ`의 진행파 |

## 프로토타입 결과

numpy로 위 식을 그대로 구현해 여섯 차례, 변형 18종을 돌렸다. 스크립트와 결과 이미지는 `specs/plasmodium-core/prototype/`에 있다.

**결론: 몸·맥동·점액·먹이 반응은 확인됐고, 분기된 정맥망은 한 번도 나오지 않았다.**
정맥망은 점균의 인상을 좌우하는 핵심이므로, 이 모델은 아직 전체 구현 계획으로 넘어갈 수준이 아니다.

### 확인된 것
- **질량 보존**: 모든 실행에서 총량 오차 0.05% 이내.
- **맥동 진행파**: 두께의 동심원 진행파가 규칙 없이 생긴다 (`result-hybrid-288.png`).
- **점액 흔적과 후퇴**: 팽창 후 얇아진 가장자리가 수축하며 점액 자국을 남긴다.
- **관 주도 신장과 먹이 반응**: 입자가 만든 관을 따라 몸이 길어지고, 끝이 먹이에 닿아 소비한다.
  스카우트 같은 규칙 없이 일어난다 (`result-hybrid-160.png`).

### 실패한 것
| 시도 | 결과 |
|---|---|
| 순수 연속체: Tero식 적응 `dD/dt ∝ \|q\|^γ − D` (3회, 6종) | `D`가 관이 아니라 뭉툭한 얼룩으로 자람. 몸은 원반 |
| 하이브리드 160², 먹이 3개 (4종) | 입자가 굵은 직선 관 **하나**로 뭉침. 분기 없음 |
| 하이브리드 288², 먹이 6개 (4종) | 스케일을 키워도 직선 관 하나. 먹이 6개 중 1~2개만 도달 |
| 하이브리드 + 셀 점유 제한 (4종) | 입자가 뭉치지 못하고 흩어져 관 자체가 사라짐 |

몸은 모든 실행에서 원반에 가까웠고, 부채꼴 전진면도 나오지 않았다.

### 아직 시험하지 못한 가설
- **스케일 분리**: 프로토타입의 몸 지름은 센서 거리의 12~20배뿐이다. 실제 게임(1500², 에이전트 10만)에서는 수십 배라
  Jones 망이 한 줄로 수렴하기 전에 오래 유지될 수 있다. numpy로는 느려서 확인하지 못했다.
- **고정점**: Jones 망은 먹이 같은 고정점이 있어야 펼쳐진 채 유지된다. 전진면과 먹이에서 입자를 붙잡는 항이 약했을 수 있다.
- **몸의 탈젖음**: 질량 대비 면적을 더 키우면 시트가 스스로 찢어져 망이 될 수 있다.
- **그래프 기반 Tero 솔버**(방식 D)로 정맥만 따로 만드는 방법.

## 요구사항

0단계가 통과해야 1~4단계로 간다. 1~4단계는 0단계 결과에 따라 바뀔 수 있는 잠정안이다.

### 0단계 — 브라우저 프로토타입 (게이트, 결과가 불확실한 연구 단계)
- [ ] 게임과 분리된 디버그 페이지에서 `h`/`φ`/`s` 장 + 갇힌 Jones 입자를 WebGL2로 구현, 실제 스케일(1500², 10만 입자)로 실행
- [ ] 위 "아직 시험하지 못한 가설"을 차례로 시험
- [ ] 통과 기준: (a) 총 질량 오차 1% 이내, (b) 맥동 진행파가 보임, (c) 먹이 3개 이상을 규칙 없이 찾아 연결,
      (d) 먹이 사이에 분기된 정맥이 2단계 이상의 굵기 위계로 유지됨, (e) 프레임당 시뮬레이션 4ms 이내(데스크톱 내장 GPU 기준)
- [ ] **(d)는 numpy 프로토타입에서 실패한 항목이다.** 여기서도 실패하면 1단계 이후를 진행하지 않고 접근 방식을 다시 정한다
- [ ] 이 단계만 먼저 `/plan` → `/implement` 한다. 1~4단계 계획은 0단계 통과 후에 세운다

### 1단계 — 장 파이프라인
- [ ] `PlasmGPU`(가칭): `h`, `z`, `s` 핑퐁 텍스처와 갱신 셰이더. 격자 해상도는 config로 조절(`PLASM.GRID_SCALE`)
- [ ] 질량 보존형 flux-form 갱신, 전진면 항복압 게이트, 유출 제한(음수 두께 방지)
- [ ] 한 프레임 내 부분 스텝 수를 config로 조절, 명시적 갱신의 안정 조건을 config 주석에 명시
- [ ] 초기 상태는 핵 위치의 원형 `h` 덩어리

### 2단계 — 에이전트 역할 변경
- [ ] `agent_update.frag.glsl`에서 섹션 2~5 휴리스틱과 flags=2 강화 deposit 제거
- [ ] 갇힘 규칙(`h > h_min`인 셀로만 이동), 원형질 속도 이류, 몸 밖 입자의 재배치
- [ ] 감지값에 먹이 유인·점액 기피 항 추가
- [ ] trail → `D` 변환을 장 갱신에 연결, `CONNECTIVITY`와 미사용 `ATTRACTION` 항목 정리

### 3단계 — 렌더링
- [ ] `blob_body`를 `h` 높이맵 기반으로 교체: 법선, 스펙큘러(젖은 광택), 두께별 색·투과
- [ ] 정맥은 `D`와 `h` 융기에서 직접 그림. 기존 `veins` 능선 검출 패스는 제거 또는 대체
- [ ] 점액 흔적 레이어(`s`)를 배경 위에 반투명으로 표시
- [ ] 에이전트 점 표시는 "원형질 입자" 뷰로 유지(왕복 흐름이 보이게), 밀집도 뷰·휴면 색 분기 유지
- [ ] 줌 0.25~8배에서 깨지지 않을 것

### 4단계 — 게임 레이어 연결
- [ ] 먹이 흡수 → `h`에 질량 주입(기존 `addAgents` 대체), 입자 수는 총 질량에 비례해 조정
- [ ] 흡수 판정(`getParticleDensity`)을 해당 반경의 `h` 적분으로 교체
- [ ] 휴면: 진동 진폭과 이동도를 낮춤. 포자화 수축: 핵 쪽으로 압력 편향
- [ ] 미니맵을 `h` 기준으로 갱신
- [ ] 세이브 데이터의 `biomass` 의미는 유지
- [ ] `npm run build`, `npm run lint` 통과

### 공통
- [ ] 모든 수치는 `src/config.ts`의 새 그룹(`PLASM`, `OSCILLATOR`, `SLIME`)에 두고 셰이더 플레이스홀더로 치환
- [ ] GPU 초기화 실패 시 기존 CPU 경로(Jones)를 그대로 유지한다. 새 모델은 GPU 전용
- [ ] HMR 재초기화 로직이 새 GPU 리소스도 해제·재생성

## 접근 방식 비교

| 방식 | 장점 | 단점 |
|---|---|---|
| A. 현재 구조 유지 + 튜닝/휴리스틱 추가 | 작업량 최소 | 몸·보존·흐름이 없어 구조적 한계가 그대로. 규칙이 서로 충돌 |
| B. 순수 연속체 (두께장 + Tero식 전도도 적응) | 규칙이 가장 적고 물리적으로 깔끔 | 프로토타입에서 관이 전혀 생기지 않음 |
| C. 하이브리드 (두께장·진동·점액 + Jones 입자가 관 형성) | 프로토타입에서 관 주도 신장·먹이 반응 확인. 기존 에이전트 파이프라인 재사용 | 프로토타입에서 관이 하나로 뭉치고 분기하지 않음 |
| D. 그래프 기반 Tero 솔버 (랜덤 메시 + 선형계 풀이) | 정맥 위계가 논문 수준으로 재현됨 | GPU에서 희소 선형계 풀이가 어렵고, 전진면·맥동과 따로 놂 |

→ **잠정 선택: C (하이브리드)** — 시험한 것 중 유일하게 관과 방향성 있는 신장을 만들었고, 기존 GPU 에이전트 코드를 재사용한다.
다만 분기 정맥망은 아직 어느 방식에서도 확인하지 못했다. 최종 선택은 0단계 결과로 정한다.
0단계에서 C가 실패하면 D(정맥만 그래프로 풀기)를 다음 후보로 검토한다.

## 데이터 흐름

```
[매 프레임 × 부분 스텝]
food 채널 c ──────────────────────────────┐
                                           ▼
h, z, s, D ──► 장 갱신 셰이더 ──► h', z', s'    (압력 계산 → 면 유량 → 보존 갱신)
                    │
                    └─► 속도장 u = q/h ─┐
                                        ▼
에이전트 상태 ──► agent_update (Jones + 갇힘 + 이류) ──► deposit ──► trail ──► D
                                        ▲
                                h, c, s 참조

[렌더]
s ──► 점액 흔적 레이어
h, D ──► blob_body (높이맵 법선·광택·투과, 정맥 융기)
에이전트 ──► 원형질 입자 뷰 (토글)
```
