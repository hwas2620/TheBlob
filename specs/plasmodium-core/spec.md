# 원형질체 코어 — 부피 보존 두께장 + 유량 구동 전진면 + 전도도 강화 정맥

블롭의 생김새·움직임·행동을 실제 황색망사점균(*Physarum polycephalum*)에 가깝게 만들기 위해
시뮬레이션 코어의 모델을 교체한다. 인프라(WebGL2 핑퐁, 듀얼 캔버스, config 플레이스홀더, 게임 레이어)는 유지한다.

**문서 상태 (2026-11-13): 연구 단계, 3차 실험까지 반영.** 문헌 조사와 numpy 수치 실험 3차(실험 10개, 실행 약 600회)가 끝났다.
모델의 뼈대와 GPU로 옮길 수 있는 풀이 경로는 numpy에서 확인됐다. 브라우저에서의 실제 비용과 먹이 사이 관 규칙이 남아 있다("미해결 문제" 절).
근거 자료는 `specs/plasmodium-core/research/`에 있고, 종합은 `research/round2/SYNTHESIS.md`와 `research/round3/SYNTHESIS3.md`다.

이 문서에서 근거의 수준은 셋으로 구분한다.
- **검증됨**: 실험 담당자와 별개의 검증자가 새 난수 시드로 다시 돌려 같은 결과를 얻었다.
- **주 세션 검증**: 검증 에이전트가 사용량 한도로 끊겨 이 문서의 작성자가 이어서 다시 돌렸다. 담당자와는 독립이지만 위보다 약하다.
- **보고됨**: 담당자 보고만 있다.

### 현재 동작
- **몸 = 에이전트 트레일.** 10만 에이전트가 trail을 남기고, `blob_body`가 trail을 임계값 + 색 보간으로 칠한다.
- **Jones 규칙 위에 휴리스틱이 쌓여 있다** (`agent_update.frag.glsl`):
  고립 복귀(섹션 2), 경계 지터·랜덤 탐험·의사족 추종(섹션 3), 16방향 먹이 스캔(섹션 4),
  25% 스카우트 + 밀도 압력(섹션 5), 스카우트/추종자 15배 deposit.
  이들은 Jones의 "가장 진한 쪽으로 회전" 규칙을 프레임마다 덮어쓴다.
- **충돌은 사실상 꺼져 있다**: `AGENT.OCCUPANCY_MULT = 500`.
- **맥동은 전역 사인파 하나**다: `update()`에서 deposit ±40%, speed ±20%를 주기 약 3초로 변조. 공간 구조(파동)가 없다.
- **질량 개념이 없다**: 먹이 흡수 시 `addAgents()`로 에이전트 수만 늘어난다.
- **렌더링은 평면**이다: 두께·법선·광택 정보가 없다.

## 문제 정의

Jones 2010은 수송 네트워크의 **패턴**을 근사하는 모델이고, 점균의 **몸**은 다루지 않는다.
그래서 실제 점균을 점균답게 보이게 하는 요소가 구조적으로 빠져 있고, 휴리스틱으로는 메울 수 없다.

| 실제 점균 | 현재 | 원인 |
|---|---|---|
| 부채꼴 전진면(시트) + 뒤따르는 정맥망 | 굵기가 균일한 그물 | 몸(두께)이라는 상태가 없음 |
| 굵은 간선 → 가는 지선의 위계, 가지치기 | trail 농도만 있음 | 유량·관 굵기 개념이 없음 |
| 1~2분 주기 두께 진동, 연동파, 왕복 원형질 흐름 | 전역 사인파 | 국소 진동자·압력·흐름이 없음 |
| 부피 보존: 앞이 나가면 뒤가 빠진다 | 에이전트가 흩어질 뿐 | 보존량이 없음 |
| 지나간 자리에 점액을 남기고 기피 | trail은 유인만 함 | 세포 밖 흔적 채널이 없음 |
| 젖은 광택, 두께에 따른 투과 | 임계값 + 색 보간 | 높이 정보가 없음 |

## 연구로 밝혀진 것

### 첫 프로토타입이 실패한 이유
첫 모델(`prototype/`)은 압력을 두께의 국소 함수로 두고 포아송 방정식을 풀지 않았다. 여섯 차례, 변형 18종에서
분기 정맥은 한 번도 나오지 않았다. 원인은 모델 구조였다.

분기·위계 정맥이 생기려면 네 가지가 함께 있어야 한다(문헌 + 실험 E1):
1. **몸 전체에서 유량이 보존되는 압력 풀이.** 한 곳의 소스가 먼 곳의 싱크까지 이어져야 유량이 줄기로 모인다.
2. **셀이 아니라 간선(이웃한 두 셀 사이)에 놓인 전도도.** 셀 값으로는 관의 방향이 표현되지 않아 얼룩이 된다.
3. **초선형 강화** `dC/dt = rate·((|Q|/Q0)^γ − C)`, γ > 1. γ ≈ 1이면 고리 많은 그물, γ < 1이면 전체가 찬다. 실측 범위는 1.22~1.58이다.
4. **모인 소스와 퍼진 싱크.** 소스가 점이고 싱크가 전진면 전체일 때 나무가 된다.

### 문헌에서 확인한 것
- 원문을 읽은 어느 모델도 열린 평면에서 부채꼴 전진면이 **스스로** 생기게 하지 못했다(Schenz 2019의 통합 모델은 폭 5mm 채널에서만 돌렸다).
  전진면을 유량으로 미는 방식은 관찰(절단 실험, 전진 속도 ∝ 두께, 수동적으로 밀리는 시트)에 근거한 이 프로젝트의 가설이다.
- 실제 원형질체의 유량은 대부분 왕복이다. 관 굵기는 주기 평균 유량에 5~50주기 지연으로 적응한다(Marbach 2023, Alim 2013).
- 점액 기피는 접촉 감지다. 빈 땅과 자기 흔적 중 고를 수 있으면 40번 중 39번 빈 땅을 고르고, 사방이 흔적이면 속도 변화 없이 지나간다(Reid 2012).
- 식과 수치 24개를 원문과 대조했고 옮겨 적은 오류는 없었다. 원문에 근거가 없는 해석 17개는 `research/lit/FULLTEXT-IMPLICATIONS.md`에 따로 적었다.

### 채택하지 않은 주장
검증에서 반박됐거나 근거가 약해 이 문서에 쓰지 않은 것들이다. 전체 목록은 두 종합 문서에 있다.
- 침투 깊이 문턱 δ0/R ≈ 0.2~0.4 (E8): 스윕이 실제로 바꾼 것은 전도도 상한과 정규화였다.
- Jacobi 30~40회로 구현 가능 (E7, E8, E10): 유량 오차 0.93, 음수 두께, 이동 속도 65%. 정맥 그래프 지표는 정상으로 나와 실패가 드러나지 않았다(N1).
- E9 멀티그리드를 그대로, 스텝당 1사이클로 쓴다 (2차 종합의 비용 추정): 통합 모델에서는 발산하거나 불합격이다(N1).
- 유출 제한으로 음수 두께를 막는다: 필요 없고, 직접 풀이의 결과까지 바꾼다(N1).
- 뒤쪽 정맥이 굵은 것은 관 부피항에 곱한 맥동 때문이다 (2차 종합의 후보 설명): 켜고 끈 차이가 시드 편차 안이다(N3).
- 먹이를 늙지 않는 저장소로 두면 먹이 사이 관이 남는다 (2차 종합의 가설): 15~35주기 안에 가늘어진다(N3).
- 맥동 위상차가 몸 길이의 제곱에 비례해 커진다: 몸이 2배 넘게 커져도 0.9~1.2바퀴였다(N1 실행 재분석).
- 공통 채점기(`common/eval_morph.py`)의 통과 판정: 변별력이 없다. 정맥 판정은 간선 그래프 지표로, 풀이 판정은 유량 오차와 이동 속도로 한다.

## 목표 모델

뼈대는 E10(E7 + 맥동), 강화 법칙은 E1, 압력 풀이는 E9를 N1에서 고친 것, 젖음 판정은 N2에서 고친 것, 먹이 규칙은 N3에서 가져온다.
통합 모델과 멀티그리드를 합친 실행은 N1에서 512²까지 돌았다. **N2·N3의 규칙을 멀티그리드와 합쳐 돌린 적은 아직 없다.**

```
          몸 전체에서 한 번에 푼다 (차폐 포아송). 풀이는 아래 "압력 풀이"

          Q0를 고정하면 근사 풀이에서 전도도가 폭주하고 음수 두께가 난다. 자동 정규화를 유지한다

6 마름    h < h_min 이고 age > grace 이면 마른다. 남은 부피는 젖은 이웃에 나눠 주고 slime = 1

7 젖음    마른 셀 j가 보는 두께 P_j = max(축 이웃 4개의 h, 대각 4방향의 보간값)
          대각 보간값 = [a(1−a)·(그 사분면 축 이웃 둘의 h) + a²·(대각 이웃의 h)] / (젖은 셀의 가중치 합),  a = 0.92/√2
          P_j > hy0·(1 + σ_y·η_j) + 8λ·(f_ref − f_j) + y_s·slime_j − y_c·c_j  이면 젖는다.  f = 젖은 마스크의 가우스 흐림(σ = 2셀)
          8이웃 중 가장 두꺼운 셀에서 min(h_fill, 0.5·h/후보 수)를 받고 age = sage = 0, 새 간선 C = D0·(1 ± 0.3)

8 먹이    먹이 위의 젖은 셀은 sage가 멈추고, 단위 시간당 eat 만큼 M을 줄이면서 같은 만큼 h를 늘린다
          M이 0이 되면 그 먹이의 유인장이 사라지고 셀은 다시 늙는다
```

값: κ=20, h0=1, τ_a=50, τ_f=2, β=0.05, cap=0.5, hy0=1.05, σ_y=0.02, λ=0.06, f_ref=0.33, y_s=0.5, h_fill=0.2, h_min=0.15,
grace=2, γ=1.5, rate=0.05, D0=2, r=0.05, dt=0.1, 맥동 주기 4, ε=0.1, D_θ=8.8, y_c=0.2, eat=0.1 (모델 단위).
시간 비: 맥동 주기 40스텝, 관 적응 시간 5주기, 나이 수축 12.5주기.

규칙 7의 원래 꼴(E7, E10)은 "젖은 8이웃의 최대 h가 hy0·(1 + σ_y·η) + λ·(3 − 젖은 이웃 수) + … 를 넘으면 젖는다"였다.
이 꼴은 대각선 방향 전진이 1.7배 빠르고 윤곽이 팔각형이 된다(N3 검증). 위의 꼴은 N2에서 고친 것이고 독립 검증이 없다.

화면의 관 굵기는 `C^(1/4)`에 비례해 그린다(Poiseuille 관에서 전도도 ∝ 반지름⁴).
모델 안의 정맥은 모두 1셀 폭이고, 굵기 위계는 전도도 값과 이 렌더 규칙으로만 드러난다.

### 압력 풀이 (N1)

- 멀티그리드 V(2,2), 감쇠 Jacobi ω=0.8, 2×2 합 제한, 조각 상수 보간. 전부 9점 스텐실과 2×2 축소·확대라 리드백이 없다.
- 조대 연산자는 매 스텝 다시 만든다. **간선 가중치는 /1.5, 차폐 항(대각의 1/(κ·dt))은 자식 합 그대로.** 차폐 항까지 나누면 발산한다.
- **스텝당 2사이클.** 직전 스텝의 해에서 시작한다. `p₀ = p_n + 0.5·(p_n − p_{n−1})`로 외삽하면 오차가 절반이 된다(계수 1.0은 발산).
- 최조 격자 Jacobi는 4회면 된다.
- 유출 제한은 넣지 않는다.
- 풀이가 맞는지는 유량 오차(CPU 직접 풀이 대비)와 이동 속도로 확인한다.

### 입자의 역할
몸은 두께장 `h`가 되고, 정맥은 전도도 `C`가 만든다. Jones 에이전트는 더 이상 몸도 관 형성자도 아니다.
남긴다면 젖은 영역에 갇혀 원형질 흐름을 보여 주는 **표시층**이다(선택 사항). 구조에 관여시키지 않는다.

## 미해결 문제

위험이 큰 순서다.

1. **WebGL2 실측이 없다.** 아래 비용은 numpy 코드 구성에서 센 값이다. 스텝당 드로콜 약 137~153은 현재 예산(약 60패스)의 2배가 넘는다.
2. **먹이 사이 굵은 관.** 게임의 핵심 장면인데 결함 없는 규칙이 없다. 먹이 원반의 쉬는 두께를 4배로 하고 막다른 끝부터 마르게 하면 관이 남지만(5/5 시드),
   정맥망이 관 하나로 줄고, 몸이 갈라지고, 음수 두께가 나고, 관이 짧아지지 않는다.
3. **정맥이 조각난다.** 이주 중 정맥의 최대 연결 성분은 24~55%다(먹이 실행에서 잰 값으로는 시트까지 합치면 94% 이상 이어져 있다). 풀이의 안정 여유도 깎는다.
4. **몸이 먹이에 머무르지 않는다.** 먹이 근처의 부피는 5~9%이고 고리 모양 전진면이 계속 밖으로 나간다.
5. **큰 격자.** 통합 모델이 384²를 넘는 격자에서 이주까지 간 실행이 없다. 768²는 돌린 적이 없다.
6. **풀이 여유.** 2사이클은 384²에서 유량 오차 중앙값 0.135~0.15로 기준에 붙어 있다. 외삽이나 3사이클을 기본으로 잡는 편이 안전하다.
7. **고친 젖음 판정의 검증.** 독립 검증, 멀티그리드, 큰 격자, 장시간 실행이 없다.
8. **정맥의 격자 정렬.** 간선이 8방향뿐이라 45°로 곧게 뻗은 평행한 정맥이 보인다. 손대지 못했다.
9. **입자층.** N4를 돌리지 못했고 E2도 미검증이다.

구배 없는 환경에서 한 방향으로 이주하지 않는 것(여러 엽으로 사방 팽창)은 결함으로 치지 않는다.
게임에는 항상 먹이가 있고, 무구배 실행의 모습(가운데로 모이는 굵은 줄기 + 여러 전진 엽)은 접종점에서 퍼지는 실제 군체와 어긋나지 않는다는 것이 작성자 판단이다.

## GPU 비용 추정 (실측 없음)

스텝당 구성(RGBA32F, 2사이클, 최조 격자 Jacobi 4회). N1 코드에서 센 값이다.

| 단계 | 512² 드로콜 | 768² 드로콜 | 격자 풀스크린 환산 |
|---|---|---|---|
| 위상 갱신 (부분 스텝 4회) | 4 | 4 | 4 |
| 쉬는 두께·우변, 간선 가중치 | 2 | 2 | 2 |
| 조대 연산자 재구성 | 7 | 8 | 0.3 |
| 멀티그리드 V(2,2) 2사이클 | 106 | 120 | 16.7 |
| 유량·두께 갱신, 전도도 갱신 | 2 | 2 | 2 |
| 정규화용 전역 평균 (밉 축소) | 9 | 10 | 1.3 |
| 마름·젖음 | 5 | 5 | 5 |
| 젖은 마스크 가우스 흐림 (규칙 7) | 2 | 2 | 2 |
| 합계 | 약 137 | 약 153 | 약 33 |

격자 풀스크린 33회는 1500² 풀스크린으로 환산하면 512²에서 약 4회, 768²에서 약 9회 분량이다.
채우기 비용은 현재 예산 안으로 보이지만 드로콜 수는 2배가 넘는다. 조대 격자 패스는 채울 픽셀이 거의 없어 FBO 전환 비용이 관건이다.
줄이는 방법(조대 레벨을 한 장에 모으기, 잔차와 제한 합치기, 2프레임에 한 번 풀기)은 아직 시험하지 않았다.
전도도를 한 스텝에 5% 넘게 바꾸면 근사 풀이가 따라가지 못한다(E9).

### 0단계 — 브라우저 프로토타입 (게이트)
게임과 분리된 디버그 페이지에서 WebGL2로 구현한다. 정맥 판정은 리드백한 간선 그래프로 하고 렌더 채점은 쓰지 않는다.

관문 A — 풀이와 비용
- [ ] A0. 재생 시험: numpy가 저장한 상태(간선 가중치, 우변, 젖은 마스크)를 텍스처에 넣고 사이클 수별 유량 오차를 재서 numpy 값과 맞는지 확인
- [ ] A1. 안정성: 통합 모델 1만 스텝, 시드 2개에서 NaN 없음, 음수 두께 셀 0, 최대 전도도가 numpy 기준 실행의 3배 이내
- [ ] A2. 정확도: 200스텝마다 CPU 직접 풀이와 비교한 유량 오차 중앙값 ≤ 0.15, 99백분위 ≤ 0.4. 이동 속도가 numpy 직접 풀이 실행의 ±10% 안
- [ ] A3. 시간: 내장 GPU에서 스텝당 시뮬레이션 시간과 드로콜 수를 실측. 목표는 프레임 평균 4ms. 못 맞추면 격자를 512²로 낮추거나, 조대 레벨을 한 장에 모으거나, k프레임마다 풀고 A1·A2를 다시 통과

관문 B — 몸 (목표 모델 전체)
- [ ] B1. 질량: 1만 스텝에서 총 부피 상대 오차 ≤ 0.1%, 음수 두께 셀 0, 최대 연결 성분 밖 부피 ≤ 10%
- [ ] B2. 전진면: 점 먹이 쪽으로 한 방향 이주가 시드 5개 중 4개 이상. 같은 거리의 먹이에 닿는 시각의 방향별(0°/13°/27°/34°/45°) 최대/최소 ≤ 1.1. 정맥 현의 격자 방향 비율 ≤ 0.45
- [ ] B3. 정맥: 시간 평균한 전도도로 잰 최대 연결 성분 ≥ 0.8, Strahler 차수 최대 ≥ 4, 반지름(C^(1/4)) p90/p10 ≥ 2, 전진면에서 멀수록 굵음
- [ ] B4. 맥동: 정맥 총유량/순유량 ≥ 3, 뒤→앞 위상 지연 0.5~2바퀴가 몸 길이를 2배로 바꿔도 유지, 시트 두께 진폭 ≥ 3%
- [ ] B5. 먹이: 점 먹이 3개 이상에 전용 규칙 없이 도달. 도달한 두 먹이가 50주기 이상 같은 정맥 성분에 있고, 그 사이 경로의 최소 전도도가 정맥 전도도의 90백분위 이상. 몸이 갈라지지 않음(가장 큰 몸 성분의 부피 ≥ 0.9)
- [ ] B6. 점액: 빈 땅과 자기 흔적 중 고를 수 있을 때 빈 땅 쪽 전진이 80% 이상, 사방이 흔적이면 멈추지 않음
- [ ] B7. 지속성: 토러스에서 500주기 동안 몸이 사라지거나 얼어붙지 않고 B1, B3 유지

## 접근 방식 비교

| 방식 | 장점 | 단점 |
|---|---|---|
| A. 현재 구조 유지 + 튜닝/휴리스틱 추가 | 작업량 최소 | 몸·보존·흐름이 없어 구조적 한계가 그대로 |
| B. 국소 압력 연속체 (두께장 + 셀 전도도) | 풀이가 없어 가장 싸다 | 프로토타입 18종에서 관이 생기지 않음. 구조적으로 불가 |
| C. 하이브리드 (두께장 + Jones 입자가 관 형성) | 기존 에이전트 파이프라인 재사용 | 관이 하나로 뭉치거나 흩어짐. 굵기 위계 없음(E2) |
| D. 그래프 기반 Tero 솔버 (랜덤 메시 + 선형계 풀이) | 정맥 위계가 논문 수준 | 전진면·맥동과 따로 놀고 GPU로 옮기기 어려움 |
| E. 격자 간선 전도도 + 전역 압력(멀티그리드) + 유량 구동 전진면 | 분기·위계 정맥, 창발 전진면, 맥동, 부피 보존이 한 모델에서 나오고, GPU로 옮길 수 있는 풀이로 512²까지 돌았다(N1) | 풀이 비용이 크고 실측이 없음. 먹이 사이 관 미해결, 정맥 조각남 |

→ **선택: E.** 시험한 것 중 분기 정맥, 전진면, 맥동, 부피 보존을 모두 낸 유일한 계열이고, N1에서 구현 경로가 확인됐다.
남은 가부 판정은 0단계 관문 A의 비용 실측이다. 프레임 예산에 넣지 못하면 격자를 줄이거나 D를 다시 검토한다.
