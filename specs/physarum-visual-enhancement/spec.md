# Physarum 비주얼 개선 — 리얼리스틱 렌더링

## 비주얼 레퍼런스

`docs/reference/` 참고 — 실물 Physarum 타임랩스/접사/포자화 사진 수록.

## 현재 상태

Jeff Jones 알고리즘은 논문 100% 준수 상태. 렌더링만 개선하면 실제 점균류에 가까워짐.

### 관련 파일
- `src/config.ts` — 모든 렌더링 파라미터
- `src/gpu/shaders/glsl/blob_body.frag.glsl` — 본체 셰이더
- `src/gpu/shaders/blob_body.ts` — 본체 플레이스홀더 치환
- `src/gpu/shaders/glsl/veins.frag.glsl` — 정맥 셰이더
- `src/gpu/shaders/veins.ts` — 정맥 플레이스홀더 치환
- `src/hooks/useGameLoop.ts` — clearColor 설정
- `src/index.css` — CSS 배경색
- `src/store/gameStore.ts` — loadGame 검증

## Phase 2: 레퍼런스 색상 매칭 (진행 중)

### 물리 모델 (핵심 인사이트)

실물 Physarum의 색상 구성:
- **본체 원형질** = 노란색 반투명 막
- **기질(agar)** = 어두운 초록/검정
- **올리브그린 외관** = 노란 막이 초록 기질 위에 겹쳐서 생기는 착시

→ 구현: 본체를 올리브그린으로 직접 칠하는 것이 아니라,
**배경을 초록으로, 본체를 노란 반투명으로** 설정해서 자연스러운 올리브 합성

### 2-1. 배경 = 어두운 초록 기질 (agar)
- [x] CLEAR_COLOR: `(15,12,8)` → `(8,20,10)` 어두운 초록
- [x] CSS 배경: `#08140a`

### 2-2. 본체 = 노란 반투명 원형질
- [x] ACTIVE_BASE: `(245,225,140)` → `(220,200,60)` 밝은 황색
- [x] ACTIVE_DARK: `(200,175,80)` → `(160,140,30)` 어두운 황색
- [x] MEMBRANE_COLOR: `(100,220,80)` → `(180,170,40)` 연한 황색
- [x] BODY_MAX_ALPHA 추가: `0.85` (고밀도→거의 불투명, 저밀도→반투명)
- [x] 알파 공식: `smoothstep(0.1, 0.5, densityT) * BODY_MAX_ALPHA` (S커브)

### 2-3. 정맥 = 밝은 노란색 (농축 원형질)
- [x] MAJOR_COLOR: `(0.95,0.88,0.55)` → `(0.95,0.88,0.35)` 밝은 황금색
- [x] MINOR_COLOR: `(0.88,0.78,0.45)` → `(0.80,0.72,0.25)` 중간 황색

### 2-4. 정맥 에이전트 노이즈 제거 ✅
- [x] 정맥 입력 3x3 블러 (STEP 간격 기준) → 에이전트 개별 경로 평활화
- [x] 능선 검출 범위 확대: STEP → STEP×2 이웃 비교
- [x] ridgeStrength에 smoothstep(0.2, 0.5) → 약한 릿지 완전 제거, 강한 릿지만 선명

### 2-5. 본체 알파 다이나믹 레인지 확대 ✅
- [x] MAX_VALUE: 60 → 150 (트레일 실분포: 중심~130, 의사족~30)
- [x] 알파 공식: `sqrt(densityT)` → `smoothstep(0.1, 0.5, densityT)` (S커브)
  - 저밀도 = 완전 투명 (의사족: 초록 비침 → 올리브)
  - 중~고밀도 = 빠르게 불투명 전환 (중심: 단단한 노랑)

## 레퍼런스 대비 갭 분석

| 요소 | 레퍼런스 | 현재 상태 | 남은 작업 |
|------|----------|----------|----------|
| 본체 색상 | 올리브그린 (노랑+초록 합성) | ✅ 중심=노랑, 의사족=올리브 | 미세 조정 |
| 정맥 | 깨끗한 밝은 라인 | 3x3 블러+smoothstep 적용 | 시각 확인 후 판단 |
| 배경 | 순수 검정/어두운 초록 | ✅ 어두운 초록 | — |
| 가장자리 | 매끄러운 유기적 곡선 | 스펙클/점점이 | 추후 개선 |
| 후기 변화 | 본체 소멸→정맥만 | 미구현 | 추후 |
