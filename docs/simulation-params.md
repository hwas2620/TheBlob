## 논문별 알고리즘 상세

### 1. MCPM (Monte Carlo Physarum Machine)

**출처:** Burchett et al., "Tracing the Cosmic Web" (2020)

**핵심 아이디어:**
- Jeff Jones의 결정론적 규칙을 확률적 선택으로 일반화
- 센서 값을 확률 분포로 변환

**알고리즘:**
```
각 센서 방향의 트레일 값: T_left, T_front, T_right

확률 계산:
  P(left)  = T_left^β  / (T_left^β + T_front^β + T_right^β)
  P(front) = T_front^β / (T_left^β + T_front^β + T_right^β)
  P(right) = T_right^β / (T_left^β + T_front^β + T_right^β)

방향 선택:
  rand = random(0, 1)
  if rand < P(left): turn_left()
  elif rand < P(left) + P(front): go_straight()
  else: turn_right()
```

**β (베타) 파라미터 효과:**

| β 값 | 동작 | 특징 |
|------|------|------|
| 0 | 완전 랜덤 | 모든 방향 33.3% 확률 |
| 1 | 선형 비례 | 트레일 10:5:1 → 확률 62.5%:31.2%:6.3% |
| 2 | 제곱 비례 | 트레일 10:5:1 → 확률 79.4%:19.8%:0.8% |
| 4 | 4승 비례 | 강한 방향 집중, 탐험 감소 |
| ∞ | 결정론적 | Jeff Jones와 동일 (argmax) |

**장점:**
- 로컬 미니마 탈출 (약한 방향도 선택 가능)
- 단일 파라미터(β)로 탐험/착취 조절
- 네트워크 다양성 증가

**주의점:**
- β < 1: 네트워크 형성 어려움 (너무 랜덤)
- β > 5: Jeff Jones와 사실상 동일
- **권장: β = 2 ~ 3**

### 2. Robust Modelling for Foraging Behaviour (2025)

**출처:** Journal of Computational Biology, 2025

**핵심 아이디어:**
- 각 에이전트가 에너지(E) 상태 보유
- 에너지 기반 행동 모드 전환

**상태 변수 (에이전트당):**
```
E: 에너지 (0 ~ E_max)
mode: 'forage' | 'explore' | 'return'
```

**에너지 규칙:**
```
매 스텝:
  E -= move_cost (0.01 ~ 0.1)

먹이 발견 시:
  E += food_value (10 ~ 100)
  E = min(E, E_max)
```

**모드 전환:**
```
if E < E_low_threshold (20%):
  mode = 'explore'  // 랜덤 탐색

if E < E_critical (5%):
  mode = 'return'   // 중심으로 복귀

if E > E_high_threshold (50%):
  mode = 'forage'   // 일반 센서 기반
```

**각 모드 동작:**

| 모드 | 센서 사용 | 랜덤성 | 특수 동작 |
|------|----------|--------|----------|
| forage | O | 낮음 | Jeff Jones 기본 |
| explore | X | 높음 | 랜덤 방향, 더 빠른 이동 |
| return | O | 중간 | 중심 방향 유인 추가 |

**장점:**
- 생물학적으로 현실적
- 자연스러운 탐험/착취 균형
- 에이전트 개별 상태로 다양한 행동

**추가 파라미터:**

| 파라미터 | 권장값 | 설명 |
|----------|--------|------|
| move_cost | 0.05 | 이동당 에너지 소비 |
| food_value | 50 | 먹이당 에너지 획득 |
| E_max | 100 | 최대 에너지 |
| E_low | 20 | 탐험 모드 진입 |
| E_critical | 5 | 복귀 모드 진입 |
| E_high | 50 | 정상 모드 복귀 |

### 3. PhysOM (Physarum for Organizational Modelling, 2024)

**출처:** Complex Systems Conference 2024

**핵심 아이디어:**
- 단일 페로몬 대신 다중 페로몬 타입
- 각 타입마다 다른 감쇠/확산 특성

**페로몬 타입:**

| 타입 | 역할 | 감쇠율 | 확산 | 반응 |
|------|------|--------|------|------|
| **food** | 먹이 경로 | 0.99 (느림) | 높음 | 강한 유인 |
| **explore** | 탐험 흔적 | 0.90 (빠름) | 낮음 | 약한 회피 |
| **danger** | 위험 표시 | 0.95 | 중간 | 강한 회피 |

**센서 계산:**
```
// 각 방향에서 세 페로몬 모두 감지
attract = food_trail * 1.0 - explore_trail * 0.3 - danger_trail * 0.8

// 최종 방향 결정은 attract 값 기반
```

**분비 규칙:**
```
매 스텝:
  deposit explore_pheromone (약하게, 지나간 곳 표시)

먹이 발견 시:
  deposit food_pheromone (강하게, 경로 표시)

막다른 길 시:
  deposit danger_pheromone (중간, 경고)
```

**장점:**
- 이미 탐험한 곳 자연스럽게 회피
- 먹이 경로는 오래 유지
- 복잡한 환경에서 더 효율적

**구현 요구사항:**
- 트레일맵 텍스처: R32F → RGB32F (채널 3개)
- 메모리: 1500×1500×12바이트 = 27MB (기존 9MB의 3배)
- 셰이더: 3채널 읽기/쓰기

### 기본값 마커 구현

슬라이더에 기본값 위치를 시각적으로 표시:

```tsx
// 기본값 마커 스타일
<div className="relative">
  <input type="range" ... />
  {/* 기본값 마커 (세로선) */}
  <div
    className="absolute top-0 h-full w-0.5 bg-yellow-500/50 pointer-events-none"
    style={{ left: `${defaultPosition}%` }}
  />
  {/* 기본값 라벨 (호버 시 표시) */}
  <div
    className="absolute -top-5 text-xs text-yellow-500/70"
    style={{ left: `${defaultPosition}%`, transform: 'translateX(-50%)' }}
  >
    ●
  </div>
</div>
```

**시각적 표현:**
- `┃` : 기본값 위치 (노란색 세로선)
- `●` : 기본값 마커 (슬라이더 위에 점)
- 현재값이 기본값과 다르면 "초기화" 버튼 활성화

## 알고리즘별 장단점 비교

### 1. MCPM (Monte Carlo Physarum Machine)

| 구분 | 내용 |
|------|------|
| **장점** | |
| 구현 용이 | 기존 Jeff Jones 코드에 확률 선택만 추가 (10줄 미만) |
| 단일 파라미터 | β 하나로 탐험/착취 균형 조절 |
| 로컬 미니마 탈출 | 약한 방향도 선택 가능 → 막힌 곳 탈출 |
| 네트워크 다양성 | 동일 조건에서도 다양한 패턴 생성 |
| **단점** | |
| β 튜닝 필요 | 적절한 β 찾기까지 실험 필요 |
| 수렴 속도 저하 | 확률적 선택 → 최적 경로 형성이 느림 |
| 예측 불가 | 동일 초기조건에서도 다른 결과 |

**적합한 상황:** 현재 "먹이를 못 찾는" 문제 해결에 가장 적합. 구현 쉽고 효과적.

### 2. Robust Modelling for Foraging Behaviour (에너지 기반)

| 구분 | 내용 |
|------|------|
| **장점** | |
| 생물학적 현실성 | 실제 점균류의 행동과 유사 |
| 자연스러운 전환 | 배고픔 → 탐험, 포만 → 안정 |
| 개별 에이전트 상태 | 다양한 행동 패턴 자연 발생 |
| 자가 조절 | 먹이 부족 시 자동으로 탐험 증가 |
| **단점** | |
| 파라미터 많음 | move_cost, food_value, 임계값 3개 등 6개+ |
| 상태 저장 필요 | 에이전트당 에너지 값 저장 (GPU 텍스처 채널 추가) |
| 밸런싱 어려움 | 에너지 소비/획득 비율 조절 복잡 |
| 게임 메카닉 충돌 | 기존 biomass/ATP 시스템과 중복 가능 |

**적합한 상황:** 더 현실적인 시뮬레이션 원할 때. 하지만 구현 복잡도 높음.

### 3. PhysOM (다중 페로몬)

| 구분 | 내용 |
|------|------|
| **장점** | |
| 탐험 자동화 | explore 페로몬으로 이미 간 곳 자동 회피 |
| 경로 최적화 | food 페로몬은 오래 유지 → 효율적 경로 형성 |
| 위험 회피 | danger 페로몬으로 막다른 길 표시 가능 |
| 확장성 | 새 페로몬 타입 추가로 행동 확장 가능 |
| **단점** | |
| 메모리 3배 | R32F → RGB32F (9MB → 27MB) |
| 성능 영향 | 3채널 읽기/쓰기 → GPU 부하 증가 |
| 복잡한 밸런싱 | 각 페로몬의 감쇠율, 분비량, 반응 강도 조절 |
| 시각화 어려움 | 3종류 페로몬을 어떻게 보여줄지 고민 필요 |

**적합한 상황:** 복잡한 환경(미로, 장애물)에서 효율적. 현재 프로젝트에는 과도할 수 있음.

## 알고리즘 선택 가이드

| 현재 문제 | 추천 알고리즘 | 이유 |
|-----------|--------------|------|
| 먹이 못 찾음 | **MCPM** | 간단하고 효과적, β=2~3으로 시작 |
| 탐험 부족 | MCPM 또는 Foraging | 둘 다 탐험 강화 |
| 네트워크 안 형성 | Jeff Jones 유지 | 결정론적 규칙이 안정적 네트워크 형성 |
| 현실적 시뮬레이션 | Foraging | 생물학적으로 가장 현실적 |
| 복잡한 환경 | PhysOM | 장애물, 미로 등에 효과적 |
