# 게임 방향성 역할극 결과

> 날짜: 2026-02-27
> 논제: TheBlob이 게임이 맞는가? 어떤 방향이 최적인가?
> 참가자: 민준(인크리멘탈), 서연(서바이벌/전략), 하늘(토이/아트), 지호(프로듀서)

## 배경: 현재 구현 상태

TheBlob은 이미 게임 메커닉이 구현된 상태:
- **자원 3종**: moisture(수분), ATP(에너지), biomass(질량) — 삼각 의존 구조
- **업그레이드 5종**: moistureRetention, expansionSpeed, digestiveEnzyme, autoWatering, sporeQuality (지수 비용 곡선, 최대 10레벨)
- **유전 시스템**: 포자화 → prestige 포인트 → 영구 보너스 (biomass/moisture/ATP 부스트)
- **스테이지 진행**: 영양분 고갈 → 포자화 → 다음 스테이지 (난이도 8%/스테이지 증가)
- **수분 관리**: 클릭 물주기(+30), 자동 급수 업그레이드, 0.5/초 자연 감소
- **상태 머신**: active → dormant (수분<5) → sporulating
- **오프라인 수익**: 수분 있을 때만 ATP 0.05/초

시뮬레이션 레이어:
- Jeff Jones 2010 알고리즘, 100k 에이전트, WebGL2 GPU
- 센서→회전→이동 + 연결성 탐색 + 먹이 화학주성
- Hessian ridge 정맥 렌더링, 노란 반투명 원형질 본체
- 토러스 1500×1500 맵 (GL_REPEAT)

**핵심 문제**: `gameStore.ts`의 게임 로직과 `PhysarumSimulation.ts`의 시뮬레이션이 거의 독립적. `nutrients` 배열이 유일한 접점이며, 업그레이드가 시뮬레이션 파라미터를 직접 변경하지 않음.

---

## 라운드 1: 방향 제안

### 민준 (방치형/인크리멘탈 전문가)

이미 **인크리멘탈 게임의 뼈대가 다 있다.** `game.ts`를 보면 — prestige 루프(유전 시스템), 지수 비용 곡선(`UPGRADE_COSTS`의 2배씩 증가), 오프라인 수익(`OFFLINE_ATP_RATE`), 스테이지 진행. Cell to Singularity가 "진화"를 테마로 인크리멘탈을 만든 것처럼, Physarum의 "네트워크 최적화"는 인크리멘탈의 완벽한 은유.

**현재 구현의 강점:**
- 자원 3종(moisture/ATP/biomass)이 서로 의존하는 삼각 구조 — 수분이 없으면 성장 정지, 성장해야 ATP, ATP로 업그레이드
- 포자화 → 유전 포인트 → 영구 보너스는 전형적 prestige 메커닉
- 난이도 스케일링(`DIFFICULTY_NUTRIENT_SPACING_SCALE: 0.08`)이 이미 스테이지별 증가

**문제점:**
- **깊이가 얕다.** 업그레이드 5종, 유전 부스트 3종뿐. Antimatter Dimensions는 무한 차원, Cookie Clicker는 수십 개 건물. 현재 구조는 스테이지 3-4에서 할 게 없어질 것
- 시뮬레이션과 게임의 **연결이 느슨하다.** `expansionSpeed` 업그레이드가 실제로 에이전트 행동을 어떻게 바꾸는지 불분명. 숫자만 올라가고 시각적 변화가 약함

**제안 방향:**
- 업그레이드 트리를 대폭 확장 — 에이전트 행동 파라미터를 직접 조절 (센서 각도, 이동 속도, 분비량)
- "네트워크 효율" 메트릭 도입 — 영양분까지의 경로 최적화 정도가 보너스 배율
- 자동화 계층 추가 — 수동 물주기 → 자동 급수 → 자동 포자화 → 자동 스테이지 진행
- **무한 필드**: 스테이지별 맵 크기 스케일링으로 자연 해결 (stage 1: 1000², stage 10: 3000²)

---

### 서연 (액션 서바이벌/전략 전문가)

현재 이 게임에는 **긴장이 없다.** 수분 감소(`BASE_MOISTURE_DECAY: 0.5/초`)가 유일한 "위협"인데, `autoWatering` 업그레이드 하나면 해결됨. 블롭이 죽을 수 있나? 아니. 실패할 수 있나? 아니. 그러면 이건 게임이 아니라 **진행 바를 지켜보는 것**.

**Physarum의 숨겨진 전략 잠재력:**
실제 Physarum polycephalum이 도쿄 지하철 네트워크를 재현한 것으로 유명. 핵심은 "제한된 자원으로 최적 네트워크를 구축하는 것". 이건 **자원 관리 전략**의 본질.

**문제점:**
- 에이전트 100k가 무조건 전부 같은 팀. **대립 구조가 없다**
- 영양분은 그냥 먹으면 됨 — 경쟁자도, 방해꾼도 없음
- `blobState`가 active/dormant/sporulating뿐 — 방어/공격/후퇴 같은 전술 상태 없음

**제안 방향:**
- **경쟁 점균 도입**: 다른 색 점균이 반대편에서 확장. 같은 Jeff Jones 알고리즘, 다른 파라미터의 "적 블롭"
- **Creeper World 모델**: 웨이브마다 "항균제"가 맵 가장자리에서 확산. 블롭 트레일 잠식. 블롭은 먹이로 성장해서 밀어내야 함
- **영토 메커닉**: 트레일 밀도 일정 이상 = "점령 지역". 점령률이 승리 조건
- **무한 필드**: 영토 쟁탈이 무한 필드에서야 의미 있음

### 하늘 (시뮬레이션/디지털 토이 전문가) — 반대 관점

**근본 질문: 이 프로젝트에서 가장 아름다운 부분이 뭔가?**

`blob_body.frag.glsl`의 노란 반투명 원형질, `veins.frag.glsl`의 Hessian ridge 정맥, 100k 에이전트가 만드는 창발적 네트워크 패턴. **이게 진짜 자산.** 그 위에 올려놓은 건 — `WaterButton.tsx`, `UpgradePanel.tsx`, `StatsPanel.tsx`. 클릭하면 숫자 올라가는 패널들.

**현재 구현의 근본 문제:**
- **게임 메커닉이 시뮬레이션을 가린다.** UI 패널이 화면을 차지하면서 아름다운 시뮬레이션은 배경
- **"물 주기"가 의미 있는 상호작용인가?** 클릭 → 숫자 증가. 시뮬레이션의 창발적 속성 활용 안 함
- **업그레이드가 시뮬레이션을 바꾸나?** `expansionSpeed` 업그레이드가 실제 에이전트 파라미터를 안 바꿈. 두 레이어가 사실상 분리

**비교 사례:**
- **Sandspiel**: 게임 메커닉 없음. 원소를 떨어뜨리고 반응 관찰. 3M+ 플레이
- **Townscaper**: 점수도 목표도 없음. 건물을 놓고 자동 생성된 마을 감상. 상업적 성공
- **Mountain**: 산을 관조. "게임" 매체의 경계 확장

**제안 방향:**
- 게임 메커닉을 걷어내고 **"디지털 페트리 디쉬"**로 재정의
- 플레이어 상호작용 = **환경 조작**: 먹이 배치, 장벽 그리기, 온도/습도 조절, 빛 방향
- 상호작용이 시뮬레이션에 **직접 반영** — 장벽 그리면 경로 변경, 먹이 놓으면 촉수 뻗음
- "목표"는 플레이어가 스스로 설정
- **무한 필드**: 캔버스가 넓을수록 좋음. 관조를 위한 공간

---

### 지호 (게임 디자이너/프로듀서)

**기술적 해자(moat):**
- WebGL2 100k 에이전트 실시간 GPU 시뮬레이션 — 쉽게 복제 불가
- Jeff Jones 알고리즘의 시각적 결과물 — 생물학적으로 정확 + 아름다움
- Hessian ridge 정맥 렌더링 — 독자적 비주얼 파이프라인

**시장 포지셔닝:**

| 방향 | 경쟁 상대 | 차별화 | 시장 크기 | 솔로 개발 실현성 |
|------|---------|--------|---------|--------------|
| 인크리멘탈 | Cookie Clicker, Antimatter Dimensions | 시각적 피드백 | 대 | 중 (콘텐츠 양) |
| 서바이벌/전략 | Creeper World, Mushroom Wars | 점균류 고유 메커닉 | 중 | 낮 (AI, 밸런싱) |
| 디지털 토이 | Sandspiel, Townscaper | GPU 시뮬레이션 품질 | 소 | 높 (이미 거의 완성) |

**핵심 질문: "Physarum으로만 할 수 있는 것"이 뭔가?**
- 숫자 올리기(인크리멘탈)는 어떤 테마든 됨. Physarum일 필요 없음
- 영토 전쟁(서바이벌)은 재밌지만, 프로젝트 규모를 키움
- **Physarum만의 것**: 에이전트 기반 창발적 네트워크 형성. 환경 조작 → 예측 불가능한 패턴

**현재 코드 진단:**
`gameStore.ts`의 게임 루프와 `PhysarumSimulation.ts`의 시뮬레이션 루프가 **거의 독립적**. `nutrients` 배열이 유일한 접점이며, 이마저도 추상적 처리. **두 레이어의 괴리**가 어떤 방향을 택하든 해결해야 할 핵심 문제.

## 라운드 2: 토론

### 민준 반론

**하늘에게**: "게임 메커닉이 시뮬레이션을 가린다"에 동의하지만, 해법이 다르다. **걷어내는 게 아니라 통합해야.** Sandspiel/Townscaper는 성공했지만 리텐션이 약함. Townscaper 출시 후 한 달 내 플레이 시간 급감. 목표 없으면 "와 예쁘다" 한 번이면 끝.

**서연에게**: 적 AI는 솔로 개발에서 비현실적이라는 지호 의견에 동의. 그런데 **"긴장이 없다"는 진단은 정확**. 인크리멘탈에서도 긴장 있음 — "프레스티지를 지금 할까 더 기를까" 타이밍 딜레마, "어떤 업그레이드 먼저?" 자원 배분. 현재 구조에 **의사결정 밀도**가 부족.

**수정안**: 업그레이드가 실제 에이전트 파라미터를 바꿔야. "확장 속도 +20%"가 아니라 "센서 거리 +2px, 대신 분비량 -10%"처럼 **트레이드오프 있는 선택**. 시뮬레이션과 게임이 유기적 연결.

### 서연 반론

**민준에게**: 에이전트 파라미터 조작은 좋은데, 그것만으로는 **관전 포인트**가 안 생김. "센서 거리 11px이 9px보다 좋구나"를 느낄 플레이어가 몇이나? 시뮬레이션 시각 변화가 너무 미묘함.

반면 **적 블롭이 내 영역을 잠식하는 장면**은 즉각적 긴장감. 내 블롭이 반격하며 되찾는 장면은 카타르시스. 시뮬레이션의 시각적 드라마 = 게임플레이 감정.

**하늘에게**: 환경 조작 — 먹이 배치, 장벽 그리기 — 이건 사실 **샌드박스 전략 게임의 시작점**. 환경 조작에 "목적"을 부여하면 그게 전략 게임.

**솔로 개발 반론에 대해**: Jeff Jones 알고리즘 **자체가 에이전트 AI**. 파라미터만 다른 두 번째 에이전트 집단을 텍스처에 추가하면 됨. 시뮬레이션 엔진이 이미 AI 역할. 새 AI 시스템 불필요.

### 하늘 반론

**서연에게**: "적 블롭" 기술적으로 가능은 인정. 하지만 **두 점균 싸움이 재밌을까?** 둘 다 느리고, 비슷하게 생겼고, 승패는 초기 위치와 파라미터에 결정됨. 플레이어 실시간 개입 여지 적음. 체스가 아니라 개미 농장 두 개 관전.

**민준에게**: "목표 없으면 리텐션 없다"는 **전통 게임 사고방식**. ASMR 수십억 조회 이유는? 목표 없는 관조에도 시장 있음. Stardew Valley도 실제 대다수 플레이어는 최적화보다 **분위기** 즐김.

**수정안**: 순수 토이의 시장 한계는 인정. **하이브리드** 제안 — 기본 모드는 "디지털 정원"(자유 관조), 선택적 "도전 모드"(스테이지 목표). 중요한 건 **기본 경험이 게임 메커닉 없이도 성립해야** 한다는 것. 업그레이드 패널 없이도 30분 쳐다볼 수 있어야.

### 지호 종합

세 분의 토론에서 **하나의 합의점**: **시뮬레이션과 게임의 괴리가 핵심 문제.**

`gameStore.ts`의 `addBiomass(amount)` → 숫자만 증가. `PhysarumSimulation.ts`의 에이전트 → 시뮬레이션만 돌아감. 접점이 `nutrients` 배열뿐.

**세 방향 모두 같은 해법을 가리킴:**
- 민준: "업그레이드가 에이전트 파라미터를 바꿔야" → 게임→시뮬레이션
- 서연: "적 블롭이 내 영역을 잠식" → 시뮬레이션→게임
- 하늘: "환경 조작이 시뮬레이션에 직접 반영" → 플레이어→시뮬레이션

서연의 "적 블롭"이 기술적으로 매력적 (시뮬레이션 엔진 재사용). 하지만 느린 시뮬레이션 충돌이 재미를 보장하진 않음 (하늘 반론 유효).

민준의 "에이전트 파라미터 트레이드오프"는 Physarum 고유 강점을 살리면서 시뮬레이션에 직접 연결. 선택이 화면에서 **즉시 다른 성장 패턴**으로 나타남.

하늘의 "기본 경험이 게임 없이도 성립해야"는 **품질 기준/원칙**으로서 유효. 방향이 아닌 제약 조건.

## 결론

### 합의점

1. **시뮬레이션-게임 연결 강화가 어떤 방향이든 최우선 과제.** 현재 두 레이어가 분리되어 있음
2. **시뮬레이션의 시각적 아름다움이 핵심 자산.** 이를 가리는 UI가 아니라 활용하는 방향
3. **플레이어 행위가 시뮬레이션에 직접 영향**을 줘야 의미있는 상호작용

### 미합의 (프로토타입 필요)

- **인크리멘탈 심화 vs 대립 구조 도입** — 에이전트 파라미터 조작이 재밌을지, 적 블롭이 재밌을지는 플레이해봐야 알 수 있음
- **"게임" vs "토이" 정체성** — 하이브리드(기본 토이 + 선택적 게임 모드)가 타협안이지만, 초점 분산 위험

### 무한 필드에 대한 결론

**현 시점에서 무한 필드의 우선순위는 낮다.**
- 인크리멘탈: 스테이지 크기 스케일링으로 해결 (동적 확장 불필요)
- 서바이벌/전략: 고정 맵에서 영토 쟁탈이 더 긴밀한 긴장 (무한은 오히려 긴장 해소)
- 토이: 넓은 캔버스는 좋지만, 시뮬레이션-게임 연결보다 후순위
