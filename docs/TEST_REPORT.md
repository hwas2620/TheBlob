## 1. FPS 성능 측정

### BUG-1 수정 전후 비교

| 항목 | 수정 전 | 수정 후 | 변화 |
|------|---------|---------|------|
| 평균 FPS (활성) | ~11 | **17.7** | +61% |
| 최소 FPS (활성) | - | 15.6 | - |
| 최대 FPS (활성) | - | 20.2 | - |
| 휴면 FPS | - | **51.8** | - |

### 30초 장기 안정성 (5초 간격 6회 측정, 활성 상태)

```
[15.6, 16.4, 19.6, 20.2, 17.4, 17.0]
평균: 17.7 FPS / 최소: 15.6 / 최대: 20.2
```

**분석:**
- 디버그 early return 제거(BUG-1)만으로 FPS 61% 향상
- 활성 상태 평균 17.7 FPS — 아직 60 FPS 목표 대비 부족
- 휴면 시 51.8 FPS — 시뮬레이션 스텝 감소 효과 확인
- PBO 더블 버퍼링(BUG-2) 수정 시 추가 개선 예상

## 3. 콘솔 로그 분석

### 에러: 0건

### 경고: 1건 (반복)

```
performance warning: READ-usage buffer was written, then fenced,
but written again before being read back.
```
- **원인:** PBO 단일 버퍼 사용으로 인한 write→fence→write 충돌 (BUG-2)
- **영향:** GPU 파이프라인 부분 스톨, FPS 저하 기여
- **해결:** 더블 PBO 버퍼링 구현 필요

### 정상 로그 (초기화 시)

```
GPU 트레일맵 처리 활성화
GPU 에이전트 처리 활성화
GPU 씬 렌더러 활성화
Jeff Jones 시뮬레이션 초기화 완료 (맵: 1500x1500, GPU: true)
[AgentGPU] 첫 업데이트: 에이전트 100000개
[AgentGPU] 첫 분비: 트레일맵 1500x1500
```

- 디버그 console.log (BUG-3) 제거 확인 — 10프레임 샘플 로그 없음
