# Physarum polycephalum Visual Reference

## growth-timelapse/ (01~13.png)

Dark-field 타임랩스. 한천 위 점균류 성장 과정 전체.

### 단계별 특징

| 단계 | 파일 | 특징 |
|------|------|------|
| 초기 | 01~02 | 작은 노란 핵 + 반투명 올리브그린 막. 가장자리 매끄러움 |
| 성장 | 03~05 | 부채꼴 확장. 흰색 정맥이 방사상으로 출현. 먹이원(밝은 점) 연결 시작 |
| 성숙 | 06~08 | 정맥 네트워크 지배적. 정맥 사이 본체 얇아지고 반투명 |
| 후기 | 09~11 | 본체 거의 투명. 정맥만 남아 먹이원 연결 최적 네트워크 형성 |
| 완성 | 12~13 | 정맥 사이 본체 완전 소실. 수송 네트워크만 남음 |

### 핵심 관찰

- **본체**: 어두운 올리브그린, 반투명 (빛이 투과됨)
- **정맥**: 밝은 흰색/연노란, 본체 대비 확실히 밝음
- **배경**: 거의 순수 검정, 차가운 톤
- **밝은 부분**: 핵 + 먹이원만 (본체 자체는 어두움)
- **가장자리**: 매끄러운 유기적 곡선, 스펙클 없음
- **후기 변화**: 본체 → 투명, 정맥만 남음 (성장에 따른 진화)

## macro-closeup/ (01.png)

표면 접사 사진. 성장기 본체 표면 질감.

- 가까이서 보면 **밝은 황금색** (dark-field의 올리브그린과 다름)
- 정맥이 **3D 튜브** 형태로 융기
- 표면에 **젖은 광택/점성** 질감
- 줌 레벨에 따라 색상 인상이 달라짐: 줌인=황금, 줌아웃=올리브그린

## sporulation/ (01~08.png)

건조 환경에서의 포자화(sporulation) 과정.

- 환경이 건조/영양 고갈 시 정맥 수축
- 노란 포자낭(sporangia) 형성 — 줄기 위 구슬 형태
- 밀집된 포자낭이 포자를 생성하여 번식

## 현재 구현과의 갭

| 요소 | 레퍼런스 | 현재 구현 |
|------|----------|----------|
| 본체 색상 | 어두운 올리브그린, 반투명 | 크림/황색, 불투명 |
| 정맥 색상 | 밝은 흰색, 본체 대비 확 튐 | 크림 톤, 본체와 비슷 |
| 배경 | 순수 검정, 차가운 톤 | 따뜻한 갈색 (15,12,8) |
| 본체-정맥 관계 | 정맥이 위에 떠 보이는 느낌 | 구분 약함 |
| 가장자리 | 매끄러운 유기적 곡선 | 스펙클/점점이 |
| 후기 변화 | 본체 사라지고 정맥만 남음 | 미구현 |
